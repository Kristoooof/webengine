## Mi a baj a naiv tokenizerrel?

Próbáld ki a `NaiveTokenizer`-rel:

```rust
let t = NaiveTokenizer;
println!("{:?}", t.tokenize("<a title=\"1 > 0\">ok</a>"));
println!("{:?}", t.tokenize("a<!-- <b> -->c"));
```

Az elsőnél az idézőjelen belüli `>`-t a tag végének hiszi. A másodiknál a kommentben lévő `<b>`-t tagnak veszi. Valódi weboldalakon mindkettő gyakori. Gondolj csak egy `onclick="if (a > b) ..."` attribútumra, vagy a kikommentezett HTML-részekre.

## A terv

A `CursorTokenizer` a 01-09-ben megírt `Cursor`-t használja. A fő ciklus minden lépésben eldönti, mi következik:

<div class="pipeline">
  <div class="pl-step"><b>1</b><strong><code>&lt;!--</code> jön?</strong><small>Komment: olvass a <code>--&gt;</code>-ig → <code>Token::Comment</code></small></div>
  <div class="pl-step"><b>2</b><strong><code>&lt;</code> jön?</strong><small>Tag: olvass a <code>&gt;</code>-ig, de figyelj az idézőjelekre → <code>Tag::parse</code></small></div>
  <div class="pl-step"><b>3</b><strong>Különben</strong><small>Szöveg: olvass a következő <code>&lt;</code>-ig → <code>Token::Text</code></small></div>
</div>

A 2. lépés trükkje: tag olvasása közben meg kell jegyezni, hogy **idézőjelen belül vagy-e**, és ha igen, melyiken (`"` vagy `'`). Erre egy `Option<char>` tökéletes: `None`, ha nem vagy idézőjelben, `Some('"')`, ha egy `"`-en belül vagy.

## 1. rész: a váz és a komment

:::task
A `tokenizer.rs`-ben:

1. Hozd létre a `CursorTokenizer` unit structot, és írd meg a `Tokenizer` implementációját.
2. A `tokenize` hozzon létre egy `Cursor`-t, és egy `while !cur.is_eof()` ciklusban döntsön a fenti három eset között.
3. A komment ágat írd meg teljesen: lépd át a `<!--`-t (`cur.advance(4)`), gyűjtsd a karaktereket, amíg el nem érsz a `-->`-ig (vagy a szöveg végéig), aztán lépd át a `-->`-t is.
4. A tag ágat egyelőre helyettesítsd ezzel: olvass a `>`-ig idézőjel-figyelés nélkül. A szöveg ágat a `consume_while(|c| c != '<')`-val oldd meg.
:::

```rust test
    #[test]
    fn cursor_basic() {
        basic_suite(&CursorTokenizer);
    }

    #[test]
    fn cursor_comments() {
        let t = CursorTokenizer;
        assert_eq!(
            t.tokenize("a<!-- <b> -->c"),
            vec![text("a"), Token::Comment(" <b> ".into()), text("c")]
        );
        assert_eq!(t.tokenize("<!--x"), vec![Token::Comment("x".into())]);
    }
```

:::hint
A fő ciklus:
```rust
let mut cur = Cursor::new(input);
let mut tokens = Vec::new();
while !cur.is_eof() {
    if cur.starts_with("<!--") {
        // komment
    } else if cur.peek() == Some('<') {
        // tag
    } else {
        // szöveg
    }
}
tokens
```
---
A komment belseje:
```rust
cur.advance(4);
let mut body = String::new();
while !cur.is_eof() && !cur.starts_with("-->") {
    body.push(cur.next_char().unwrap());
}
cur.advance(3);   // ha a végén vagyunk, az advance nem lép túl, emlékszel?
tokens.push(Token::Comment(body));
```
Itt az `unwrap()` biztonságos, mert az előbb ellenőriztük, hogy nem vagyunk a végén. Az ilyen eseteket érdemes egy kommentben meg is indokolni.

## 2. rész: tag idézőjelekkel

:::task
Szervezd ki a tag olvasását egy külön függvénybe: `fn read_tag(cur: &mut Cursor) -> Token`. Olvass karakterenként egy `raw` pufferbe, és tartsd számon egy `quote: Option<char>` változóban, hogy idézőjelen belül vagy-e:

- Ha idézőjelen belül vagy, és pont a záró idézőjel jön → `quote = None`.
- Ha idézőjelen belül vagy, és bármi más jön → semmi (a karakter csak bekerül a pufferbe).
- Ha nem vagy idézőjelen belül, és `"` vagy `'` jön → `quote = Some(c)`.
- Ha nem vagy idézőjelen belül, és `>` jön → vége a tagnek.

A végén: `Token::from_tag(Tag::parse(&raw))`.
:::

```rust test
    #[test]
    fn cursor_quotes() {
        let t = CursorTokenizer;
        assert_eq!(
            t.tokenize("<a title=\"1 > 0\">ok</a>"),
            vec![start("a"), text("ok"), end("a")]
        );
        assert_eq!(t.tokenize("<a title='>'>ok</a>"), vec![start("a"), text("ok"), end("a")]);
    }

    #[test]
    fn whitespace_between_tags() {
        let t = CursorTokenizer;
        let toks = t.tokenize("<ul>\n  <li>1</li>\n</ul>");
        assert_eq!(toks.len(), 7);
        assert!(toks[1].is_whitespace_text());
    }
```

:::hint
A fenti négy szabály szó szerint egy `match quote { ... }` négy ággal, őrfeltételekkel:
```rust
match quote {
    Some(q) if c == q => quote = None,
    Some(_) => {}
    None if c == '"' || c == '\'' => quote = Some(c),
    None if c == '>' => break,
    None => {}
}
```
---
A ciklus: `while let Some(c) = cur.next_char() { raw.push(c); match quote { ... } }`. Figyeld meg, hogy a `raw.push(c)` a `match` **előtt** van, így a záró `>` is bekerül a pufferbe, mielőtt a `break` kilép.
:::

:::solution A teljes CursorTokenizer és a pick
```rust
pub struct CursorTokenizer;

impl Tokenizer for CursorTokenizer {
    fn name(&self) -> &'static str {
        "kurzoros"
    }

    fn tokenize(&self, input: &str) -> Vec<Token> {
        let mut cur = Cursor::new(input);
        let mut tokens = Vec::new();
        while !cur.is_eof() {
            if cur.starts_with("<!--") {
                cur.advance(4);
                let mut body = String::new();
                while !cur.is_eof() && !cur.starts_with("-->") {
                    // nem vagyunk a végén, tehát van következő karakter
                    body.push(cur.next_char().unwrap());
                }
                cur.advance(3);
                tokens.push(Token::Comment(body));
            } else if cur.peek() == Some('<') {
                tokens.push(read_tag(&mut cur));
            } else {
                let text = cur.consume_while(|c| c != '<');
                tokens.push(Token::Text(text));
            }
        }
        tokens
    }
}

fn read_tag(cur: &mut Cursor) -> Token {
    let mut raw = String::new();
    let mut quote: Option<char> = None;
    while let Some(c) = cur.next_char() {
        raw.push(c);
        match quote {
            Some(q) if c == q => quote = None,
            Some(_) => {}
            None if c == '"' || c == '\'' => quote = Some(c),
            None if c == '>' => break,
            None => {}
        }
    }
    Token::from_tag(Tag::parse(&raw))
}

pub fn pick(naive: bool) -> Box<dyn Tokenizer> {
    if naive {
        Box::new(NaiveTokenizer)
    } else {
        Box::new(CursorTokenizer)
    }
}
```

```rust
// src/main.rs
use gyakorlo::token::Token;
use gyakorlo::tokenizer::pick;
use owo_colors::OwoColorize;

fn main() {
    let naive = std::env::args().any(|a| a == "--naiv");
    let tokenizer = pick(naive);
    let html = "<p title=\"1 > 0\">Szia, <b>Rozsda</b>!</p><!-- <i>titok</i> -->";

    println!("Tokenizer: {}", tokenizer.name().bold());
    for t in tokenizer.tokenize(html) {
        match &t {
            Token::StartTag { .. } => println!("  {}", t.to_string().green()),
            Token::EndTag { .. } => println!("  {}", t.to_string().red()),
            Token::Text(_) => println!("  {:?}", t.to_string()),
            Token::Comment(_) => println!("  {}", t.to_string().dimmed()),
        }
    }
}
```
