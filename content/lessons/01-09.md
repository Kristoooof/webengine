## Vec: a növelhető tömb

```rust
let mut tags: Vec<String> = Vec::new();
tags.push(String::from("html"));
tags.push(String::from("body"));

let nums = vec![1, 2, 3];       // a vec! makró kezdőértékkel hoz létre

println!("{}", tags.len());     // 2
println!("{}", tags[0]);        // html
println!("{:?}", tags);         // ["html", "body"]
```

Ez a C# `List<T>`, a C++ `std::vector<T>` és a Python `list` megfelelője, csak itt minden elem **ugyanolyan típusú**.

### Indexelés: [] vagy get

```rust
let v = vec!['a', 'b'];
let x = v[5];           // 💥 panic: index out of bounds
let y = v.get(5);       // None, nincs pánik
let z = v.get(0);       // Some(&'a')
```

A `get` `Option`-t ad vissza, ezért a böngészőben, ahol a bemenet bármilyen lehet, a `get` a biztonságos választás.

### Bejárás

```rust
for t in &tags {            // kölcsönzött bejárás: tags megmarad
    println!("{t}");
}
for t in &mut tags {        // módosítva bejárás
    t.push('!');
}
for t in tags {             // "elfogyasztó" bejárás: tags utána nem használható (move!)
    println!("{t}");
}
```

Látod? Az ownership és a borrowing itt is pontosan ugyanúgy működik.

## Szeletek: &[T]

Ahogy a `&str` egy szelet egy `String`-ből, a `&[T]` egy szelet egy `Vec<T>`-ből (vagy tömbből):

```rust
let v = vec![10, 20, 30, 40];
let middle: &[i32] = &v[1..3];      // [20, 30]

fn sum(xs: &[i32]) -> i32 {        // szeletet vár: Vec-et és tömböt is elfogad
    let mut s = 0;
    for x in xs {
        s += x;
    }
    s
}
```

:::tip Arany szabály, 2. rész
Ahogy szövegnél `&str` a jobb paraméter `&String` helyett, listánál `&[T]` a jobb `&Vec<T>` helyett. Ugyanazért: rugalmasabb, és nem kerül többe.
:::

## Miért kell kurzor?

A tokenizernek gyakran kell **előre nézni**: ha `<` jön, utána `!--` következik-e (akkor komment), vagy `/` (akkor zárótag)? A `for c in s.chars()` erre nem jó, mert nem tudsz vele visszanézni vagy előrekukkantani.

Ezért építünk egy **kurzort**: egy struct, ami tartja a karaktereket és egy pozíciót.

```rust
struct Cursor {
    chars: Vec<char>,
    pos: usize,
}
```

A `Vec<char>`-t a szövegből így kapod meg:

```rust
let chars: Vec<char> = "<p>".chars().collect();   // ['<', 'p', '>']
```

A `collect()` összegyűjti az iterátor elemeit egy gyűjteménybe. Hogy milyenbe, azt a típus (`Vec<char>`) mondja meg.

:::note Miért Vec&lt;char&gt;, és miért nem közvetlenül a &str?
Mert a `&str`-ben a karakterek különböző hosszúak (1–4 bájt), ezért az „5. karakter” megkereséséhez az elejéről kellene számolni. A `Vec<char>`-ben minden karakter 4 bájt, így a `chars[pos]` azonnali. Cserébe 4-szer annyi memóriát használ ASCII-szövegnél. Egy tanuló-tokenizerben ez tökéletesen rendben van. A profi parserek bájtokon dolgoznak, ezt a 3. modulban megnézzük.
:::

## Te jössz: a Cursor

:::task
Építsd meg a `Cursor` structot és ezeket a metódusokat:

| Metódus | Mit csinál |
|---|---|
| `fn new(input: &str) -> Cursor` | Létrehozza a kurzort, `pos = 0` |
| `fn peek(&self) -> Option<char>` | Az aktuális karakter, **továbblépés nélkül**. `None`, ha a végén vagyunk |
| `fn next_char(&mut self) -> Option<char>` | Visszaadja az aktuális karaktert, és **továbblép** |
| `fn is_eof(&self) -> bool` | A végén vagyunk-e (end of file) |
| `fn starts_with(&self, s: &str) -> bool` | Az aktuális pozíciótól `s` következik-e (pl. `"<!--"`) |
| `fn advance(&mut self, n: usize)` | Továbblép `n` karaktert (de legfeljebb a végéig) |
| `fn consume_while(&mut self, pred: fn(char) -> bool) -> String` | Összegyűjti a karaktereket, amíg `pred` igaz |

A `pred: fn(char) -> bool` egy **függvény paraméter**: bármilyen függvényt átadhatsz, ami `char`-t kap és `bool`-t ad. Például az `is_ascii_letter`-t, vagy egy névtelen függvényt: `|c| c.is_ascii_alphanumeric()`.
:::

```rust test
    #[test]
    fn cursor_peek_and_next() {
        let mut c = Cursor::new("ab");
        assert_eq!(c.peek(), Some('a'));
        assert_eq!(c.next_char(), Some('a'));
        assert_eq!(c.next_char(), Some('b'));
        assert_eq!(c.next_char(), None);
        assert!(c.is_eof());
    }

    #[test]
    fn cursor_unicode() {
        let mut c = Cursor::new("ő<");
        assert_eq!(c.next_char(), Some('ő'));
        assert_eq!(c.peek(), Some('<'));
    }

    #[test]
    fn cursor_starts_with() {
        let mut c = Cursor::new("x<!-- y");
        assert!(!c.starts_with("<!--"));
        c.next_char();
        assert!(c.starts_with("<!--"));
        assert!(!c.starts_with("<!--- y long"));
    }

    #[test]
    fn cursor_consume() {
        let mut c = Cursor::new("div class");
        assert_eq!(c.consume_while(|ch| ch.is_ascii_alphanumeric()), "div");
        assert_eq!(c.peek(), Some(' '));
        assert_eq!(c.consume_while(|ch| ch == 'z'), "");
        c.advance(100);
        assert!(c.is_eof());
    }
```

:::hint
A `peek`-hez: a `self.chars.get(self.pos)` egy `Option<&char>`-t ad (referenciát). Neked `Option<char>` kell. A `.copied()` pont ezt csinálja: `self.chars.get(self.pos).copied()`. (Ha ez túl varázslatos, egy `if self.pos < self.chars.len() { Some(self.chars[self.pos]) } else { None }` is tökéletes.)
---
A `next_char` a `peek`-re épülhet, és itt jól jön a `?`:
```rust
fn next_char(&mut self) -> Option<char> {
    let c = self.peek()?;
    self.pos += 1;
    Some(c)
}
```
---
A `starts_with`: menj végig az `s` karakterein egy `i` indexszel (ami `self.pos`-tól indul), és hasonlítsd össze őket a `self.chars.get(i)`-vel. Ha bármelyik nem egyezik (vagy elfogyott a szöveg), `false`. Tipp: a `self.chars.get(i) != Some(&c)` ellenőrzi egyszerre a kettőt.
---
A `consume_while` egy `while let` ciklus, ami egy `if let`-hez hasonlóan addig fut, amíg a minta illeszkedik:
```rust
while let Some(c) = self.peek() {
    if !pred(c) { break; }
    out.push(c);
    self.pos += 1;
}
```
Az `advance`-hoz: `self.pos = (self.pos + n).min(self.chars.len());`
:::

:::solution
```rust
struct Cursor {
    chars: Vec<char>,
    pos: usize,
}

impl Cursor {
    fn new(input: &str) -> Cursor {
        Cursor { chars: input.chars().collect(), pos: 0 }
    }

    fn peek(&self) -> Option<char> {
        self.chars.get(self.pos).copied()
    }

    fn next_char(&mut self) -> Option<char> {
        let c = self.peek()?;
        self.pos += 1;
        Some(c)
    }

    fn is_eof(&self) -> bool {
        self.pos >= self.chars.len()
    }

    fn starts_with(&self, s: &str) -> bool {
        let mut i = self.pos;
        for c in s.chars() {
            if self.chars.get(i) != Some(&c) {
                return false;
            }
            i += 1;
        }
        true
    }

    fn advance(&mut self, n: usize) {
        self.pos = (self.pos + n).min(self.chars.len());
    }

    fn consume_while(&mut self, pred: fn(char) -> bool) -> String {
        let mut out = String::new();
        while let Some(c) = self.peek() {
            if !pred(c) {
                break;
            }
            out.push(c);
            self.pos += 1;
        }
        out
    }
}
```
