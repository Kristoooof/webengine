:::goal
A szelektorokból adatszerkezet lesz: a `nav > ul li.aktiv` szövegből egy `Selector`, amiben benne van, hogy milyen tagű, id-jű és osztályú elemeket keresünk, és milyen viszonyban. Közben megismered a Rust **szelet-mintáit** (*slice patterns*) és egy szép `collect`-trükköt.
:::

## A szelektorok fajtái

| Neve | Példa | Mire illik |
|---|---|---|
| Típus-szelektor (*type*) | `p` | minden `<p>` |
| Osztály-szelektor (*class*) | `.intro` | minden elem, aminek a `class` attribútumában ott van az `intro` |
| Id-szelektor (*id*) | `#fo` | az elem, aminek az `id`-je `fo` |
| Univerzális (*universal*) | `*` | minden elem |
| **Összetett** (*compound*) | `p.intro#fo` | ami egyszerre `p`, `intro` osztályú **és** `fo` id-jű |
| Leszármazott (*descendant*) | `nav a` | `a`, ami valahol egy `nav` **alatt** van |
| Gyerek (*child*) | `ul > li` | `li`, aminek a **közvetlen** szülője `ul` |
| Lista | `h1, h2` | ami `h1` **vagy** `h2` |

Az összetett szelektorban nincs szóköz, a darabjai ugyanarra az elemre vonatkoznak. A szóköz és a `>` a **kombinátorok** (*combinators*): ezek két elem viszonyát írják le.

:::note Amit (még) nem tudunk
Vannak még pszeudo-osztályok (`a:hover`, `li:first-child`), attribútum-szelektorok (`a[href]`) és testvér-kombinátorok (`h1 + p`, `h1 ~ p`). Ezeket most **érvénytelennek** tekintjük. A szabvány szerint ha egy szelektor-lista bármelyik tagja érvénytelen, **az egész szabály elvész**. A `h1, a:hover { … }` tehát nálunk a `h1`-re sem vonatkozik. Ez nem a mi hibánk: egy igazi böngésző is pontosan így bánik egy szelektorral, amit nem ismer.
:::

## Az adatszerkezet

```rust
/// Egyszerű szelektorok szóköz nélkül egymás után, pl. `p.intro#fo`.
#[derive(Debug, Clone, PartialEq, Default)]
pub struct Compound {
    pub tag: Option<String>,
    pub id: Option<String>,
    pub classes: Vec<String>,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub enum Combinator {
    /// `a b`: b valahol a alatt
    Descendant,
    /// `a > b`: b közvetlenül a alatt
    Child,
}

/// Egy teljes szelektor, pl. `nav > ul li.aktiv`.
/// A `combinators[i]` a `compounds[i]` és a `compounds[i + 1]` között áll.
#[derive(Debug, Clone, PartialEq)]
pub struct Selector {
    pub compounds: Vec<Compound>,
    pub combinators: Vec<Combinator>,
}
```

```text Ábra
nav > ul  li.aktiv

compounds:    [ nav ]       [ ul ]       [ li.aktiv ]
combinators:           [>]        [szóköz]
                      Child      Descendant
```

Az univerzális `*` egy olyan `Compound`, amiben minden üres (`Compound::default()`): nincs feltétel, tehát minden elemre illik.

## Szelet-minták: tokenek levágása

A szelektor elején és végén lehet szóköz (`h1 , h2` → `" h2 "`). Kell egy függvény, ami levágja a `Whitespace` tokeneket. Ehhez a Rust egyik legszebb eszköze, a **szelet-minta**:

```rust
match tokens {
    [] => "üres",
    [Token::Whitespace, rest @ ..] => "szóközzel kezdődik, a többi a rest-ben",
    [.., Token::Whitespace] => "szóközzel végződik",
    [egy] => "pontosan egy elem",
    _ => "bármi más",
}
```

A `rest @ ..` azt jelenti: „a maradék rész, és nevezd el `rest`-nek”. Ugyanez `while let`-tel ciklusban:

```rust
/// Levágja a szóköz-tokeneket a szelet elejéről és végéről.
pub fn trim_ws(mut tokens: &[Token]) -> &[Token] {
    while let [Token::Whitespace, rest @ ..] = tokens {
        tokens = rest;
    }
    while let [rest @ .., Token::Whitespace] = tokens {
        tokens = rest;
    }
    tokens
}
```

Semmit nem másol: csak a szelet eleje és vége mozdul. Ezt a függvényt rakd a `tokenizer.rs`-be, mert a parser is használni fogja.

:::compare Szelet-minták máshol
@@ Python
`elso, *tobbi = lista`: a Python „csillagos kicsomagolása” ugyanez az ötlet. A Python 3.10 `match` utasítása is tud ilyet: `case [Token.WS, *rest]:`.
@@ C#
A C# 11 óta van *list pattern*: `if (tokens is [Whitespace, .. var rest])`. Szinte ugyanaz a szintaxis!
@@ C++
Nincs ilyen. A C++-ban `std::span`-nal és kézi indexeléssel csinálnád.
:::

## A parse-olás menete

A `parse_selector` egy ciklus, ami egy indexszel halad a tokeneken:

1. Olvass be egy **összetett szelektort** (`parse_compound`). Ha nem sikerül, az egész érvénytelen.
2. Ha elfogytak a tokenek, kész.
3. Különben **kombinátor** kell: ha szóközök után `>` jön (vagy szóközök nélkül `>`), az `Child`, és a `>` utáni szóközöket is átugorjuk. Ha csak szóköz volt, `Descendant`. Ha egyik sem (pl. `a:hover`-nél a `:`), érvénytelen.
4. Vissza az 1. lépéshez.

A `parse_compound` a `start` indextől olvas: opcionálisan egy tagnév (`Ident`) vagy `*`, aztán akárhány `Hash` (id) vagy `Delim('.')` + `Ident` (osztály). Ha egyetlen tokent sem tudott elfogyasztani, `None`. Visszaadja az elkészült `Compound`-ot és azt az indexet, ahol abbahagyta.

A tagnevet kisbetűsítjük (`to_ascii_lowercase`), mert a HTML-tagek nevét a DOM is kisbetűvel tárolja, és a `P { }` ugyanúgy illik a `<p>`-re. Az osztály és az id viszont **kis- és nagybetű-érzékeny**: a `.Intro` nem illik a `class="intro"`-ra.

```rust
//! Szelektorok: parse-olás, specificitás és illesztés a DOM-ra.

use crate::tokenizer::{Token, trim_ws};

/// Egy összetett szelektor a `start` indextől. Visszaadja, hol ért véget.
fn parse_compound(tokens: &[Token], start: usize) -> Option<(Compound, usize)> {
    let mut c = Compound::default();
    let mut i = start;
    match tokens.get(i) {
        Some(Token::Ident(name)) => {
            c.tag = Some(name.to_ascii_lowercase());
            i += 1;
        }
        Some(Token::Delim('*')) => i += 1,
        _ => {}
    }
    loop {
        match (tokens.get(i), tokens.get(i + 1)) {
            (Some(Token::Hash(id)), _) => {
                c.id = Some(id.clone());
                i += 1;
            }
            (Some(Token::Delim('.')), Some(Token::Ident(class))) => {
                c.classes.push(class.clone());
                i += 2;
            }
            _ => break,
        }
    }
    if i == start { None } else { Some((c, i)) }
}

pub fn parse_selector(tokens: &[Token]) -> Option<Selector> {
    let tokens = trim_ws(tokens);
    let mut compounds = Vec::new();
    let mut combinators = Vec::new();
    let mut i = 0;
    loop {
        let (compound, next) = parse_compound(tokens, i)?;
        compounds.push(compound);
        i = next;
        if i == tokens.len() {
            break;
        }
        let mut saw_space = false;
        while tokens.get(i) == Some(&Token::Whitespace) {
            saw_space = true;
            i += 1;
        }
        let combinator = if tokens.get(i) == Some(&Token::Delim('>')) {
            i += 1;
            while tokens.get(i) == Some(&Token::Whitespace) {
                i += 1;
            }
            Combinator::Child
        } else if saw_space {
            Combinator::Descendant
        } else {
            return None; // pl. `a:hover`: ezt (még) nem ismerjük
        };
        combinators.push(combinator);
    }
    Some(Selector {
        compounds,
        combinators,
    })
}

/// Vesszővel elválasztott szelektorok. Ha bármelyik érvénytelen, az egész lista az.
pub fn parse_selector_list(tokens: &[Token]) -> Option<Vec<Selector>> {
    tokens
        .split(|t| *t == Token::Comma)
        .map(parse_selector)
        .collect()
}
```

fn parse_compound(s: &str) -> Option<(Option<String>, Option<String>, Vec<String>)> {
    if s.is_empty() {
        return None;
    }
    let is_name = |c: char| c.is_ascii_alphanumeric() || c == '-' || c == '_';
    let name_len = |t: &str| t.find(|c: char| !is_name(c)).unwrap_or(t.len());
    let mut rest = s;
    let mut tag = None;
    if let Some(r) = rest.strip_prefix('*') {
        rest = r;
    } else if name_len(rest) > 0 {
        let n = name_len(rest);
        tag = Some(rest[..n].to_ascii_lowercase());
        rest = &rest[n..];
    }
    let mut id = None;
    let mut classes = Vec::new();
    while let Some(marker) = rest.chars().next() {
        if marker != '#' && marker != '.' {
            return None;
        }
        let after = &rest[1..];
        let n = name_len(after);
        if n == 0 {
            return None;
        }
        if marker == '#' {
            id = Some(after[..n].to_string());

            classes.push(after[..n].to_string());

        rest = &after[n..];

fn parse_compound(s: &str) -> Option<(Option<String>, Option<String>, Vec<String>)> {
    let chars: Vec<char> = s.chars().collect();
    if chars.is_empty() {
        return None;
    }
    let is_name = |c: char| c.is_ascii_alphanumeric() || c == '-' || c == '_';
    let mut i = 0;
    let mut tag = None;
    if chars[0] == '*' {
        i = 1;
    } else {
        let mut name = String::new();
        while i < chars.len() && is_name(chars[i]) {
            name.push(chars[i].to_ascii_lowercase());
            i += 1;
        }
        if !name.is_empty() {
            tag = Some(name);
        }
    }
    let mut id = None;
    let mut classes: Vec<String> = Vec::new();
    while i < chars.len() {
        let marker = chars[i];
        if marker != '#' && marker != '.' {
            return None;
        }
        i += 1;
        let mut name = String::new();
        while i < chars.len() && is_name(chars[i]) {
            name = format!("{name}{}", chars[i]);
            i += 1;
        }
        if name.is_empty() {
            return None;
        }
        if marker == '#' {
            id = Some(name);
        } else {
            classes.push(name);
        }
    }
    Some((tag, id, classes))
}
