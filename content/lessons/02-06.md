## 1. rész: sortörés

A legegyszerűbb sortörő algoritmus a **mohó** (greedy): szavanként haladunk, és ha a következő szó már nem fér ki a sorba, új sort kezdünk.

```text Ábra
max 12 karakter:  "Ez az első oldal, amit a böngészőm"
                  ┌────────────┐
                  │Ez az első  │  ← az "oldal," már nem fért volna ki
                  │oldal, amit │
                  │a böngészőm │
                  └────────────┘
```

A bitmap font minden betűje ugyanolyan széles (*monospace*), ezért a szélességet karakterszámmal is mérhetjük. Ha egy szó önmagában is hosszabb a sornál (pl. egy hosszú URL), azt **keményen** el kell vágni.

:::task
Hozz létre egy `crates/rozsda-browser/src/layout.rs` modult, és írd meg: `pub fn wrap(text: &str, max_chars: usize) -> Vec<String>`

- A szavak szóközzel vannak elválasztva (a szóközöket a parser már összevonta).
- Egy sor legfeljebb `max_chars` **karakter** (nem bájt!) lehet.
- A túl hosszú szót vágd fel `max_chars` hosszú darabokra.
- Üres bemenetre üres vektort adj vissza.
:::

```rust test
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn wrap_basic() {
        assert_eq!(wrap("a bb ccc dddd", 6), vec!["a bb", "ccc", "dddd"]);
        assert_eq!(wrap("", 5), Vec::<String>::new());
        assert_eq!(wrap("egy", 10), vec!["egy"]);
    }

    #[test]
    fn wrap_long_word_and_unicode() {
        assert_eq!(wrap("abcdefgh", 3), vec!["abc", "def", "gh"]);
        assert_eq!(wrap("ő ű áéí", 3), vec!["ő ű", "áéí"]);
        assert_eq!(wrap("x abcdefg", 4), vec!["x", "abcd", "efg"]);
    }
}
```

:::hint
Tartsd számon az aktuális sort (`current: String`) és a hosszát **karakterben** (`len: usize`), mert a `current.len()` bájtot adna, és az ékezeteknél tévedne. Menj végig a szavakon: `for word in text.split(' ').filter(|w| !w.is_empty())`.
---
Egy szónál: ha a sor nem üres, és `len + 1 + szóhossz > max_chars`, akkor a sort lezárod (`lines.push(...)`), és újat kezdesz. Utána (ha a sor nem üres) egy szóköz, aztán maga a szó. A `std::mem::take(&mut current)` kiveszi a `String`-et, és egy üreset hagy a helyén. Pont ez kell a lezáráshoz.
---
A túl hosszú szó: alakítsd `Vec<char>`-rá, és amíg hosszabb, mint `max_chars`, vágd le az elejét (`let rest = word.split_off(max_chars);` – ez a `max_chars` utáni részt adja vissza, és a `word`-ben az eleje marad). Az elejét tedd külön sorba, a `rest` megy tovább. (Előtte zárd le az aktuális sort, ha nem üres.)
:::

## 2. rész: layout

Minden blokkfajtának saját stílusa van:

| Fajta | Nagyítás | Szín | Extra |
|---|---|---|---|
| `Heading(1)` | 4 | `0x1C1917` | |
| `Heading(2)` | 3 | `0x1C1917` | |
| `Heading(3)` | 2 | `0xC2410C` (narancs) | |
| `Paragraph` | 2 | `0x44403C` | |
| `ListItem` | 2 | `0x44403C` | behúzás és `»` jel előtte |

:::note A felsorolásjel
A szép `•` karakter (U+2022) nincs benne a Latin-1 fontban, abból tofu lenne. A `»` (U+00BB) viszont benne van, és listajelnek is jól néz ki.
:::

:::task
Írd meg a `layout.rs`-be:

1. `#[derive(Debug, Clone, PartialEq)] pub struct Line { pub x: i32, pub y: i32, pub scale: i32, pub color: u32, pub text: String }`
2. `pub struct Style { pub scale: i32, pub color: u32, pub bullet: bool }` és `pub fn style_for(kind: BlockKind) -> Style` a fenti táblázat szerint.
3. `pub fn layout(page: &Page, width: i32, margin: i32) -> (Vec<Line>, i32)`, ami a sorokat és a teljes tartalom magasságát adja vissza (ez kell majd a görgetéshez):
   - `y` a `margin`-ról indul.
   - Blokkonként: a karakterszélesség `GLYPH * scale`, a sor magassága `GLYPH * scale + scale * 4` (egy kis sorköz).
   - A `max_chars` annyi, amennyi karakter kifér a `width - 2 * margin - behúzás` szélességbe.
   - A blokk szövegét a `'\n'` mentén (a `<br>`-ek) bekezdésekre bontod, mindegyiket `wrap`-eled, és minden sor egy `Line`, majd `y += sor_magassága`.
   - Listaelemnél az első sor elé egy narancssárga `»` `Line` is kerül.
   - Blokkok után egy fél sornyi extra hely.
:::

```rust test
    #[test]
    fn layout_stacks_blocks() {
        let page = Page {
            title: None,
            blocks: vec![
                Block { kind: BlockKind::Heading(1), text: "Cím".into() },
                Block { kind: BlockKind::Paragraph, text: "szöveg".into() },
            ],
        };
        let (lines, height) = layout(&page, 800, 20);
        assert_eq!(lines.len(), 2);
        assert_eq!(lines[0].scale, 4);
        assert!(lines[1].y > lines[0].y);
        assert!(height > lines[1].y);
    }
```

(Ezt a tesztet a `tests` modulba tedd, és a tetejére írd be: `use rozsda_core::Block;`.)

:::hint
A blokkonkénti rész váza:

## 3. rész: festés és görgetés

:::task
A `main`-ben (`mod layout;`):

1. A layoutot a render loop **előtt**, egyszer számold ki: `let (lines, content_height) = layout::layout(&page, WIDTH as i32, 40);`
2. Legyen egy `scroll: i32` változó. A legnagyobb értéke `max_scroll = (content_height - HEIGHT as i32).max(0)`.
3. Minden képkockában:
   - Egérgörgő: `if let Some((_, dy)) = window.get_scroll_wheel() { scroll -= (dy * 3.0) as i32; }`
   - Billentyűk: `Down`/`Up` ± 40, `PageDown`/`Space`/`PageUp` ± egy képernyőnyi, `Home`/`End` az elejére/végére. Használd a `window.is_key_pressed(Key::Down, KeyRepeat::Yes)`-t, így nyomva tartva ismétlődik.
   - `scroll = scroll.clamp(0, max_scroll);`
   - Háttér törlése, aztán minden `Line`-t a `y - scroll` pozícióba rajzolsz. Ami teljesen kilóg a képernyőről, azt kihagyod.
:::

:::solution A teljes layout.rs
```rust
use crate::text::GLYPH;
use rozsda_core::{BlockKind, Page};

/// Egy kirajzolandó sor: ez a Rozsda első "display listje".
#[derive(Debug, Clone, PartialEq)]
pub struct Line {
    pub x: i32,
    pub y: i32,
    pub scale: i32,
    pub color: u32,
    pub text: String,
}

pub fn wrap(text: &str, max_chars: usize) -> Vec<String> {
    let max_chars = max_chars.max(1);
    let mut lines = Vec::new();
    let mut current = String::new();
    let mut len = 0;
    for word in text.split(' ').filter(|w| !w.is_empty()) {
        let mut word: Vec<char> = word.chars().collect();
        // túl hosszú szó: kemény törés
        while word.len() > max_chars {
            if len > 0 {
                lines.push(std::mem::take(&mut current));
                len = 0;
            }
            let rest = word.split_off(max_chars);
            lines.push(word.into_iter().collect());
            word = rest;
        }
        let wlen = word.len();
        if len > 0 && len + 1 + wlen > max_chars {
            lines.push(std::mem::take(&mut current));
            len = 0;
        }
        if len > 0 {
            current.push(' ');
            len += 1;
        }
        current.extend(word);
        len += wlen;
    }
    if len > 0 {
        lines.push(current);
    }
    lines
}

pub struct Style {
    pub scale: i32,
    pub color: u32,
    pub bullet: bool,
}

pub fn style_for(kind: BlockKind) -> Style {
    match kind {
        BlockKind::Heading(1) => Style { scale: 4, color: 0x1C1917, bullet: false },
        BlockKind::Heading(2) => Style { scale: 3, color: 0x1C1917, bullet: false },
        BlockKind::Heading(_) => Style { scale: 2, color: 0xC2410C, bullet: false },
        BlockKind::Paragraph => Style { scale: 2, color: 0x44403C, bullet: false },
        BlockKind::ListItem => Style { scale: 2, color: 0x44403C, bullet: true },
    }
}

pub fn layout(page: &Page, width: i32, margin: i32) -> (Vec<Line>, i32) {
    let mut lines = Vec::new();
    let mut y = margin;
    for block in &page.blocks {
        let st = style_for(block.kind);
        let indent = if st.bullet { 3 * GLYPH * st.scale } else { 0 };
        let char_w = GLYPH * st.scale;
        let max_chars = ((width - 2 * margin - indent) / char_w).max(1) as usize;
        let line_h = char_w + st.scale * 4;
        for (i, para) in block.text.split('\n').enumerate() {
            for (j, text) in wrap(para, max_chars).into_iter().enumerate() {
                if st.bullet && i == 0 && j == 0 {
                    lines.push(Line { x: margin + GLYPH * st.scale, y, scale: st.scale, color: 0xEA580C, text: "»".into() });
                }
                lines.push(Line { x: margin + indent, y, scale: st.scale, color: st.color, text });
                y += line_h;
            }
        }
        y += line_h / 2;
    }
    (lines, y + margin)
}
```
:::

:::solution A render loop a main-ben
```rust
let (lines, content_height) = layout::layout(&page, WIDTH as i32, 40);
let max_scroll = (content_height - HEIGHT as i32).max(0);
let mut scroll: i32 = 0;

while window.is_open() && !window.is_key_down(Key::Escape) {
    if let Some((_, dy)) = window.get_scroll_wheel() {
        scroll -= (dy * 3.0) as i32;
    }
    if window.is_key_pressed(Key::Down, KeyRepeat::Yes) {
        scroll += 40;
    }
    if window.is_key_pressed(Key::Up, KeyRepeat::Yes) {
        scroll -= 40;
    }
    if window.is_key_pressed(Key::PageDown, KeyRepeat::Yes) || window.is_key_pressed(Key::Space, KeyRepeat::Yes) {
        scroll += HEIGHT as i32 - 80;
    }
    if window.is_key_pressed(Key::PageUp, KeyRepeat::Yes) {
        scroll -= HEIGHT as i32 - 80;
    }
    if window.is_key_pressed(Key::Home, KeyRepeat::No) {
        scroll = 0;
    }
    if window.is_key_pressed(Key::End, KeyRepeat::No) {
        scroll = max_scroll;
    }
    scroll = scroll.clamp(0, max_scroll);

    canvas.clear(rgb(0xFA, 0xFA, 0xF9));
    for line in &lines {
        let y = line.y - scroll;
        if y + 8 * line.scale < 0 || y > HEIGHT as i32 {
            continue; // nem látszik
        }
        text::draw_text(&mut canvas, line.x, y, &line.text, line.scale, line.color);
    }
    window.update_with_buffer(&canvas.pixels, WIDTH, HEIGHT).unwrap();
}
```

fn wrap(text: &str, max_chars: usize) -> Vec<String> {
    let mut lines = Vec::new();
    let mut current = String::new();
    for word in text.split(' ').filter(|w| !w.is_empty()) {
        if !current.is_empty() && current.len() + 1 + word.len() > max_chars {
            lines.push(std::mem::take(&mut current));

        if !current.is_empty() {
            current.push(' ');
