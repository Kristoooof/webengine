## Átirányítás: „máshol keresd”

Egy oldal elköltözik, egy rövid link (`bit.ly/…`) a hosszúra mutat, vagy egy űrlap elküldése után a szerver egy köszönőoldalra küld. Ilyenkor 3xx-es kód jön, és a `Location` fejléc mondja meg, hová menjünk:

```text Ábra
GET /atiranyit?hova=/masodik.html          →
                                            ←  HTTP/1.1 302 Found
                                               Location: /masodik.html
GET /masodik.html                          →
                                            ←  HTTP/1.1 200 OK
```

| Kód | Neve | Jelentés |
|---|---|---|
| 301 | Moved Permanently | Végleg elköltözött (a keresők frissítik a linket) |
| 302 | Found | Most éppen máshol van |
| 303 | See Other | Nézd meg ezt helyette (űrlap után, mindig `GET`-tel) |
| 307 | Temporary Redirect | Mint a 302, de a módszer nem változhat |
| 308 | Permanent Redirect | Mint a 301, de a módszer nem változhat |

A `304 Not Modified` is 3xx, de az nem átirányítás: azt jelenti, hogy a gyorsítótárban lévő példány még jó.

A `Location` **relatív** is lehet (`vegso.html`, `/uj/hely.html`). Ezt a **jelenlegi** címhez képest kell feloldani, pont mint egy linket: erre ott a `Url::join` a 08-03-ból. Egy átirányítás egy másik átirányításhoz is vezethet, ezért ciklusban követjük őket. Két oldal azonban egymásra is mutathat, és akkor a ciklus sosem érne véget. Ezért van **korlát**: mi legfeljebb 10 átirányítást követünk (a böngészők 20-at).

## Sütik: a szerver emlékezete

A HTTP **állapotmentes** (stateless): minden kérés önálló, a szerver nem tudja, hogy a mostani kérés ugyanattól a böngészőtől jön-e, mint az előző. Hogyan marad bejelentkezve valaki, vagy hogyan emlékszik a webshop a kosárra? **Sütikkel** (cookies):

```text Ábra
GET /suti                                  →
                                            ←  HTTP/1.1 200 OK
                                               Set-Cookie: latogatas=1; Path=/
GET /suti                                  →
Cookie: latogatas=1
                                            ←  HTTP/1.1 200 OK
                                               Set-Cookie: latogatas=2; Path=/
```

A szerver egy `Set-Cookie` fejléccel ad egy `név=érték` párt, és a böngésző a **következő** kéréseknél `Cookie` fejlécben visszaküldi. A pár után `;`-vel tulajdonságok (attributes) jöhetnek:

- **`Domain=pelda.hu`**: a süti a `pelda.hu`-nak és minden aldomainjének (`www.pelda.hu`, `bolt.pelda.hu`) jár. Ha nincs `Domain`, csak pontosan annak a gépnek (host-only). Egy oldal **nem** adhat sütit egy idegen domainnek: a `rossz.hu` nem állíthat be sütit a `bank.hu`-nak.
- **`Path=/bolt`**: csak az ez alatti útvonalaknak jár (`/bolt`, `/bolt/kosar`, de a `/boltok` nem). Ha nincs, a kért útvonal „mappája” (`/bolt/kosar.html` → `/bolt`).
- **`Max-Age=3600`**: ennyi másodpercig él. A `0` vagy negatív azonnal **törli**.
- **`Secure`**: csak titkosított (`https`) kapcsolaton megy el.
- Az `Expires`, a `HttpOnly` (a JavaScript nem látja) és a `SameSite` (más oldalról indított kéréseknél nem megy el) is létezik. Ezekkel most nem foglalkozunk.

Ugyanazzal a névvel, domainnel és útvonallal érkező új süti felülírja a régit. Ha több süti jár egy kéréshez, a hosszabb útvonalúak mennek előre: `Cookie: kosar=3; nyelv=hu`.

```rust
//! Sütik (cookies, RFC 6265): a szerver `Set-Cookie` fejléccel ad egyet, a böngésző a
//! következő kéréseknél `Cookie` fejlécben küldi vissza. Így „emlékszik” rád egy oldal.

use crate::url::Url;
use std::cmp::Reverse;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Cookie {
    pub name: String,
    pub value: String,
    pub domain: String,
    /// Ha a szerver nem adott `Domain`-t, a süti csak pontosan ennek a gépnek jár (aldomainnek nem).
    pub host_only: bool,
    pub path: String,
    /// Csak titkosított (https) kapcsolaton küldhető.
    pub secure: bool,
}

/// A gép a domainhez tartozik-e: maga a domain, vagy egy aldomainje (`www.pelda.hu` ⊂ `pelda.hu`).
pub fn domain_match(host: &str, domain: &str) -> bool {
    host == domain
        || (host.len() > domain.len()
            && host.ends_with(domain)
            && host.as_bytes()[host.len() - domain.len() - 1] == b'.')
}

/// Az útvonal a süti útvonala „alatt” van-e: a `/a` süti a `/a/b`-nek is jár, a `/ab`-nek nem.
pub fn path_match(request_path: &str, cookie_path: &str) -> bool {
    request_path == cookie_path
        || (request_path.starts_with(cookie_path)
            && (cookie_path.ends_with('/') || request_path[cookie_path.len()..].starts_with('/')))
}

/// Ha a szerver nem adott `Path`-t: a kért útvonal „mappája”, `/a/b.html` → `/a`.
fn default_path(path: &str) -> String {
    match path.rfind('/') {
        Some(0) | None => String::from("/"),
        Some(i) => path[..i].to_string(),
    }
}

#[derive(Debug, Clone, Default)]
pub struct CookieJar {
    cookies: Vec<Cookie>,
}

impl CookieJar {
    pub fn len(&self) -> usize {
        self.cookies.len()
    }

    pub fn is_empty(&self) -> bool {
        self.cookies.is_empty()
    }

    /// Egy `Set-Cookie: név=érték; Path=/; Max-Age=3600` fejléc a `url` válaszából.
    pub fn store(&mut self, url: &Url, header: &str) {
        let Some(host) = &url.host else {
            return;
        };
        let host = host.to_string();
        let mut parts = header.split(';');
        let Some((name, value)) = parts.next().and_then(|p| p.split_once('=')) else {
            return;
        };
        let mut cookie = Cookie {
            name: name.trim().to_string(),
            value: value.trim().to_string(),
            domain: host.clone(),
            host_only: true,
            path: default_path(&url.path),
            secure: false,
        };
        if cookie.name.is_empty() {
            return;
        }
        let mut delete = false;
        for attribute in parts {
            let (key, val) = attribute.split_once('=').unwrap_or((attribute, ""));
            let val = val.trim();
            match key.trim().to_ascii_lowercase().as_str() {
                "domain" => {
                    let domain = val.trim_start_matches('.').to_ascii_lowercase();
                    if domain.is_empty() {
                        continue;
                    }
                    // egy oldal nem adhat sütit egy idegen domainnek
                    if !domain_match(&host, &domain) {
                        return;
                    }
                    cookie.domain = domain;
                    cookie.host_only = false;
                }
                "path" if val.starts_with('/') => cookie.path = val.to_string(),
                "max-age" => delete = val.parse::<i64>().is_ok_and(|s| s <= 0),
                "secure" => cookie.secure = true,
                _ => {} // Expires, HttpOnly, SameSite: ezeket most nem kezeljük
            }
        }
        // ugyanaz a név, domain és útvonal: az új felülírja a régit
        self.cookies.retain(|c| {
            !(c.name == cookie.name && c.domain == cookie.domain && c.path == cookie.path)
        });
        if !delete {
            self.cookies.push(cookie);
        }
    }

    /// A `Cookie` fejléc egy kéréshez: `a=1; b=2`. Ha egy süti sem jár, `None`.
    pub fn header_for(&self, url: &Url) -> Option<String> {
        let host = url.host.as_ref()?.to_string();
        let mut matching: Vec<&Cookie> = self
            .cookies
            .iter()
            .filter(|c| {
                let host_ok = if c.host_only {
                    host == c.domain
                } else {
                    domain_match(&host, &c.domain)
                };
                host_ok && path_match(&url.path, &c.path) && (!c.secure || url.scheme == "https")
            })
            .collect();
        if matching.is_empty() {
            return None;
        }
        // a hosszabb (pontosabb) útvonalú sütik előre (RFC 6265, 5.4)
        matching.sort_by_key(|c| Reverse(c.path.len()));
        let pairs: Vec<String> = matching
            .iter()
            .map(|c| format!("{}={}", c.name, c.value))
            .collect();
        Some(pairs.join("; "))
    }
}
```

```rust
/// Egy letöltés eredménye: a végső cím (az átirányítások után) és a válasz.
#[derive(Debug)]
pub struct Fetched {
    pub url: Url,
    pub response: Response,
}

pub struct Client {
    /// Ezt a DNS-szervert kérdezzük
    pub dns: SocketAddr,
    /// A sütik egy böngészési munkamenetre (session) szólnak: a program végén elvesznek.
    pub cookies: CookieJar,
    pub max_redirects: usize,
}

impl Default for Client {
    fn default() -> Client {
        Client {
            dns: DEFAULT_DNS,
            cookies: CookieJar::default(),
            max_redirects: 10,
        }
    }
}

impl Client {
    /// Egyetlen kérés egy `http:` címre, átirányítások nélkül.
    pub fn get(&mut self, url: &Url) -> Result<Response, NetError> {
        if url.scheme != "http" {
            return Err(NetError::Unsupported(url.scheme.clone()));
        }
        let Some(host) = &url.host else {
            return Err(UrlError::BadHost(String::new()).into());
        };
        let stream = tcp::connect(host, url.port_or_default().unwrap_or(80), self.dns)?;
        let cookie = self.cookies.header_for(url);
        let extra: Vec<(&str, &str)> = cookie.iter().map(|c| ("Cookie", c.as_str())).collect();
        (&stream).write_all(http::request(url, &extra).as_bytes())?;
        let response = http::read_response(&mut BufReader::new(&stream))?;
        for header in response.headers_named("Set-Cookie") {
            self.cookies.store(url, header);
        }
        Ok(response)
    }

    /// Letöltés az átirányítások követésével. A `Location` relatív is lehet.
    pub fn fetch(&mut self, url: &Url) -> Result<Fetched, NetError> {
        let mut url = url.clone();
        for _ in 0..=self.max_redirects {
            let response = self.get(&url)?;
            match response.header("Location") {
                Some(location) if response.is_redirect() => url = url.join(location)?,
                _ => return Ok(Fetched { url, response }),
            }
        }
        Err(NetError::TooManyRedirects)
    }
}
```

## Próbáld ki itt, a kurzusban

:::exercise Milyen módszerrel tovább?
@@ feladat
Egy átirányítás után milyen módszerrel (method) menjen a következő kérés? A szabályok (a Fetch szabvány szerint):

- `301` és `302`: a `POST`-ból `GET` lesz (történelmi okból), minden más marad.
- `303`: mindig `GET`, kivéve a `HEAD`-et, ami marad.
- `307` és `308`: a módszer **nem** változik.
- Minden más kód nem átirányítás: `None`.
@@ kód
```rust
fn next_method(status: u16, method: &str) -> Option<String> {
    todo!()
}
```
@@ megoldás
```rust
fn next_method(status: u16, method: &str) -> Option<String> {
    let next = match status {
        301 | 302 if method == "POST" => "GET",
        303 if method != "HEAD" => "GET",
        301 | 302 | 303 | 307 | 308 => method,
        _ => return None,
    };
    Some(next.to_string())
}
```
@@ magyarázat
Egyetlen `match` őrfeltételekkel (`if`) mindent elintéz, foglalás csak a végén. Ha minden hívásnál egy táblázatot (`HashMap`-et) építesz, vagy több `String`-et hozol létre, az sokkal több munka ennyi döntéshez.
@@ esetek
```rust

next_method(301, "POST")
next_method(302, "POST")
next_method(302, "PUT")
next_method(303, "POST")
next_method(303, "HEAD")
next_method(307, "POST")
next_method(308, "DELETE")
next_method(304, "GET")
next_method(200, "GET")
next_method(404, "POST")
```
@@ mérés
```rust
let methods = ["GET", "POST", "HEAD", "PUT"];
let inputs: Vec<(u16, &str)> = (0..20000).map(|i| (300 + (i % 10) as u16, methods[i % 4])).collect();

```
@@ teszt-rossz
```rust
fn next_method(status: u16, method: &str) -> Option<String> {
    match status {
        301 | 302 | 303 => Some("GET".to_string()),
        307 | 308 => Some(method.to_string()),
        _ => None,
    }
}
```
@@ teszt-lassú
```rust
fn next_method(status: u16, method: &str) -> Option<String> {
    let mut table = std::collections::HashMap::new();
    for code in [301u16, 302, 303, 307, 308] {
        for m in ["GET", "POST", "HEAD", "PUT", "DELETE"] {
            let next = match (code, m) {
                (301 | 302, "POST") => "GET".to_string(),
                (303, "HEAD") => "HEAD".to_string(),
                (303, _) => "GET".to_string(),
                _ => m.to_string(),
            };
            table.insert((code, m.to_string()), next);
        }
    }
    if !table.keys().any(|(c, _)| *c == status) {
        return None;
    }
    Some(table.get(&(status, method.to_string())).cloned().unwrap_or_else(|| method.to_string()))
}
```
