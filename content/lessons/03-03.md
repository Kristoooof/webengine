:::goal
A tokenizered felismeri a kezdő- és zárótageket, kisbetűsíti a nevüket, kezeli az önzáró `/>` jelölést, és a szabvány szerint bánik az olyan furcsaságokkal, mint a `</>` vagy a `</ x>`.
:::

## Négy új állapot

A szabvány tag-állapotai a mi kódunkban (egyszerűsítve, a fontos részekkel):

| Állapot | Karakter | Teendő |
|---|---|---|
| **TagOpen** | `/` | → EndTagOpen |
| | betű | új **kezdő**tag, reconsume → TagName |
| **EndTagOpen** | betű | új **záró**tag, reconsume → TagName |
| | `>` | parse error, a `</>`-t eldobjuk → Data |
| | EOF | a `</` szöveg lesz, vége |
| | bármi más | parse error, hamis komment (*bogus comment*), reconsume → BogusComment |
| **TagName** | szóköz | → BeforeAttributeName |
| | `/` | → SelfClosingStartTag |
| | `>` | a tag kész, kibocsátjuk → Data |
| | EOF | parse error, a félkész taget eldobjuk, vége |
| | bármi más | a karakter **kisbetűsítve** a névhez adódik |
| **SelfClosingStartTag** | `>` | önzáró, kibocsátjuk → Data |
| | EOF | vége |
| | bármi más | reconsume → BeforeAttributeName |

Plusz egy ötödik, a **BogusComment**: minden karakter a kommenthez adódik, a `>` lezárja.

:::note A szóköz a HTML-ben
A tag-állapotokban a „szóköz” a 01-02-ben megismert HTML-whitespace, egy kis eltéréssel: a tokenizer a `\r`-t már nem látja, mert az előfeldolgozás `\n`-né alakította. Ezért elég négy karakter: tab, `\n`, lapdobás, szóköz.
:::

```rust
fn is_whitespace(c: char) -> bool {
    matches!(c, '\t' | '\n' | '\u{000C}' | ' ')
}
```

### Hova kerülnek az attribútumok?

Sehova, egyelőre. A szóköz után a **BeforeAttributeName** állapotba lépünk, amit a következő leckében írsz meg rendesen. Ma csak egy csonka változat kell: a szóközt átugorja, a `/`-re és a `>`-re úgy reagál, ahogy kell, minden másra pedig `todo!()`.

## A félkész tag tárolása

A tag karakterenként épül, ezért a tokenizernek tárolnia kell a „félkész” tag adatait. Új mezők:

```rust
tag_name: String,
tag_is_end: bool,
self_closing: bool,
comment: String,
```

És három segédfüggvény:

```rust
fn new_tag(&mut self, is_end: bool) {
    self.tag_name.clear();
    self.tag_is_end = is_end;
    self.self_closing = false;
}

fn emit_tag(&mut self) {
    let name = std::mem::take(&mut self.tag_name);
    let token = if self.tag_is_end {
        Token::EndTag { name }
    } else {
        Token::StartTag { name, attrs: Vec::new(), self_closing: self.self_closing }
    };
    self.emit(token);
    self.state = State::Data;
}

fn emit_comment(&mut self) {
    let c = std::mem::take(&mut self.comment);
    self.emit(Token::Comment(c));
}
```

:::compare
@@ C#
```csharp
// A "félkész token" mintája C#-ban egy StringBuilder:
var name = new StringBuilder();
name.Append(char.ToLowerInvariant(c));
var token = new StartTag(name.ToString());
name.Clear();
```
@@ Rust
```rust
self.tag_name.push(c.to_ascii_lowercase());
let name = std::mem::take(&mut self.tag_name);   // kivesszük, és üres marad
```
A `mem::take` egyszerre kiolvassa és törli: nincs másolás, és nem marad szemét a következő tagnak.
:::

```rust test
    fn start(name: &str) -> Token {
        Token::StartTag { name: name.into(), attrs: vec![], self_closing: false }
    }
    fn end(name: &str) -> Token {
        Token::EndTag { name: name.into() }
    }

    #[test]
    fn start_and_end_tags() {
        assert_eq!(tokenize("<p>Szia</p>"), vec![start("p"), text("Szia"), end("p"), Token::Eof]);
        assert_eq!(tokenize("<DIV></Div>"), vec![start("div"), end("div"), Token::Eof]);
        assert_eq!(tokenize("<h1>"), vec![start("h1"), Token::Eof]);
    }

    #[test]
    fn self_closing_and_odd_end_tags() {
        assert_eq!(
            tokenize("<br/>"),
            vec![Token::StartTag { name: "br".into(), attrs: vec![], self_closing: true }, Token::Eof]
        );
        assert_eq!(tokenize("a</>b"), vec![text("ab"), Token::Eof]);
        assert_eq!(tokenize("</ x>"), vec![Token::Comment(" x".into()), Token::Eof]);
        assert_eq!(tokenize("<p"), vec![Token::Eof]);
    }
```

:::hint
A `TagName` állapot négy ága: `Some(c) if is_whitespace(c)`, `Some('/')`, `Some('>')`, és `Some(c)` (a kisbetűsítés: `c.to_ascii_lowercase()`). Ne felejtsd el a `None => break`-et sem.
---
Az `a</>b` miért `"ab"`, egyetlen tokenként? Mert a `</>` nem bocsát ki semmit, nem is „flush”-ol, így a `b` ugyanahhoz a szöveghez adódik, mint az `a`. Ha két külön szövegtokent kapsz, valahol fölöslegesen hívsz `flush_text`-et.
---
A `</ x>`: az EndTagOpen szóközt kap, ami „bármi más”. Ilyenkor `self.comment.clear()`, reconsume, `BogusComment`. A BogusComment a szóközt és az `x`-et a kommenthez adja, a `>` pedig `emit_comment()`-tel lezárja, és vissza a Data-ba.
:::

:::solution
```rust
fn is_whitespace(c: char) -> bool {
    matches!(c, '\t' | '\n' | '\u{000C}' | ' ')
}

// ... a run() match-ében:
State::TagOpen => match c {
    Some('/') => self.state = State::EndTagOpen,
    Some(c) if c.is_ascii_alphabetic() => {
        self.new_tag(false);
        self.reconsume();
        self.state = State::TagName;
    }
    Some(_) => {
        self.text.push('<');
        self.reconsume();
        self.state = State::Data;
    }
    None => {
        self.text.push('<');
        break;
    }
},
State::EndTagOpen => match c {
    Some(c) if c.is_ascii_alphabetic() => {
        self.new_tag(true);
        self.reconsume();
        self.state = State::TagName;
    }
    Some('>') => self.state = State::Data,
    Some(_) => {
        self.comment.clear();
        self.reconsume();
        self.state = State::BogusComment;
    }
    None => {
        self.text.push_str("</");
        break;
    }
},
State::TagName => match c {
    Some(c) if is_whitespace(c) => self.state = State::BeforeAttributeName,
    Some('/') => self.state = State::SelfClosingStartTag,
    Some('>') => self.emit_tag(),
    Some(c) => self.tag_name.push(c.to_ascii_lowercase()),
    None => break,
},
State::SelfClosingStartTag => match c {
    Some('>') => {
        self.self_closing = true;
        self.emit_tag();
    }
    Some(_) => {
        self.reconsume();
        self.state = State::BeforeAttributeName;
    }
    None => break,
},
State::BeforeAttributeName => match c {
    Some(c) if is_whitespace(c) => {}
    Some('/') => self.state = State::SelfClosingStartTag,
    Some('>') => self.emit_tag(),
    Some(_) => todo!("03-04: attribútumok"),
    None => break,
},
State::BogusComment => match c {
    Some('>') => {
        self.emit_comment();
        self.state = State::Data;
    }
    Some(c) => self.comment.push(c),
    None => {
        self.emit_comment();
        break;
    }
},
```

:::why Mit jelent az önzárás a HTML-ben?
Meglepő, de a HTML-ben a `/>` szinte semmit nem jelent! A `<br/>` és a `<br>` ugyanaz, mert a `br` void elem, amúgy sincs tartalma. A `<div/>` viszont **nem** zárja le a divet: a fa-építő figyelmen kívül hagyja a `/`-t, és a div nyitva marad. Az önzárás csak az SVG-ben és a MathML-ben (az úgynevezett „foreign content”-ben) számít. A `self_closing` jelzőt azért tároljuk, mert a szabvány is tárolja, és a fa-építő ott használja. Ez az XHTML-korszak öröksége, amikor mindenki `/>`-t írt.
:::
