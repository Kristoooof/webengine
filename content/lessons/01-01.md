## let: változók, alapból állandóan

```rust
fn main() {
    let tag = "p";
    println!("A tag neve: {tag}");
}
```

A `let` változót hoz létre. A `{tag}` a `println!`-ben a változó értékét illeszti be. (Írhatnád így is: `println!("A tag neve: {}", tag);`.)

Most jön az első meglepetés. Próbáld ki ezt:

```rust
fn main() {
    let tag_count = 0;
    tag_count = tag_count + 1;
    println!("{tag_count}");
}
```

A fordító nem engedi:

```text Fordítóhiba
error[E0384]: cannot assign twice to immutable variable `tag_count`
 --> src/main.rs:3:5
  |
2 |     let tag_count = 0;
  |         --------- first assignment to `tag_count`
3 |     tag_count = tag_count + 1;
  |     ^^^^^^^^^^^^^^^^^^^^^^^^^ cannot assign twice to immutable variable
  |
help: consider making this binding mutable
  |
2 |     let mut tag_count = 0;
  |         +++
```

:::adhd Olvasd el a hibaüzenetet, mint egy levelet
A Rust hibaüzenetei **mindig** ugyanígy néznek ki: mi a baj (`error[E0384]`), hol (`src/main.rs:3:5` = 3. sor, 5. oszlop), és gyakran még azt is, **hogyan javítsd** (`help:`). Itt konkrétan megmutatja, hova kell a `mut`. Ne ijedj meg a hosszuktól: a fordító itt a tanárod.
:::

Rustban a változók **alapból nem módosíthatók**. Ha módosítani akarod, a `mut` kulcsszóval kell jelezned:

```rust
let mut tag_count = 0;
tag_count += 1;
```

:::compare Miért ilyen szigorú?
@@ C#
C#-ban minden változó alapból módosítható, és a `readonly`/`const` jelzi, ha nem. A Rust fordítva csinálja: alapból állandó, és a `mut` jelzi, ha nem.
@@ C++
C++-ban a `const` az opcionális, és könnyű elfelejteni. A Rustban a `mut` az opcionális, ezért ha egy `let mut`-ot látsz, azonnal tudod, hogy ott **valami változni fog**. Egy böngészőmotorban, ahol több szál dolgozik ugyanazon az adaton, ez aranyat ér.
@@ Python
Pythonban minden változó módosítható, és még a típusa is megváltozhat. Rustban egyik sem: a típus fix, és a módosítás engedélyhez kötött.
:::

## Alaptípusok

A Rust **statikusan típusos**, de általában kitalálja a típust (type inference). Ha akarod, ki is írhatod:

```rust
let depth: u32 = 3;          // előjel nélküli 32 bites egész
let offset: i64 = -120;      // előjeles 64 bites egész
let byte: u8 = 0x3C;         // egy bájt: 0..=255 (a 0x3C a '<' kódja)
let index: usize = 7;        // tömbindex / méret: 64 bites gépen 64 bit
let opacity: f64 = 0.75;     // lebegőpontos
let visible: bool = true;
let first: char = 'Ő';       // EGY Unicode-karakter, 4 bájton
let tag: &str = "div";       // szöveg (string slice), erről sokat beszélünk még
```

| Rust | C# | C++ | Mire jó a böngészőben |
|---|---|---|---|
| `i32`, `i64` | `int`, `long` | `int32_t`, `int64_t` | koordináták, eltolás |
| `u8` | `byte` | `uint8_t` | nyers bájtok a hálózatról, színcsatornák |
| `u32` | `uint` | `uint32_t` | egy pixel színe (0xRRGGBB) |
| `usize` | (`nint`) | `size_t` | indexek, hosszak |
| `f32`, `f64` | `float`, `double` | `float`, `double` | CSS-méretek, layout |
| `char` | `char` (de az 2 bájt!) | `char32_t` | egy karakter a szövegben |
| `bool` | `bool` | `bool` | igen/nem |

:::warn Túlcsordulás
Ha egy `u8`-hoz (max. 255) hozzáadsz annyit, hogy túlcsorduljon, a Rust **debug** módban pánikol (leáll a program). Release módban körbefordul. C++-ban az előjeles túlcsordulás „nem definiált viselkedés”, ami a biztonsági hibák klasszikus forrása. A Rust ezt nem engedi csendben megtörténni.
:::

## Shadowing: ugyanaz a név, új változó

```rust
let input = "  <p>  ";
let input = input.trim();   // új változó, ami "eltakarja" a régit
println!("[{input}]");      // [<p>]
```

Ez nem módosítás, hanem egy **új** változó ugyanazzal a névvel. Hasznos, amikor egy értéket lépésenként alakítasz, és nem akarsz `input2`, `input3` neveket kitalálni.

## Konstansok

```rust
const MAX_NESTING: usize = 512;
```

A `const` mindig nagybetűs, mindig kell neki típus, és fordítási időben ismert. Később a böngészőben így adunk meg korlátokat (pl. milyen mélyen lehetnek egymásba ágyazva az elemek).

## A nagy UTF-8-meglepetés

Itt jön a lecke legfontosabb része, egy igazi böngészős probléma:

```rust
fn main() {
    let text = "Szia, világ!";
    println!("len(): {}", text.len());
    println!("chars().count(): {}", text.chars().count());
}
```

```text
len(): 13
chars().count(): 12
```

Miért 13, ha csak 12 betű van benne? Mert a Rust a szöveget **UTF-8** kódolással tárolja, és a `len()` a **bájtok** számát adja vissza, nem a karakterekét. Az angol betűk 1 bájtot foglalnak, de az **á** 2-t. A `ő` és a `ű` is 2-t, egy emoji 4-et.

:::note Miért fontos ez a böngészőben?
A hálózatról **bájtok** jönnek, nem betűk. A böngészőnek tudnia kell, milyen kódolásban vannak (szinte mindig UTF-8), és helyesen kell karakterekké alakítania őket. Ha valahol bájtokat számolsz karakterek helyett, a magyar ékezetes szövegek pont ott fognak szétesni. A 7. modulban ezt még részletesebben megnézzük.
:::

:::task
Írd meg a `gyakorlo/src/main.rs`-be:

1. Hozz létre egy `html` változót ezzel az értékkel: `"<p>Árvíztűrő tükörfúrógép</p>"`.
2. Írd ki a hosszát bájtban és karakterben.
3. Írd ki a különbséget is („ennyi extra bájt az ékezetek miatt”).
4. Hozz létre egy `let mut tags = 0;` számlálót, növeld kétszer (a `<p>` és a `</p>` miatt), és írd ki.

Várt kimenet:

```text
Bájtok: 38
Karakterek: 29
Extra bájt az ékezetek miatt: 9
Tagek: 2
```
:::

:::hint
A különbséget egyszerűen kivonással számolhatod. Mindkét érték `usize` típusú, ezért közvetlenül kivonhatod őket egymásból: `html.len() - html.chars().count()`.
---
Számold meg az ékezetes betűket a szövegben: Á, í, ű, ő, ü, ö, ú, ó, é. Ez 9 darab, és mindegyik 1 extra bájtot jelent. Stimmel!
:::

:::solution
```rust
fn main() {
    let html = "<p>Árvíztűrő tükörfúrógép</p>";
    let bytes = html.len();
    let chars = html.chars().count();

    println!("Bájtok: {bytes}");
    println!("Karakterek: {chars}");
    println!("Extra bájt az ékezetek miatt: {}", bytes - chars);

    let mut tags = 0;
    tags += 1;
    tags += 1;
    println!("Tagek: {tags}");
}
```
:::

:::quiz
Mennyi `"ő".len()` értéke?
- [ ] 1
- [x] 2
- [ ] 4
> Az „ő” (U+0151) UTF-8-ban 2 bájt. A `len()` bájtokat számol. A `char` típus viszont mindig 4 bájtos a memóriában, mert bármelyik Unicode-karaktert el kell tudnia tárolni.
:::

:::quiz
Melyik sor fordul le?
- [ ] `let x = 5; x = 6;`
- [x] `let mut x = 5; x = 6;`
- [ ] `let x: u8 = 300;`
> Az első azért nem, mert `x` nem `mut`. A harmadik azért nem, mert a 300 nem fér el egy `u8`-ban (max. 255), és ezt a fordító már fordításkor észreveszi.
:::

:::card
K: Mit csinál a `mut` kulcsszó?
V: Módosíthatóvá teszi a változót. Rustban a változók alapból **nem** módosíthatók.
:::

:::card
K: Miért 13 a `"Szia, világ!".len()` értéke, ha csak 12 karakter?
V: Mert a `len()` **bájtokat** számol, és UTF-8-ban az „á” 2 bájt. Karaktert a `.chars().count()` számol.
:::

:::card
K: Mi a shadowing?
V: Új változó létrehozása ugyanazzal a névvel (`let x = ...; let x = ...;`). A régi „eltakaródik”. Nem módosítás, és akár más típusú is lehet.
:::
