## A HTTP: szöveg a kapcsolaton

A HTTP (HyperText Transfer Protocol) 1.1-es változata meglepően egyszerű: **olvasható szöveg**. A böngésző egy kérést ír a TCP-kapcsolatra, a szerver egy választ ír vissza. Egy kérés így néz ki:

```text Ábra
GET /cikkek/rozsda.html?lap=2 HTTP/1.1      ← kérősor: módszer, cél, változat
Host: pelda.hu                              ← fejlécek: „Név: érték”
User-Agent: Rozsda/0.3
Accept: text/html, */*
Connection: close
                                            ← üres sor: vége a fejléceknek
```

Minden sor `\r\n`-nel (CR LF, „kocsi vissza, soremelés”) végződik, a régi írógépek és telexek öröksége. A fejlécek végét egy **üres sor** jelzi. Egy `GET` kérésnek nincs törzse, ezért itt vége is.

- A **módszer** (method) megmondja, mit akarunk: `GET` (lekérés), `POST` (adatküldés, pl. egy űrlap), `HEAD` (csak a fejlécek). Mi most csak `GET`-et küldünk.
- A **cél** (request target) a URL útvonala és lekérdezése (`Url::request_target`, 08-02). A részlet (`#…`) **nem** megy el.
- A `Host` fejléc a HTTP/1.1-ben kötelező: egy IP-címen sok weboldal lakhat (virtual hosting), és a szerver ebből tudja, melyiket kérjük. Ha nem az alapértelmezett a port, az is benne van: `localhost:8080`.
- A `User-Agent` a böngésző neve. Udvarias, és a szerverek statisztikái ebből tudják, ki látogatja őket.
- A `Connection: close` azt kéri, hogy a szerver a válasz után bontsa a kapcsolatot. A HTTP/1.1 alapból **nyitva tartaná** (keep-alive), hogy a következő kérés ugyanazon menjen, de ez bonyolítja a válasz végének felismerését. Mi egyelőre minden kéréshez új kapcsolatot nyitunk.

:::compare HTTP máshol
@@ C#
A `HttpClient` ezt a szöveget írja meg helyetted. A `HttpRequestMessage.Headers` a fejlécek, a `RequestUri.PathAndQuery` a cél.
@@ C++
A libcurl ugyanígy összeállítja a szöveget, és a `CURLOPT_VERBOSE` kapcsolóval ki is írja, amit küld. Érdemes egyszer megnézni: `curl -v http://example.com/`.
@@ Python
`http.client.HTTPConnection("pelda.hu").request("GET", "/")`. A mi tesztszerverünk a `http.server`-t használja, ami a másik oldalt, a kérés olvasását csinálja.
@@ Érettségi
A HTTP a böngésző és a webszerver közötti protokoll. A `GET` és a `POST` különbsége az űrlapoknál (HTML-feladatok) is előjön.
:::

:::note A HTTP/2 és a HTTP/3
A mai nagy oldalak többsége HTTP/2-t vagy HTTP/3-at is beszél. Ezek **binárisak**, egy kapcsolaton sok kérést futtatnak párhuzamosan, a HTTP/3 pedig már nem is TCP-n, hanem UDP-n (a QUIC protokollon) megy. A jelentésük ugyanaz, mint a HTTP/1.1-é: módszer, cél, fejlécek, törzs. Minden szerver érti a HTTP/1.1-et is, ezért nekünk ez elég.
:::

## Te jössz: a kérés

:::task
Új fájl: `src/http.rs` (és `pub mod http;`).

1. `pub const USER_AGENT: &str = "Rozsda/0.3";`
2. `pub fn request(url: &Url, extra_headers: &[(&str, &str)]) -> String`: a kérősor, a négy alap fejléc (`Host`, `User-Agent`, `Accept`, `Connection`), utána az extra fejlécek (a sütiknél kell majd), és a záró üres sor.
:::

```rust test
#[cfg(test)]
mod tests {
    use super::*;

    // 08-07
    #[test]
    fn the_request_text() {
        let url = Url::parse("http://localhost:8080/oldalak/a b.html?x=1#teteje").unwrap();
        let text = request(&url, &[("Cookie", "a=1")]);
        let lines: Vec<&str> = text.split("\r\n").collect();
        assert_eq!(
            lines[0], "GET /oldalak/a%20b.html?x=1 HTTP/1.1",
            "a részlet nem megy el"
        );
        assert_eq!(lines[1], "Host: localhost:8080");
        assert!(lines.contains(&"Connection: close"));
        assert_eq!(lines[lines.len() - 3], "Cookie: a=1");
        assert!(text.ends_with("\r\n\r\n"), "üres sor zárja");
    }
}
```

:::hint
A fejléceket egy tömbbe érdemes tenni, és egy ciklusban kiírni a többiekkel együtt: `standard.iter().chain(extra_headers)`. A `chain` két iterátort fűz össze egymás után.
---
A `Host` értéke a `url.authority()` (08-02). Mivel ez egy `String`, és a tömbben `&str`-ek vannak, előbb egy változóba kell tenni: `let host = url.authority();`, és utána `("Host", host.as_str())`.
:::

:::solution
```rust
//! HTTP/1.1 (RFC 9112): a kérés szövege, és a válasz beolvasása.

use crate::url::Url;

pub const USER_AGENT: &str = "Rozsda/0.3";

/// A kérés: kérősor, fejlécek, üres sor. Egy kapcsolat, egy kérés: `Connection: close`.
pub fn request(url: &Url, extra_headers: &[(&str, &str)]) -> String {
    let mut out = format!("GET {} HTTP/1.1\r\n", url.request_target());
    let host = url.authority();
    let standard = [
        ("Host", host.as_str()),
        ("User-Agent", USER_AGENT),
        ("Accept", "text/html, */*"),
        ("Connection", "close"),
    ];
    for (name, value) in standard.iter().chain(extra_headers) {
        out.push_str(&format!("{name}: {value}\r\n"));
    }
    out.push_str("\r\n");
    out
}
```
:::

## A tesztszerver

A kipróbáláshoz kell egy szerver. A legegyszerűbb, ha a saját gépeden fut. Python mindenhol van (a 0. modulban telepítetted), és a beépített `http.server` modullal pár sorban írható egy. A miénk tud néhány trükköt is, amit a következő leckékben használunk.

Mentsd el `eszkozok/tesztszerver.py` néven a `rozsda` mappában (ez nem Rust-kód, és nem is a tananyag része: nyugodtan másold be):

```python
"""A Rozsda tesztszervere: kiszolgálja az oldalak/ mappát a saját gépeden.

Indítás a rozsda mappából:   python eszkozok/tesztszerver.py
Utána például:               http://localhost:8080/pelda.html

Különleges címek:
  /chunked/<fájl>        a fájl darabokban (Transfer-Encoding: chunked)
  /gzip/<fájl>           a fájl tömörítve (Content-Encoding: gzip)
  /atiranyit?hova=<cím>  302-es átirányítás
  /suti                  sütit ad, és megmutatja, hányadik látogatásod
"""

import gzip
import http.server
import pathlib

GYOKER = pathlib.Path(__file__).resolve().parent.parent / "oldalak"
PORT = 8080
HTML = "text/html; charset=utf-8"


class Kezelo(http.server.BaseHTTPRequestHandler):
    protocol_version = "HTTP/1.1"
    server_version = "Rozsda-tesztszerver/1.0"

    def do_GET(self):
        ut, _, lekerdezes = self.path.partition("?")
        if ut == "/atiranyit":
            hova = lekerdezes.removeprefix("hova=") or "/pelda.html"
            return self.valasz(302, b"", [("Location", hova)])
        if ut == "/suti":
            return self.suti()
        mod = ""
        for elotag in ("/chunked", "/gzip"):
            if ut.startswith(elotag + "/"):
                mod, ut = elotag, ut[len(elotag):]
        fajl = (GYOKER / ut.lstrip("/")).resolve()
        if GYOKER not in fajl.parents or not fajl.is_file():
            return self.valasz(404, "<h1>404: nincs ilyen oldal</h1>".encode(), [("Content-Type", HTML)])
        tartalom = fajl.read_bytes()
        tipus = HTML if fajl.suffix == ".html" else "application/octet-stream"
        if mod == "/gzip":
            fejlecek = [("Content-Type", tipus), ("Content-Encoding", "gzip")]
            return self.valasz(200, gzip.compress(tartalom), fejlecek)
        if mod == "/chunked":
            return self.darabokban(tartalom, tipus)
        self.valasz(200, tartalom, [("Content-Type", tipus)])

    def suti(self):
        regi = 0
        for resz in self.headers.get("Cookie", "").split(";"):
            nev, _, ertek = resz.strip().partition("=")
            if nev == "latogatas" and ertek.isdigit():
                regi = int(ertek)
        szam = regi + 1
        torzs = f"<h1>Süti</h1><p>Ez a(z) {szam}. látogatásod.</p><p><a href=\"/suti\">Még egyszer</a></p>"
        fejlecek = [("Content-Type", HTML), ("Set-Cookie", f"latogatas={szam}; Path=/")]
        self.valasz(200, torzs.encode(), fejlecek)

    def darabokban(self, tartalom, tipus):
        self.send_response(200)
        self.send_header("Content-Type", tipus)
        self.send_header("Transfer-Encoding", "chunked")
        self.send_header("Connection", "close")
        self.end_headers()
        for i in range(0, len(tartalom), 500):
            darab = tartalom[i:i + 500]
            self.wfile.write(f"{len(darab):x}\r\n".encode() + darab + b"\r\n")
        self.wfile.write(b"0\r\n\r\n")

    def valasz(self, kod, torzs, fejlecek):
        self.send_response(kod)
        for nev, ertek in fejlecek:
            self.send_header(nev, ertek)
        self.send_header("Content-Length", str(len(torzs)))
        self.send_header("Connection", "close")
        self.end_headers()
        self.wfile.write(torzs)


if __name__ == "__main__":
    print(f"Tesztszerver: http://localhost:{PORT}/pelda.html  (leállítás: Ctrl+C)")
    http.server.ThreadingHTTPServer(("127.0.0.1", PORT), Kezelo).serve_forever()
```

Indítsd el egy **külön** terminálablakban, és hagyd futni:

```powershell
python eszkozok/tesztszerver.py
```

```text Kimenet
Tesztszerver: http://localhost:8080/pelda.html  (leállítás: Ctrl+C)
```

(Ha a `python` parancsot nem találja, a Windows `py` indítója is jó: `py eszkozok/tesztszerver.py`.)

## A `letolt` program

Most írj egy kis programot, ami kapcsolódik, elküldi a kérést, és mindent kiír, ami visszajön: `crates/rozsda-net/examples/letolt.rs`. A `lib.rs`-ben a `pub use url::Url;` már megvan (08-02), így elég `rozsda_net::Url`-t írni.

```rust
//! Egy oldal letöltése nyersen: a kérés, és a szerver válasza, ahogy a TCP-n érkezik.
//! `cargo run -p rozsda-net --example letolt -- http://localhost:8080/pelda.html`

use rozsda_net::dns::DEFAULT_DNS;
use rozsda_net::{Url, http, tcp};
use std::io::{Read, Write};

fn main() {
    let Some(arg) = std::env::args().nth(1) else {
        eprintln!("használat: letolt <url>");
        std::process::exit(2);
    };
    let url = Url::parse(&arg).expect("érvényes cím kell");
    let host = url.host.as_ref().expect("a címben kell gépnév");
    let port = url.port_or_default().unwrap_or(80);
    let mut stream = tcp::connect(host, port, DEFAULT_DNS).expect("nem sikerült kapcsolódni");
    let request = http::request(&url, &[]);
    print!("{request}");
    stream
        .write_all(request.as_bytes())
        .expect("nem sikerült küldeni");
    let mut response = Vec::new();
    stream
        .read_to_end(&mut response)
        .expect("nem sikerült olvasni");
    println!("{}", String::from_utf8_lossy(&response));
}
```

A `read_to_end` addig olvas, amíg a szerver nem bontja a kapcsolatot. A `Connection: close` miatt ez a válasz után megtörténik.

    let mut out = format!("GET {target} HTTP/1.1\r\nHost: {host}\r\n");
    for (name, value) in headers {

:::card
K: Hogyan néz ki egy HTTP/1.1 kérés?
V: Kérősor (`GET /útvonal?lekérdezés HTTP/1.1`), fejlécek (`Név: érték`, köztük a kötelező `Host`), és egy üres sor. Minden sor `\r\n`-nel végződik.
