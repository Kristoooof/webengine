## Struct: mezők egy csomagban

```rust
#[derive(Debug, Clone, PartialEq)]
struct Tag {
    name: String,
    closing: bool,
    self_closing: bool,
}
```

A struct olyan, mint egy C#-os `class` vagy `struct`, de **öröklés nélkül**. Csak adatot tárol, a viselkedés külön, az `impl` blokkban van.

Létrehozás és használat:

```rust
let t = Tag {
    name: String::from("div"),
    closing: false,
    self_closing: false,
};
println!("{}", t.name);
println!("{:?}", t);    // Tag { name: "div", closing: false, self_closing: false }
println!("{:#?}", t);   // ugyanez szépen, több sorban
```

### Mit csinál a `#[derive(...)]`?

A derive automatikusan megírja helyetted a gyakori viselkedéseket:

| Derive | Mit ad | Mire kell |
|---|---|---|
| `Debug` | `{:?}` kiírás | hibakereséshez, `println!`-hez |
| `Clone` | `.clone()` | ha másolatot akarsz |
| `PartialEq` | `==` összehasonlítás | **az `assert_eq!`-hez kötelező** |

C#-ban a `record` ad hasonlót (`ToString`, `Equals`). Itt te választod ki, mit kérsz.

## impl: metódusok

```rust
impl Tag {
    // Asszociált függvény (nincs self): mint C#-ban a static. Konvenció: new
    fn new(name: &str) -> Tag {
        Tag {
            name: name.to_string(),
            closing: false,
            self_closing: false,
        }
    }

    // Metódus: az első paraméter self
    fn is_closing(&self) -> bool {
        self.closing
    }
}

let t = Tag::new("p");      // asszociált függvény: Típus::név
let c = t.is_closing();     // metódus: érték.név
```

A `self` háromféle lehet, és ez pont az előző két lecke tudása:

| Paraméter | Jelentés | Mikor |
|---|---|---|
| `&self` | Olvasásra kölcsönkapja | A leggyakoribb: lekérdezés |
| `&mut self` | Írásra kölcsönkapja | Ha módosítja a struct mezőit |
| `self` | Elviszi (move) | Ha átalakítja valami mássá |

:::tip Self: rövidítés
Az `impl Tag { ... }` blokkon belül a `Self` (nagy S) a `Tag` típust jelenti. Így írhatod azt is, hogy `fn new(name: &str) -> Self`. Ha később átnevezed a structot, nem kell mindenhol átírni.
:::

:::compare
@@ C#
```csharp
record Tag(string Name, bool Closing, bool SelfClosing) {
    public static Tag New(string name) => new(name, false, false);
    public bool IsVoid() => ...;
}
```
@@ Rust
```rust
#[derive(Debug, Clone, PartialEq)]
struct Tag { name: String, closing: bool, self_closing: bool }

impl Tag {
    fn new(name: &str) -> Self { ... }
    fn is_void(&self) -> bool { ... }
}
```
Az adat és a viselkedés külön blokkban van. Ez furcsa lehet elsőre, de később (traitekkel) nagyon hasznos lesz: egy típushoz bárhol, bármennyi `impl` blokk írható.
:::

## Void elemek

A HTML-ben néhány elemnek **soha nincs zárótagja**, és nem lehet tartalma. Ezek a *void* elemek: `<br>`, `<img>`, `<input>`, `<meta>`, `<link>`, `<hr>` és még néhány. A szabvány pontos listája:

```rust
const VOID_ELEMENTS: [&str; 13] = [
    "area", "base", "br", "col", "embed", "hr", "img",
    "input", "link", "meta", "source", "track", "wbr",
];
```

A `[&str; 13]` egy **fix méretű tömb**: 13 darab `&str`. Hogy egy elem benne van-e, azt a `.contains(&érték)` mondja meg.

## Te jössz

:::task
Hozd létre a `Tag` structot a fenti mezőkkel és derive-okkal, és írd meg az `impl` blokkot:

1. `fn new(name: &str) -> Tag`: nyitó tag, se nem záró, se nem önzáró.
2. `fn parse(src: &str) -> Tag`: egy teljes tagból (pl. `"<DIV class=\"a\">"`) készít `Tag`-et. A nevet az előző leckében írt `tag_name`-mel vedd ki, és **kisbetűsítsd** (`.to_lowercase()`), mert a HTML-tagnevek nem kis- és nagybetű-érzékenyek. Zárótag, ha `"</"`-rel kezdődik. Önzáró, ha `"/>"`-re végződik.
3. `fn is_void(&self) -> bool`: benne van-e a neve a `VOID_ELEMENTS`-ben.
4. `fn to_html(&self) -> String`: visszaalakítja HTML-lé (`<p>`, `</p>`, `<br/>`). Használd a `format!`-ot.
:::

```rust test
    #[test]
    fn tag_parse_start() {
        let t = Tag::parse("<div class=\"x\">");
        assert_eq!(t, Tag { name: "div".to_string(), closing: false, self_closing: false });
    }

    #[test]
    fn tag_parse_end_and_self_closing() {
        assert!(Tag::parse("</p>").closing);
        assert!(Tag::parse("<br/>").self_closing);
        assert_eq!(Tag::parse("<DIV>").name, "div");
    }

    #[test]
    fn tag_void() {
        assert!(Tag::new("br").is_void());
        assert!(Tag::new("img").is_void());
        assert!(!Tag::new("div").is_void());
    }

    #[test]
    fn tag_to_html() {
        assert_eq!(Tag::new("p").to_html(), "<p>");
        assert_eq!(Tag::parse("</p>").to_html(), "</p>");
        assert_eq!(Tag::parse("<br />").to_html(), "<br/>");
    }
```

:::hint
A `parse` egyetlen struct-kifejezés lehet:
```rust
Tag {
    name: /* tag_name + to_lowercase */,
    closing: src.starts_with("</"),
    self_closing: /* ... */,
}
```
---
Az `is_void`-nál a `VOID_ELEMENTS.contains(...)` egy `&&str`-t vár (referenciát egy `&str`-re). A `self.name` viszont `String`. Az `self.name.as_str()` `&str`-t ad, és ennek a referenciája kell: `VOID_ELEMENTS.contains(&self.name.as_str())`.
---
A `to_html`-ben egy `if self.closing { ... } else if self.self_closing { ... } else { ... }` lánc, mindegyik ágban egy `format!("</{}>", self.name)` jellegű kifejezéssel.
:::

:::solution
```rust
#[derive(Debug, Clone, PartialEq)]
struct Tag {
    name: String,
    closing: bool,
    self_closing: bool,
}

const VOID_ELEMENTS: [&str; 13] = [
    "area", "base", "br", "col", "embed", "hr", "img",
    "input", "link", "meta", "source", "track", "wbr",
];

impl Tag {
    fn new(name: &str) -> Tag {
        Tag {
            name: name.to_string(),
            closing: false,
            self_closing: false,
        }
    }

    fn parse(src: &str) -> Tag {
        Tag {
            name: tag_name(src).to_lowercase(),
            closing: src.starts_with("</"),
            self_closing: src.ends_with("/>"),
        }
    }

    fn is_void(&self) -> bool {
        VOID_ELEMENTS.contains(&self.name.as_str())
    }

    fn to_html(&self) -> String {
        if self.closing {
            format!("</{}>", self.name)
        } else if self.self_closing {
            format!("<{}/>", self.name)
        } else {
            format!("<{}>", self.name)
        }
    }
}
```

:::quiz
Melyik `self` kell egy olyan metódushoz, ami megváltoztatja a tag nevét?
- [ ] `&self`
- [x] `&mut self`
- [ ] `self`
> A `&mut self` írásra kölcsönkapja a structot. A `&self` csak olvasni engedi, a `self` pedig elvinné (utána a hívó nem használhatná).
:::

:::card
K: Mi a különbség az asszociált függvény és a metódus között?
V: Az asszociált függvénynek nincs `self` paramétere, és `Típus::név()` formában hívod (pl. `Tag::new`). A metódus első paramétere `self`/`&self`/`&mut self`, és `érték.név()` formában hívod.
:::

:::card
K: Mire kell a `#[derive(PartialEq)]`?
V: Hogy a típus értékeit `==`-vel össze lehessen hasonlítani. Ez kell az `assert_eq!`-hez is.
:::
