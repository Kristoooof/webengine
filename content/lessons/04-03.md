:::goal
A tokenizer megtanulja a számokat (`0`, `1.5`, `-3`, `.5`), a százalékokat (`50%`), a mértékegységes számokat (`12px`, `2em`) és az idézőjeles szövegeket (`"Comic Sans"`). A lecke végére a CSS-tokenizer kész, és az összes tokenfajtát ismeri.
:::

## A szabvány a számokról

A „Consume a token” algoritmus hiányzó ágai:

> - **számjegy**, vagy **`.` + számjegy**, vagy **`+`/`-` + számjegy**, vagy **`+`/`-` + `.` + számjegy:** fogyassz el egy **numerikus tokent**.
> - **`"` vagy `'`:** fogyassz el egy **string tokent**.

És a numerikus token (4.3.3, egyszerűsítve):

> Olvass be egy számot. Ezután:
> - ha egy **név** kezdődik, olvasd be: ez a mértékegység → *dimension* token;
> - ha **`%`** jön, fogyaszd el → *percentage* token;
> - különben → *number* token.

Egy szám így néz ki: opcionális előjel (`+` vagy `-`), számjegyek, aztán opcionálisan egy `.` és **legalább egy** számjegy. A `.` csak akkor tartozik a számhoz, ha utána számjegy jön.

| Bemenet | Tokenek |
|---|---|
| `12px` | `Dimension(12.0, "px")` |
| `1.5em` | `Dimension(1.5, "em")` |
| `50%` | `Percentage(50.0)` |
| `.5` | `Number(0.5)` |
| `-3` | `Number(-3.0)` |
| `1.` | `Number(1.0)`, `Delim('.')`: a pont után nincs számjegy |
| `-x` | `Ident("-x")`: a `-` után nem számjegy jön |

:::note A sorrend számít
A `next_token`-ben a szám-ellenőrzés a név-ellenőrzés **előtt** legyen. A `-5` esetén mindkettő a `-`-ral kezdődik, és a `starts_ident` itt hamisat adna (a `5` nem névkezdő), de egyszerűbb, ha a számot nézzük előbb. Ugyanígy: a `#1a2b3c` a `#` ágon megy, és mivel a `1` névkarakter (csak névkezdő nem), szépen `Hash("1a2b3c")` lesz belőle.
:::

## A szöveg számmá alakítása

Nem kell kézzel kiszámolnod a szám értékét. Gyűjtsd össze a számhoz tartozó karaktereket, és a Rust beépített parse-olója megcsinálja:

```rust
let text: String = self.chars[start..self.pos].iter().collect();
text.parse().unwrap_or(0.0)
```

A `parse()` a visszatérési típusból (itt `f32`) tudja, mire kell alakítania. A `"+2"`, a `"-0.5"` és a `"007"` is működik vele.

:::compare Szöveg → szám
@@ C#
`float.Parse("1.5", CultureInfo.InvariantCulture)`: C#-ban a kulturális beállítás miatt a magyar Windows `1,5`-öt várna! A Rust `parse()`-a mindig pontot vár, nincs ilyen csapda.
@@ Python
`float("1.5")`. Hiba esetén `ValueError` kivételt dob. A Rust `parse()` egy `Result`-ot ad, amit itt `unwrap_or(0.0)`-val kezelünk.
@@ C++
`std::stof("1.5")`, ami hibánál kivételt dob, vagy `std::from_chars`, ami nem.
@@ Érettségi
Ugyanaz, mint az `int(sor[2])` vagy a `double.Parse(...)` egy fájl beolvasásakor, csak itt a „mező” határát nekünk kell megtalálni.
:::

## Stringek

A string tokent idézőjel nyitja (`"` vagy `'`), és **ugyanolyan** idézőjel zárja. A másik fajta idézőjel a belsejében sima karakter: `"Rozsda's"`. A visszaper (`\`) a következő karaktert „szó szerint” veszi: `'a\'b'` → `a'b`.

:::warn Egyszerűsítés
A szabvány szerint a `\` után hexadecimális kód is jöhet (`"\2764"` → ❤), és a sortörés egy le nem zárt stringben „bad-string” hibát ad. Mi ezeket kihagyjuk: a `\` után álló karaktert vesszük, és a le nem zárt string a fájl végéig tart. A 16. modul profi parsere mindent tud majd.
:::

## Te jössz

:::task
A `Tokenizer`-be:

1. `starts_number(&self) -> bool`: a fenti négy eset valamelyike áll-e az aktuális pozíción.
2. `consume_number(&mut self) -> f32`: előjel, számjegyek, opcionálisan `.` + számjegyek, aztán `parse`.
3. `consume_numeric(&mut self) -> Token`: szám, utána név → `Dimension`, `%` → `Percentage`, különben `Number`.
4. `consume_string(&mut self, quote: char) -> Token`: a nyitó idézőjel már elfogyott, olvass a záróig (vagy a végéig), a `\` utáni karaktert szó szerint vedd.
5. A `next_token`-ben: a szóközök után jöjjön az `if self.starts_number()` ág, a `match`-be pedig a `'"' | '\''` ág.
:::

        assert_eq!(tokenize("\"nyitva"), vec![Str("nyitva".into())]);

:::hint
A `starts_number`-ben egy kis closure sokat egyszerűsít:
```rust
let digit = |c: Option<char>| c.is_some_and(|c| c.is_ascii_digit());
```
Így a négy eset egy `match self.peek(0)` három ágában elfér: `Some('+' | '-')`, `Some('.')`, és minden más (`c => digit(c)`).
---
A `consume_number` először megjegyzi, hol kezdődik (`let start = self.pos;`), aztán három lépés: ha `+` vagy `-` jön, lépj egyet. Amíg számjegy jön, lépj. Ha `.` jön **és** utána számjegy, lépj a ponton, és megint amíg számjegy jön. A végén a `self.chars[start..self.pos]` a teljes szám.
---
A `consume_string`-ben a ciklus minden kört egy `self.pos += 1`-gyel kezd (a karakter elfogyott). Ha a karakter a záró idézőjel, `break`. Ha `\`, akkor a **következő** karaktert tedd a szövegbe (ha van), lépj még egyet, és `continue`. Különben `s.push(c)`.
:::

:::solution
```rust
    /// Egy szám kezdődik-e az aktuális pozíción? (`5`, `.5`, `-5`, `+.5`)
    fn starts_number(&self) -> bool {
        let digit = |c: Option<char>| c.is_some_and(|c| c.is_ascii_digit());
        match self.peek(0) {
            Some('+' | '-') => {
                digit(self.peek(1)) || (self.peek(1) == Some('.') && digit(self.peek(2)))
            }
            Some('.') => digit(self.peek(1)),
            c => digit(c),
        }
    }

    fn consume_number(&mut self) -> f32 {
        let start = self.pos;
        if matches!(self.peek(0), Some('+' | '-')) {
            self.pos += 1;
        }
        while self.peek(0).is_some_and(|c| c.is_ascii_digit()) {
            self.pos += 1;
        }
        if self.peek(0) == Some('.') && self.peek(1).is_some_and(|c| c.is_ascii_digit()) {
            self.pos += 1;
            while self.peek(0).is_some_and(|c| c.is_ascii_digit()) {
                self.pos += 1;
            }
        }
        let text: String = self.chars[start..self.pos].iter().collect();
        text.parse().unwrap_or(0.0)
    }

    fn consume_numeric(&mut self) -> Token {
        let n = self.consume_number();
        if self.starts_ident() {
            Token::Dimension(n, self.consume_name())
        } else if self.peek(0) == Some('%') {
            self.pos += 1;
            Token::Percentage(n)
        } else {
            Token::Number(n)
        }
    }

    /// A nyitó idézőjel már elfogyott.
    fn consume_string(&mut self, quote: char) -> Token {
        let mut s = String::new();
        while let Some(c) = self.peek(0) {
            self.pos += 1;
            if c == quote {
                break;
            }
            if c == '\\' {
                if let Some(next) = self.peek(0) {
                    s.push(next);
                    self.pos += 1;
                }
                continue;
            }
            s.push(c);
        }
        Token::Str(s)
    }
```

:::why Miért nincs `1e3`?
A CSS-ben a tudományos jelölés is érvényes: `1e3px` = 1000 pixel. A valóságban szinte senki nem használja, és van egy csapdája: az `1em` nem 1·10ᵐ, hanem 1 em! A szabvány szerint az `e` csak akkor kitevő, ha utána számjegy (vagy előjel és számjegy) jön. Ha kedved van, egészítsd ki a `consume_number`-t: az `1e3` legyen `Number(1000.0)`, az `1em` maradjon `Dimension(1.0, "em")`.

fn parse_number_prefix(s: &str) -> Option<(f32, usize)> {
    let b = s.as_bytes();
    let mut i = 0;
    if matches!(b.first(), Some(b'+' | b'-')) {
        i += 1;
    }
    let int_start = i;
    while i < b.len() && b[i].is_ascii_digit() {
        i += 1;
    }
    let mut digits = i - int_start;
    if i + 1 < b.len() && b[i] == b'.' && b[i + 1].is_ascii_digit() {
        i += 1;
        let frac_start = i;
        while i < b.len() && b[i].is_ascii_digit() {
            i += 1;
        }
        digits += i - frac_start;
    }
    if digits == 0 {
        return None;
    }
    s[..i].parse().ok().map(|n| (n, i))
}

fn parse_number_prefix(s: &str) -> Option<(f32, usize)> {
    let chars: Vec<char> = s.chars().collect();
    let mut text = String::new();
    let mut i = 0;
    if i < chars.len() && (chars[i] == '+' || chars[i] == '-') {
        text.push(chars[i]);
        i += 1;
    }
    let mut digits = 0;
    while i < chars.len() && chars[i].is_ascii_digit() {
        text.push(chars[i]);
        i += 1;
        digits += 1;
    }
    if i + 1 < chars.len() && chars[i] == '.' && chars[i + 1].is_ascii_digit() {
        text.push('.');
        i += 1;
        while i < chars.len() && chars[i].is_ascii_digit() {
            text.push(chars[i]);
            i += 1;
            digits += 1;
        }
    }
    if digits == 0 {
        return None;
    }
    let n: f32 = text.clone().parse().ok()?;
    Some((n, text.chars().count()))
