:::goal
Megtanítod a raszterizálót az **átlátszóságra**. Egy félig átlátszó szín nem felülírja a pixelt, hanem **keveredik** vele (alpha blending). A lecke végén az `rgba()` színek áttetszők lesznek, és a raszterizáló minden parancsnál figyel az átlátszóságra.
:::

## Mi az alfa?

A CSS-parser már a 4. modulban tudta az `rgba(194, 65, 12, 0.5)` színt, és a `Color` negyedik mezőjébe (`a`, alpha) el is tette: 0 a teljesen átlátszó, 255 a teljesen fedő. A raszterizáló viszont eddig csak a `to_u32()`-t kérte el, ami az alfát eldobja. Ezért minden szín fedő volt.

Az átlátszó festék úgy működik, mint egy színes üveg: a mögötte lévő szín átlátszik rajta. Csatornánként egy **súlyozott átlag**:

```text Ábra
új = felső · α + alsó · (1 − α)        (α = a / 255, 0 és 1 között)

fehér háttér (255) + 50%-os piros (255, 0, 0):
  r = 255 · 0.5 + 255 · 0.5 = 255
  g =   0 · 0.5 + 255 · 0.5 = 127.5
  b =   0 · 0.5 + 255 · 0.5 = 127.5   → rózsaszín
```

Ez a Porter–Duff-féle **„source over”** művelet (1984), és szinte minden grafikus rendszer alapértelmezése.

:::compare Átlátszóság
@@ CSS
```css
.arnyek { background: rgba(0, 0, 0, 0.2); }   /* 20%-os fekete */
.kiemeles { background: #c2410c26; }          /* 8 jegyű hexa: 26 = 38/255 ≈ 15% (a Rozsda még nem ismeri) */
```
@@ C#
`Color.FromArgb(128, 255, 0, 0)`: az első szám az alfa. A WPF és a WinForms is „source over” módon keveri.
@@ Python
A Pillow `Image.alpha_composite(alul, felul)` ugyanezt csinálja képekkel.
@@ Érettségi
Ez egy **súlyozott átlag** két szám között, ahol a súlyok összege 1. Egész számokkal: `(felső · a + alsó · (255 − a)) / 255`.
:::

## Egész számokkal, kerekítve

Pixelenként nem akarunk `f32`-vel számolni, mert lassú, és a kerekítés is kérdéses. Az egész változat:

```text Ábra
(felső · a + alsó · (255 − a) + 127) / 255
```

A `+ 127` a kerekítés: egész osztásnál a Rust lefelé kerekít, és ha előtte hozzáadjuk az osztó felét, a legközelebbi egészet kapjuk. (Ugyanez a trükk: `(x + 50) / 100` kerekít százasokra.)

A pixel `0x00RRGGBB` alakú. A csatornákat eltolással és maszkolással szedjük ki: `(dst >> 16) & 0xFF` a piros, `(dst >> 8) & 0xFF` a zöld, `dst & 0xFF` a kék.

:::hint
A `blend` három `mix` hívás. A piros csatorna:
```rust
let a = color.a as u32;
let r = mix(color.r as u32, (dst >> 16) & 0xFF, a);
```
A végén vissza a helyükre: `(r << 16) | (g << 8) | b`.
---
A `fill_rect` belső ciklusában egy `&mut` referencia a pixelre kényelmes:
```rust
let p = &mut self.pixels[py as usize * self.width + px as usize];
*p = if color.a == 255 {
    opaque
} else {
    blend(*p, color)
};
```
Az `opaque`-ot (`color.to_u32()`) a ciklus **előtt** számold ki, ne minden pixelnél.
---
Az `if` Rustban kifejezés: az értéke a nyertes ág utolsó kifejezése. Ezért írhatod így: `*p = if … { opaque } else { blend(*p, color) };`. C#-ban ez a `? :` operátor lenne.
:::

:::solution
```rust
use rozsda_core::style::Color;

/// Egy képernyőnyi pixel: 0x00RRGGBB színek, soronként egymás után.
pub struct Canvas {
    pub width: usize,
    pub height: usize,
    pub pixels: Vec<u32>,
}

/// Egy színcsatorna keverése: `a/255` arányban a felső, a többi az alsó.
fn mix(top: u32, bottom: u32, a: u32) -> u32 {
    (top * a + bottom * (255 - a) + 127) / 255
}

/// A `color` ráfestése a `dst` pixelre, az átlátszóságát figyelembe véve ("source over").
pub fn blend(dst: u32, color: Color) -> u32 {
    let a = color.a as u32;
    let r = mix(color.r as u32, (dst >> 16) & 0xFF, a);
    let g = mix(color.g as u32, (dst >> 8) & 0xFF, a);
    let b = mix(color.b as u32, dst & 0xFF, a);
    (r << 16) | (g << 8) | b
}

impl Canvas {
    pub fn new(width: usize, height: usize) -> Canvas {
        Canvas {
            width,
            height,
            pixels: vec![0; width * height],
        }
    }

    pub fn clear(&mut self, color: u32) {
        for p in self.pixels.iter_mut() {
            *p = color;
        }
    }

    /// Téglalap kitöltése, a vászonra vágva. Az átlátszó szín keveredik az alatta lévővel.
    pub fn fill_rect(&mut self, x: i32, y: i32, w: i32, h: i32, color: Color) {
        if color.a == 0 {
            return;
        }
        let opaque = color.to_u32();
        let x0 = x.max(0);
        let y0 = y.max(0);
        let x1 = (x + w).min(self.width as i32);
        let y1 = (y + h).min(self.height as i32);
        for py in y0..y1 {
            for px in x0..x1 {
                let p = &mut self.pixels[py as usize * self.width + px as usize];
                *p = if color.a == 255 {
                    opaque
                } else {
                    blend(*p, color)
                };
            }
        }
    }
}
```

```rust
/// A keret négy téglalap, a doboz négy szélén. Nem fedhetik egymást, különben
/// egy átlátszó keret sarkai kétszer kapnának festéket.
fn border(canvas: &mut Canvas, r: Rect, w: Sides<f32>, scroll: i32, color: Color) {
    fill(canvas, Rect { height: w.top, ..r }, scroll, color);
    let bottom = Rect {
        y: r.bottom() - w.bottom,
        height: w.bottom,
        ..r
    };
    fill(canvas, bottom, scroll, color);
    // a két oldalsó csak a felső és az alsó között
    let middle = Rect {
        y: r.y + w.top,
        height: r.height - w.top - w.bottom,
        ..r
    };
    let left = Rect {
        width: w.left,
        ..middle
    };
    fill(canvas, left, scroll, color);
    let right = Rect {
        x: r.right() - w.right,
        width: w.right,
        ..middle
    };
    fill(canvas, right, scroll, color);
}
```

:::why Előre szorzott alfa
A profi grafikus könyvtárak (Skia, WebRender, tiny-skia) a színeket **előre szorzott** (premultiplied) alakban tárolják: a csatornákat már eleve megszorozzák az alfával. Egy 50%-os piros így nem `(255, 0, 0, 128)`, hanem `(128, 0, 0, 128)`. Ettől a keverés egyszerűbb lesz (`új = felső + alsó · (1 − α)`, egy szorzással kevesebb), és ami fontosabb: átméretezésnél és elmosásnál nem keletkeznek sötét szegélyek az átlátszó részek körül. A mi vásznunk mindig fedő (a háttér kitölti), ezért nekünk elég az egyszerű képlet.
:::

```rust
fn blend(dst: u32, r: u8, g: u8, b: u8, a: u8) -> u32 {
    let hex = format!("{:06x}", dst);
    let channel = |i: usize| u32::from_str_radix(&hex[i..i + 2], 16).unwrap() as f64;
    let alpha = a as f64 / 255.0;
    let mix = |top: u8, bottom: f64| (top as f64 * alpha + bottom * (1.0 - alpha)).round() as u32;
    let nr = mix(r, channel(0));
    let ng = mix(g, channel(2));
    let nb = mix(b, channel(4));
    (nr << 16) | (ng << 8) | nb
}
```
