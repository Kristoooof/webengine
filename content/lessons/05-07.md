## Ahol a szöveg lakik

A 05-04-ben minden olyan blokk, aminek csak inline gyereke van, kapott egy `inline_nodes` listát: a DOM-csomópontokat, amik a sorait adják. Egy `<p>Szia <b>Rozsda</b>!</p>` esetén ez három csomópont: `"Szia "`, `<b>` és `"!"`.

A sorokba tördeléshez (05-08) ebből két lépésben jutunk el:

```text Ábra
DOM-csomópontok ──► futamok (runs) ──► szavak (items) ──► sorok (05-08)
"Szia ", <b>, "!"   "Szia " (p)        Szia

```

## 1. lépés: futamok

A **futam** (run) egy darab szöveg, és mellette az elem, amelyiknek a stílusával meg kell jelennie. A fát mélységi bejárással laposítjuk ki, rekurzióval, mint a 3. modul `dump()`-ja:

- **szöveg-csomópont** → egy futam. A stílus a **szülőé**, mert a szöveg-csomópontnak nincs saját stílusa: a `"Rozsda"` a `<b>` stílusával jelenik meg.
- **`<br>`** → egy `Break` futam: itt kötelező sortörés lesz.
- **`display: none` elem** → semmi, a gyerekeivel együtt.
- **minden más elem** → a gyerekei, sorban.

```rust
/// Egy darab szöveg, és az elem, amelyiknek a stílusával meg kell jelennie.
#[derive(Debug, Clone, PartialEq)]
pub enum Run {
    Text { text: String, node: NodeId },
    Break,
}

/// Az inline tartalom szövegdarabjai, dokumentum-sorrendben.
pub fn collect_runs(doc: &Document, styles: &StyleMap, nodes: &[NodeId]) -> Vec<Run> {
    let mut out = Vec::new();
    for &node in nodes {
        let parent = doc.parent(node).unwrap_or(node);
        collect(doc, styles, node, parent, &mut out);
    }
    out
}

fn collect(doc: &Document, styles: &StyleMap, id: NodeId, styled: NodeId, out: &mut Vec<Run>) {
    match &doc.node(id).data {
        NodeData::Text(t) => out.push(Run::Text {
            text: t.clone(),
            node: styled,
        }),
        NodeData::Element(e) => {
            if styles.get(id).is_some_and(|s| s.display == Display::None) {
                return;
            }
            if e.name == "br" {
                out.push(Run::Break);
                return;
            }
            for &child in doc.children(id) {
                collect(doc, styles, child, id, out);
            }
        }
        _ => {}
    }
}
```

A `styled` paraméter viszi le a fában, kinek a stílusa érvényes. Amikor egy elembe lépünk, az elem lesz a `styled` a gyerekei számára (`collect(doc, styles, child, id, out)`).

## 2. lépés: a szóközök összevonása

Írd be egy HTML-fájlba:

```html
<p>  Ez   egy
     mondat.  </p>
```

A böngésző ezt írja ki: „Ez egy mondat.” A HTML-ben (pontosabban a CSS `white-space: normal` beállításánál) a szóköz-karakterek **sorozata** egyetlen szóközzé olvad, a sor elején és végén pedig eltűnik. Ezért tagolhatod a HTML-t szabadon, behúzással és sortörésekkel.

:::compare Szóköz-összevonás
@@ Python
```python
" ".join("  Ez   egy\n  mondat.  ".split())
# 'Ez egy mondat.'
```
@@ C#
```csharp
string.Join(" ", s.Split((char[])null, StringSplitOptions.RemoveEmptyEntries));
```
@@ Rust
```rust
s.split_whitespace().collect::<Vec<_>>().join(" ")
```
De vigyázz: a `split_whitespace` a Unicode összes szóközét eldobja, a nem törő szóközt (U+00A0, `&nbsp;`) is. A CSS-ben az **nem** olvad össze, ezért írtuk meg a saját `is_space`-ünket (05-04).
@@ Érettségi
Ez a klasszikus „szóközök összevonása” feladat: egy állapotváltozó jegyzi, hogy az előző karakter szóköz volt-e.
:::

Mi viszont nem egy összevont szöveget akarunk, hanem **szavakat**, és mindegyik mellé egy jelzést: volt-e előtte szóköz (`space_before`). A szóköz szélessége ugyanis a stílustól függ (05-08), és a sor elején el kell tűnnie. Ezt csak a tördelő tudja, nem mi.

## Szavak, amik átnyúlnak

```html
<p>Szia<b>Rozsda</b>!</p>
```

Itt nincs szóköz: ez **egy szó**, ami három elemen nyúlik át. Nem szabad közte sort törni, de a darabjai más stílussal jelennek meg. Ezért egy szó **darabok** (pieces) listája:

```rust
/// Egy szó egy darabja: egy szó több elemen is átnyúlhat (`Szia<b>Rozsda</b>`).
#[derive(Debug, Clone, PartialEq)]
pub struct Piece {
    pub text: String,
    pub node: NodeId,
}

#[derive(Debug, Clone, PartialEq)]
pub enum Item {
    Word {
        pieces: Vec<Piece>,
        space_before: bool,
    },
    Break,
}
```

A tesztekben egy rövid jelölést használunk: `_` a szóköz előtte, `|` a darabok határa, `⏎` a sortörés. A fenti példa: `Szia|Rozsda|!`.

```rust test
        let p = doc.find_first("p").unwrap();

    fn words(items: &[Item]) -> Vec<String> {
```

```rust
fn finish_word(items: &mut Vec<Item>, word: &mut Vec<Piece>, space_before: bool) {
    if !word.is_empty() {
        items.push(Item::Word {
            pieces: std::mem::take(word),
            space_before,
        });
    }
}

/// Szavakra bontás, a szóközök összevonásával: a szóközök sorozatából egyetlen
/// „szóköz előtte” jelzés lesz, a sor eleji és végi szóköz pedig eltűnik.
pub fn split_words(runs: &[Run]) -> Vec<Item> {
    let mut items = Vec::new();
    let mut word: Vec<Piece> = Vec::new();
    let mut space_before = false;
    let mut pending_space = false;
    for run in runs {
        match run {
            Run::Break => {
                finish_word(&mut items, &mut word, space_before);
                items.push(Item::Break);
                pending_space = false;
            }
            Run::Text { text, node } => {
                for c in text.chars() {
                    if is_space(c) {
                        // a legelső szó előtti szóköz nem számít
                        if !items.is_empty() || !word.is_empty() {
                            pending_space = true;
                        }
                        finish_word(&mut items, &mut word, space_before);
                        continue;
                    }
                    if word.is_empty() {
                        space_before = pending_space;
                        pending_space = false;
                    }
                    match word.last_mut() {
                        Some(piece) if piece.node == *node => piece.text.push(c),
                        _ => word.push(Piece {
                            text: c.to_string(),
                            node: *node,
                        }),
                    }
                }
            }
        }
    }
    finish_word(&mut items, &mut word, space_before);
    items
}
```

:::why A `white-space` többi értéke
A `white-space: pre` (a `<pre>` alapértéke) épp az ellenkezője: minden szóköz és sortörés megmarad, és nincs automatikus tördelés. A `pre-wrap` megtartja a szóközöket, de tördel; a `nowrap` összevon, de nem tördel. A szabvány egy egész fejezetet szán erre (*CSS Text Module Level 3*, „White Space Processing”), és még a sorvégi szóközök „lógását” (*hanging*) is szabályozza.

A Rozsda egyelőre csak a `normal`-t tudja. Ezért a `<pre>` kódblokkjai is összevont szóközökkel jelennek meg. A kódblokkokhoz egy fix szélességű (monospace) betűtípus is kell, ezért ezt a 14. modulban, a modern CSS mellett pótoljuk.
:::

```rust
fn split_words(runs: &[(&str, char)]) -> Vec<String> {
    let mut chars: Vec<(char, char)> = Vec::new();
    for &(text, element) in runs {
        for c in text.chars() {
            chars.push((c, element));
        }
    }
    let mut words: Vec<String> = Vec::new();
    let mut i = 0;
    while i < chars.len() {
        if is_space(chars[i].0) {
            i += 1;
            continue;
        }
        let space = i > 0 && is_space(chars[i - 1].0) && !words.is_empty();
        let mut word = if space { "_".to_string() } else { String::new() };
        let mut j = i;
        while j < chars.len() && !is_space(chars[j].0) {
            if j > i && chars[j].1 != chars[j - 1].1 {
                word = format!("{}|", word);
            }
            word = format!("{}{}", word, chars[j].0);
            j += 1;
        }
        words.push(word);
        i = j;
    }
    words
}
```
