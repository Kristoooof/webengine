## Modulok

Rustban a **modul** (`mod`) egy névtér, ami csoportosítja a kódot. Minden modul egy fájl (vagy egy fájlon belüli blokk).

```text
gyakorlo/
├── Cargo.toml
└── src/
    ├── main.rs       ← a futtatható program (bináris crate gyökere)
    ├── lib.rs        ← a könyvtár (library crate gyökere)
    ├── alap.rs       ← is_html_whitespace, strip_tags, tag_name, …
    ├── tag.rs        ← Tag, TagError, parse_tag
    ├── token.rs      ← Token
    ├── cursor.rs     ← Cursor
    └── elemzes.rs    ← text_content, tag_counts, element_names
```

A `lib.rs` megmondja, milyen modulok vannak:

```rust
// src/lib.rs
pub mod alap;
pub mod cursor;
pub mod elemzes;
pub mod tag;
pub mod token;
```

A `pub mod alap;` azt jelenti: *„van egy `alap` modul, keresd a `src/alap.rs`-ben, és legyen kívülről is látható”*.

## Láthatóság: pub

Rustban **minden alapból privát**: a modulon kívülről nem látszik. Ami kell kívülről, azt `pub`-bal kell megjelölni:

```rust
// src/tag.rs
pub struct Tag {
    pub name: String,        // a mezők is külön pub-ot kapnak!
    pub closing: bool,
    pub self_closing: bool,
}

impl Tag {
    pub fn new(name: &str) -> Tag { /* ... */ }
    pub fn parse(src: &str) -> Tag { /* ... */ }
}
```

:::compare
@@ C#
```csharp
namespace Gyakorlo.Tag;
public class Tag {
    public string Name { get; }
    internal bool Closing;   // csak az assemblyn belül
}
```
C#-ban a `public`/`internal`/`private` hasonló. A Rust `pub(crate)` kb. az `internal`.
@@ Rust
```rust
// tag.rs maga a "namespace"
pub struct Tag {
    pub name: String,
    pub(crate) closing: bool,   // csak a crate-en belül
}
```
:::

## Más modulok használata: use

```rust
// src/token.rs
use crate::tag::Tag;            // a crate gyökeréből: crate::modul::elem
use std::collections::HashMap;  // a standard könyvtárból

pub enum Token { /* ... */ }

impl Token {
    pub fn from_tag(tag: Tag) -> Token { /* ... */ }
}
```

- `crate::` = a saját crate-ed gyökere (a `lib.rs`).
- `super::` = a szülő modul (ezért volt a tesztekben `use super::*;`).
- `std::` = a standard könyvtár.

A tesztek a saját moduljukkal együtt költöznek: a `tag.rs` aljára kerülnek a `Tag` tesztjei, a `cursor.rs` aljára a `Cursor` tesztjei.

## Bináris és könyvtár egy csomagban

Ha egy csomagban `main.rs` **és** `lib.rs` is van, a Cargo két crate-et fordít: egy könyvtárat (`gyakorlo`) és egy programot, ami azt használja:

```rust
// src/main.rs
use gyakorlo::tag::Tag;
use gyakorlo::token::Token;

fn main() {
    let t = Token::from_tag(Tag::parse("<p>"));
    println!("{}", t.describe());
}
```

A `main.rs` kívülről használja a könyvtárat, ezért csak a `pub` dolgokat látja. Pont úgy, ahogy később a `rozsda-browser` fogja használni a `rozsda-html`-t.

## Külső crate-ek: crates.io

A [crates.io](https://crates.io) a Rust csomagtára, több mint 150 000 crate-tel. Egy crate hozzáadása:

```powershell
cargo add owo-colors
```

Ez beírja a `Cargo.toml`-ba:

```toml
[dependencies]
owo-colors = "4.4.0"
```

A `"4.4.0"` valójában `^4.4.0`-t jelent: bármelyik `4.x.y` verzió jó, ami legalább `4.4.0`. Ez a **semver**: a főverzió (4) változása jelzi a nem kompatibilis változást. A pontosan használt verziókat a `Cargo.lock` rögzíti. Ezt is commitold, hogy jövő héten is ugyanaz forduljon le.

:::tip docs.rs
Minden crate dokumentációja automatikusan megjelenik a [docs.rs](https://docs.rs) oldalon. Ha egy crate-et használsz, nyisd meg a `docs.rs/<crate-név>` oldalt: ott vannak a példák és az összes típus.
:::

:::warn Óvatosan a függőségekkel
Minden crate idegen kód, ami a gépeden fut. Mielőtt hozzáadsz egyet, nézd meg: hányan töltik le, mikor frissült utoljára, van-e repója. A Rozsdában a **saját** implementációkhoz szándékosan szinte semmit nem fogunk használni, a **profi** oldalon viszont jól bevált, sokak által használt crate-ek jönnek.
:::

## Te jössz

:::task
1. Hozd létre a fenti fájlszerkezetet, és költöztesd át a kódot (a teszteket is) a megfelelő fájlokba.
2. Tegyél `pub`-ot mindenhova, ahol a fordító kéri. Olvasd el a hibaüzeneteket, pontosan megmondják, mi nem látszik.
3. A modulok közötti hivatkozásokat oldd meg `use crate::...`-tal (pl. a `tag.rs`-nek kell a `tag_name` az `alap.rs`-ből).
4. `cargo add owo-colors`, és írd meg a `main`-t: írjon ki néhány tokent **színesen** (kezdőtag zölden, zárótag pirosan, komment halványan).
:::

Egy lehetséges `main.rs`:

```rust
use gyakorlo::tag::Tag;
use gyakorlo::token::Token;
use owo_colors::OwoColorize;

fn main() {
    let tokens = vec![
        Token::from_tag(Tag::parse("<p>")),
        Token::Text(String::from("Szia, Rozsda!")),
        Token::Comment(String::from(" ez egy komment ")),
        Token::from_tag(Tag::parse("</p>")),
    ];
    for t in &tokens {
        match t {
            Token::StartTag { .. } => println!("{}", t.describe().green()),
            Token::EndTag { .. } => println!("{}", t.describe().red()),
            Token::Text(_) => println!("{}", t.describe()),
            Token::Comment(_) => println!("{}", t.describe().dimmed()),
        }
    }
}
```

:::hint
Ha a fordító azt írja, hogy `error[E0603]: struct `Tag` is private` vagy `function ... is private`, akkor hiányzik egy `pub`. Ha azt, hogy `cannot find type `Tag` in this scope`, akkor a fájl tetejéről hiányzik egy `use crate::tag::Tag;`.
---
A struct-mezőkhöz is kell `pub`, ha egy másik modul közvetlenül olvassa őket. A `token.rs` `from_tag` függvénye például a `tag.name`-et olvassa.
---
A teszteknek nem kell `pub`, mert a `mod tests` a modul *belsejében* van. Ott a `use super::*;` mindent lát, a privát dolgokat is.
:::
