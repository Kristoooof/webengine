:::goal
Megírod a CSS-tokenizer motorját: egy `Tokenizer` structot, ami karakterről karakterre halad, kihagyja a kommenteket, és kiadja a neveket, a függvényneveket, a `#`- és `@`-szavakat és az írásjeleket. A lecke végére a `tokenize("p { color: red; }")` már helyes tokenlistát ad.
:::

## Mit mond a szabvány?

A CSS Syntax Level 3 szabvány 4.3.1-es része, a **„Consume a token”** algoritmus. Magyarul, a mai leckéhez szükséges részekre szűkítve:

> **Egy token elfogyasztása.** Fogyaszd el a kommenteket. Utána fogyaszd el a következő karaktert:
> - **szóköz:** fogyaszd el az összes utána következő szóközt is, és adj ki egy *whitespace* tokent.
> - **`#`:** ha utána névkarakter jön, olvasd be a nevet, és adj ki egy *hash* tokent. Különben *delim* token.
> - **`(` `)` `,` `:` `;` `{` `}`:** a megfelelő egykarakteres token.
> - **`@`:** ha utána név kezdődik, olvasd be, és adj ki egy *at-keyword* tokent. Különben *delim*.
> - **névkezdő karakter:** olvasd be a nevet. Ha rögtön `(` jön utána, fogyaszd el, és adj ki egy *function* tokent, különben egy *ident* tokent.
> - **EOF:** vége.
> - **bármi más:** *delim* token ezzel az egy karakterrel.

A számok és a stringek a következő leckében jönnek.

## Nincs állapotgép?

A HTML-tokenizer egy 20 állapotú állapotgép volt, mert a HTML-ben ugyanaz a karakter mást jelent attól függően, hol vagy (egy `<` a szövegben, egy attribútumban vagy egy `<script>`-ben). A CSS-ben **minden tokent az első 1–3 karaktere eldönt**. Nem kell emlékezni, honnan jöttünk, elég **előrenézni** (*lookahead*). Ezért a CSS-tokenizer egy nagy `if`-lánc és egy `match`, `State` enum nélkül.

Az előrenézéshez kell egy `peek(n)` metódus: az aktuális pozíciótól `n`-nel előrébb lévő karakter, **elfogyasztás nélkül**. A szerkezet ugyanaz, mint az 1. modul `Cursor`-ánál és a 3. modul lexerénél: egy `Vec<char>` és egy pozíció.

```rust
pub struct Tokenizer {
    chars: Vec<char>,
    pos: usize,
}
```

## Mikor kezdődik egy név?

A `-` trükkös. A `-webkit-box` egy név, a `-5` egy szám, a `--fo-szin` pedig egy CSS-változó neve (a 14. modulban lesz rá szükség). A szabály:

| Első karakter | Második karakter | Név kezdődik? |
|---|---|---|
| `-` | névkezdő vagy `-` | igen: `-webkit-box`, `--x` |
| `-` | bármi más | nem: `-5`, `- ` |
| névkezdő | | igen |
| bármi más | | nem |

Ezt egy `starts_ident()` metódus dönti el, a `peek(0)` és a `peek(1)` alapján.

:::note A kommentek eltűnnek
A `/* … */` kommentből **semmilyen token** nem lesz. Az `a/* x */b` két ident: `a` és `b`. Ha egy komment sosem zárul (`/* elfelejtettem bezárni`), a szabvány szerint a fájl végéig minden komment. Egy elfelejtett `*/` tehát „lenyeli” a stíluslap hátralevő részét. Ez egy klasszikus CSS-hiba, amit most már belülről is értesz!
:::

2. Privát segédek: `peek(&self, n: usize) -> Option<char>`, `starts_ident(&self) -> bool`, `consume_name(&mut self) -> String` (amíg névkarakter jön), `skip_comment(&mut self)` (a `/*`-on áll, és a `*/` utánig vagy a végéig lép).

A tesztmodulba vedd fel a `use Token::*;` sort is: így a tesztekben elég `Ident(…)`-ot írni `Token::Ident(…)` helyett.

```rust test
#[cfg(test)]
mod tests {
    use super::*;
    use Token::*;

    #[test]
    fn simple_rule() {
        assert_eq!(
            tokenize("p { color: red; }"),
            vec![
                Ident("p".into()),
                Whitespace,
                LeftBrace,
                Whitespace,
                Ident("color".into()),
                Colon,
                Whitespace,
                Ident("red".into()),
                Semicolon,
                Whitespace,
                RightBrace,
            ]
        );
    }

    #[test]
    fn selectors_and_at_rules() {
        assert_eq!(
            tokenize("#nav>.item,@media"),
            vec![
                Hash("nav".into()),
                Delim('>'),
                Delim('.'),
                Ident("item".into()),
                Comma,
                AtKeyword("media".into()),
            ]
        );
        assert_eq!(
            tokenize("-webkit-box --x"),
            vec![Ident("-webkit-box".into()), Whitespace, Ident("--x".into())]
        );
    }

    #[test]
    fn comments_and_functions() {
        assert_eq!(
            tokenize("a/* komment */b"),
            vec![Ident("a".into()), Ident("b".into())]
        );
        assert_eq!(tokenize("/* soha nem zárul"), vec![]);
        assert_eq!(
            tokenize("url(a) (b)"),
            vec![
                Function("url".into()),
                Ident("a".into()),
                RightParen,
                Whitespace,
                LeftParen,
                Ident("b".into()),
                RightParen,
            ]
        );
    }
}
```

:::hint
A `peek` egy sor: `self.chars.get(self.pos + n).copied()`. A `get` nem pánikol, ha túlszaladsz, hanem `None`-t ad. A `copied()` a `Option<&char>`-ból `Option<char>`-t csinál.
---
A `next_token` váza:
```rust
pub fn next_token(&mut self) -> Option<Token> {
    while self.peek(0) == Some('/') && self.peek(1) == Some('*') {
        self.skip_comment();
    }
    let c = self.peek(0)?;
    // 1. szóköz → Whitespace
    // 2. starts_ident() → név, és ha utána '(' jön, Function
    // 3. különben: self.pos += 1, és egy match a c-n
}
```
A `while` azért kell, mert két komment is jöhet egymás után (`/* a *//* b */`). A `?` az `Option`-nél is működik: ha a `peek(0)` `None`, a függvény azonnal `None`-nal tér vissza.
---
A `match`-ben az **őrfeltétel** (*match guard*) segít a `#`-nél és a `@`-nál:
```rust
'#' if self.peek(0).is_some_and(is_name_char) => Token::Hash(self.consume_name()),
'@' if self.starts_ident() => Token::AtKeyword(self.consume_name()),
```
Itt a `self.pos += 1` már lefutott, tehát a `peek(0)` a `#` **utáni** karakter. Ha az őrfeltétel hamis, a `match` megy tovább a következő ágra, és a végén az `other => Token::Delim(other)` elkapja.
:::

:::solution
```rust
pub struct Tokenizer {
    chars: Vec<char>,
    pos: usize,
}

impl Tokenizer {
    pub fn new(input: &str) -> Tokenizer {
        Tokenizer {
            chars: input.chars().collect(),
            pos: 0,
        }
    }

    /// Az aktuális pozíciótól `n`-nel előrébb lévő karakter, elfogyasztás nélkül.
    fn peek(&self, n: usize) -> Option<char> {
        self.chars.get(self.pos + n).copied()
    }

    /// Egy név kezdődik-e az aktuális pozíción? (`-x` és `--x` is név.)
    fn starts_ident(&self) -> bool {
        match self.peek(0) {
            Some('-') => self.peek(1).is_some_and(|c| is_name_start(c) || c == '-'),
            Some(c) => is_name_start(c),
            None => false,
        }
    }

    fn consume_name(&mut self) -> String {
        let mut name = String::new();
        while let Some(c) = self.peek(0) {
            if !is_name_char(c) {
                break;
            }
            name.push(c);
            self.pos += 1;
        }
        name
    }

    fn skip_comment(&mut self) {
        self.pos += 2; // a "/*"
        while self.pos < self.chars.len() {
            if self.peek(0) == Some('*') && self.peek(1) == Some('/') {
                self.pos += 2;
                return;
            }
            self.pos += 1;
        }
    }

    pub fn next_token(&mut self) -> Option<Token> {
        while self.peek(0) == Some('/') && self.peek(1) == Some('*') {
            self.skip_comment();
        }
        let c = self.peek(0)?;
        if is_whitespace(c) {
            while self.peek(0).is_some_and(is_whitespace) {
                self.pos += 1;
            }
            return Some(Token::Whitespace);
        }
        if self.starts_ident() {
            let name = self.consume_name();
            if self.peek(0) == Some('(') {
                self.pos += 1;
                return Some(Token::Function(name));
            }
            return Some(Token::Ident(name));
        }
        self.pos += 1;
        let token = match c {
            '#' if self.peek(0).is_some_and(is_name_char) => Token::Hash(self.consume_name()),
            '@' if self.starts_ident() => Token::AtKeyword(self.consume_name()),
            ':' => Token::Colon,
            ';' => Token::Semicolon,
            ',' => Token::Comma,
            '{' => Token::LeftBrace,
            '}' => Token::RightBrace,
            '(' => Token::LeftParen,
            ')' => Token::RightParen,
            other => Token::Delim(other),
        };
        Some(token)
    }
}

pub fn tokenize(input: &str) -> Vec<Token> {
    let mut t = Tokenizer::new(input);
    let mut out = Vec::new();
    while let Some(token) = t.next_token() {
        out.push(token);
    }
    out
}
```

:::why Miért nem reguláris kifejezésekkel?
Egy CSS-tokenizer megírható regexekkel is (`[a-zA-Z_-][a-zA-Z0-9_-]*` a névre és így tovább), és sok tankönyvi példa így csinálja. A böngészők mégis kézzel írják. Két okból. Egyrészt **gyorsabb**: egy kézzel írt ciklus minden karaktert pontosan egyszer néz meg, és nem kell a regex-motort sem betölteni. Másrészt **pontosabb**: a szabvány algoritmust ír le (előrenézés, kivételek, hibás bemenet kezelése), és ezt egy az egyben le lehet fordítani kódra. A Firefox `cssparser` crate-je (amit a 16. modulban bekötünk) is így működik.

@@ megoldás
```rust
fn strip_comments(css: &str) -> String {
    let mut out = String::with_capacity(css.len());
    let mut rest = css;
    while let Some(start) = rest.find("/*") {
        out.push_str(&rest[..start]);
        match rest[start + 2..].find("*/") {
            Some(end) => rest = &rest[start + 2 + end + 2..],
            None => return out,
        }
    }
    out.push_str(rest);
    out
}
```
@@ magyarázat
A `str::find` nagyon gyorsan keres (egyszerre több bájtot is megnéz), és a `push_str` egész szeleteket másol, nem karakterenként tolja a szöveget. A `with_capacity` előre lefoglalja a helyet, így a `String`-nek nem kell menet közben újra és újra nagyobb memóriát kérnie. A záró `*/`-t a `start + 2`-től keressük, így a nyitó csillag nem számít bele.
@@ esetek

strip_comments("/*/ x */y")
strip_comments("árvíz/* ő */tűrő")

        out.push_str(&rest[..start]);

@@ teszt-lassú
```rust
fn strip_comments(css: &str) -> String {
    let chars: Vec<char> = css.chars().collect();
    let mut out = String::new();
    let mut i = 0;
    let mut in_comment = false;
    while i < chars.len() {
        let rest: String = chars[i..chars.len().min(i + 2)].iter().collect();
        if !in_comment && rest == "/*" {
            in_comment = true;
            i += 2;
        } else if in_comment && rest == "*/" {
            in_comment = false;
            i += 2;
        } else {
            if !in_comment {
                out.push(chars[i]);
            }
            i += 1;
        }
    }
    out
}
```
