A `rozsda` repóból **Cargo workspace** lesz, benne három crate-tel: `rozsda-core`, `rozsda-html` és `rozsda-browser`. A lecke végén a `cargo run -p rozsda-browser` kiírja, melyik HTML-motor fut.

## Mi az a workspace?

Eddig minden projekted egyetlen crate volt. A **workspace** több crate-et fog össze egy projektbe:

- közös `target/` mappa (nem fordul le minden kétszer),
- közös `Cargo.lock` (mindenhol ugyanazok a verziók),
- egy paranccsal tesztelhető az egész (`cargo test`).

C#-ban ez a *solution* (`.sln`) több *projekttel*. A Servo, a Firefox Rust-része és a legtöbb nagy Rust-projekt is így épül fel.

## A célszerkezet

```text
rozsda/
├── Cargo.toml              ← a workspace leírása (nincs benne [package]!)
├── README.md
├── gyakorlo/               ← az 1. modul, megmarad
└── crates/
    ├── rozsda-core/        ← közös típusok és traitek (library)
    ├── rozsda-html/        ← a saját HTML-motorod (library)
    └── rozsda-browser/     ← az ablak és a UI (binary)
```

:::steps
- Nyiss terminált a `C:\kod\rozsda` mappában.
- Hozd létre a gyökér `Cargo.toml`-t (VS Code-ban: `code Cargo.toml`) az alábbi tartalommal.
- Hozd létre a három crate-et a lenti `cargo new` parancsokkal.
- Futtasd a gyökérben: `cargo test`. A gyakorló összes tesztjének továbbra is zöldnek kell lennie.
:::

```toml
[workspace]
resolver = "3"
members = ["crates/*", "gyakorlo"]
```

- A `members` mondja meg, melyik mappák tartoznak a workspace-be. A `crates/*` minden mappát jelent a `crates` alatt.
- A `resolver = "3"` a függőségfeloldó algoritmus legújabb változata (a 2024-es editionhöz ez való).

```powershell
cargo new crates/rozsda-core --lib
cargo new crates/rozsda-html --lib
cargo new crates/rozsda-browser
```

A `--lib` könyvtárat (library) hoz létre (`lib.rs`), a kapcsoló nélküli parancs programot (`main.rs`).

:::note Miért „rozsda-” előtaggal?
A crate-nevek globálisak a crates.io-n, és a `core`, a `html` és a `browser` név már foglalt (sőt a `core` a Rust saját beépített crate-je!). Az előtag ütközésmentessé teszi őket. A kódban a kötőjelből aláhúzás lesz: `use rozsda_core::...`.
:::

## Crate-ek közötti függőség

A `rozsda-html` és a `rozsda-browser` is a `rozsda-core`-t fogja használni, a browser pedig a html-t is. Ezt **útvonal-függőséggel** (path dependency) adod meg. A `crates/rozsda-html/Cargo.toml` végére:

```toml
[dependencies]
rozsda-core = { path = "../rozsda-core" }
```

A `crates/rozsda-browser/Cargo.toml` végére:

```toml
[dependencies]
rozsda-core = { path = "../rozsda-core" }
rozsda-html = { path = "../rozsda-html" }
```

:::warn Körkörös függőség tilos
A `core` **nem** függhet a `html`-től, mert a `html` már függ a `core`-tól, és a Cargo nem engedi a kört. Ez nem korlát, hanem jó tervezési szabály: a core a „szerződés”, és nem tudhat az implementációkról. A browser az egyetlen, aki mindenkit ismer.
:::

## Az első életjel

:::task
1. A `rozsda-core/src/lib.rs`-be írj egy függvényt: `pub fn version() -> &'static str`, ami `"0.1.0-dev"`-et ad vissza.
2. A `rozsda-html/src/lib.rs`-be írj egy függvényt: `pub fn engine_name() -> &'static str`, ami `"Rozsda (saját)"`-ot ad vissza.
3. A `rozsda-browser/src/main.rs` írja ki:

```text
Rozsda 0.1.0-dev
HTML-motor: Rozsda (saját)
```

Futtatás a gyökérből:

```powershell
cargo run -p rozsda-browser
```

A `-p` (package) mondja meg, melyik crate-et futtassa, mert a workspace-ben több program is lehet.
:::

:::hint
A `cargo new --lib` egy példa-függvényt (`add`) és egy tesztet is generál a `lib.rs`-be. Nyugodtan töröld ki.
---
A `main.rs`-ben: `println!("Rozsda {}", rozsda_core::version());`. A kötőjel helyett aláhúzás kell, és a teljes útvonallal `use` nélkül is hivatkozhatsz.
:::

:::solution
```rust
// crates/rozsda-core/src/lib.rs
pub fn version() -> &'static str {
    "0.1.0-dev"
}
```

```rust
// crates/rozsda-html/src/lib.rs
pub fn engine_name() -> &'static str {
    "Rozsda (saját)"
}
```

```rust
// crates/rozsda-browser/src/main.rs
fn main() {
    println!("Rozsda {}", rozsda_core::version());
    println!("HTML-motor: {}", rozsda_html::engine_name());
}
```
:::

## Hasznos workspace-parancsok

| Parancs | Mit csinál |
|---|---|
| `cargo test` | A gyökérben: **minden** crate tesztje |
| `cargo test -p rozsda-html` | Csak egy crate tesztjei |
| `cargo run -p rozsda-browser` | A böngésző futtatása |
| `cargo check --workspace` | Gyors ellenőrzés mindenre |
| `cargo clippy --workspace` | Lint mindenre |

:::tip Egy kis kényelem: alias
Hogy ne kelljen mindig kiírni a `-p rozsda-browser`-t, hozz létre egy `.cargo/config.toml` fájlt a gyökérben:
```toml
[alias]
b = "run -p rozsda-browser --"
```
Mostantól elég ennyi: `cargo b`. (A `--` után írt dolgokat a program kapja meg. Ez a 02-07-es leckében jól jön majd.)
:::
