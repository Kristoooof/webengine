## A fájl térképe

A fontfájl elején 12 bájtos fejléc áll, utána a táblakönyvtár: minden táblának egy 16 bájtos sor.

```text Ábra
bájt   0 ┌──────────────────────────────────┐
         │ verzió          u32  0x00010000  │
         │ táblák száma    u16  20          │
         │ searchRange, entrySelector,      │
         │ rangeShift     (3 × u16)         │
bájt  12 ├──────────────────────────────────┤
         │ "FFTM"  összeg      332     28   │
         │ "GDEF"  összeg      360    660   │
         │ …                                │
         │ "head"  összeg  611 512     54   │
         │ …  (20 sor, név szerint)         │
bájt 332 ├──────────────────────────────────┤
         │ a táblák maguk, bárhol a fájlban │
         └──────────────────────────────────┘
```

Egy sor: a név (4 bájt, pl. `b"head"`), egy ellenőrzőösszeg (checksum, `u32`), a tábla helye a fájl elejétől (`u32`) és a hossza (`u32`). Az ellenőrzőösszeggel nem foglalkozunk: a böngészők sem ellenőrzik, mert egy rossz összeg miatt nem érdemes egy egyébként jó fontot eldobni.

```rust
use reader::Reader;
```

```rust
/// Egy tábla helye a fájlban.
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Table {
    pub offset: usize,
    pub len: usize,
}

/// A táblakönyvtár: minden táblának egy 16 bájtos sor (név, ellenőrzőösszeg, hely, hossz).
pub fn table_directory(data: &[u8]) -> Option<Vec<([u8; 4], Table)>> {
    let mut r = Reader::at(data, 4);
    let num_tables = r.u16()?;
    r.skip(6); // searchRange, entrySelector, rangeShift: a bináris kereséshez kellenének
    let mut tables = Vec::with_capacity(num_tables as usize);
    for _ in 0..num_tables {
        let tag = r.tag()?;
        let _checksum = r.u32()?;
        let offset = r.u32()? as usize;
        let len = r.u32()? as usize;
        tables.push((tag, Table { offset, len }));
    }
    Some(tables)
}
```

## A három igazolvány

Három táblából olvasunk most néhány számot. A helyük a tábla elejétől számít (a szabvány táblázataiból összeszámolva):

| Tábla | Hely | Típus | Mező | DejaVu Sans |
|---|---|---|---|---|
| `head` | 18 | `u16` | `unitsPerEm`: hány egység egy em | 2048 |
| `maxp` | 4 | `u16` | `numGlyphs`: a glifek száma | 6253 |
| `hhea` | 4 | `i16` | `ascender`: az alapvonal fölött | 1901 |
| `hhea` | 6 | `i16` | `descender`: az alapvonal alatt (negatív!) | −483 |

## A hibák

Eddig minden olvasás `Option` volt. A `Font::parse` viszont mondja meg, **mi** a baj, mert a felhasználó (vagy te, hibakereséskor) erre kíváncsi:

```rust
#[derive(Debug, Clone, PartialEq)]
pub enum FontError {
    /// Elfogyott az adat olvasás közben: a fájl csonka vagy sérült.
    Truncated,
    /// Nem TrueType-körvonalas betűtípus (pl. CFF-alapú `.otf`, vagy nem is betűtípus).
    NotTrueType,
    /// Hiányzik egy kötelező tábla.
    MissingTable(&'static str),
}
```

A `&'static str` egy szövegliterál, ami a program teljes futása alatt él (pl. `"head"`). Így a hiba nem foglal külön memóriát.

## Te jössz: `Font::parse`

:::task

A `not_a_font` harmadik esete egy „font”, aminek a fejléce rendben van, de 0 táblája van.

:::hint
A `Font<'a>` élettartam-paramétere azt fejezi ki, hogy a `Font` **kölcsönveszi** (borrowing) a bájtokat, és nem élhet tovább náluk. A `DEJAVU_SANS`-ből készült `Font` `Font<'static>` lesz, mert a konstans a program teljes futása alatt él.
---
A táblakereséshez egy **closure** (névtelen függvény) a legkényelmesebb, ami a `tables` és a `data` változót a környezetéből látja:
```rust
let find = |tag: &'static str| {
    tables
        .iter()
        .find(|(t, _)| t == tag.as_bytes())
        // ... a Table kivétele, a határ ellenőrzése, Option → Result
};
```
Az `Option`-ből a `.ok_or(hiba)` csinál `Result`-ot, és a `.filter(|t| …)` dobja el azt a táblát, ami kilóg a fájlból.
---
A számokhoz egy második closure: `let at = |pos: usize| Reader::at(data, pos);`, és utána pl. `at(head.offset + 18).u16().ok_or(FontError::Truncated)?`.
:::

```rust
impl fmt::Display for FontError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            FontError::Truncated => write!(f, "a betűtípus-fájl csonka"),
            FontError::NotTrueType => write!(f, "nem TrueType-betűtípus"),
            FontError::MissingTable(tag) => write!(f, "hiányzik a(z) {tag} tábla"),
        }
    }
}
```

```rust
/// Egy beolvasott betűtípus. A fájl bájtjait nem másolja, csak hivatkozik rájuk.
#[derive(Debug, Clone)]
pub struct Font<'a> {
    data: &'a [u8],
    /// Hány egység egy „em” (a betűméret): 1000 vagy 2048 a szokásos
    pub units_per_em: u16,
    pub num_glyphs: u16,
    /// Az alapvonal fölötti és alatti rész, font-egységben (a `descender` negatív)
    pub ascender: i16,
    pub descender: i16,
}

impl<'a> Font<'a> {
    pub fn parse(data: &'a [u8]) -> Result<Font<'a>, FontError> {
        let version = Reader::new(data).u32().ok_or(FontError::Truncated)?;
        if version != 0x0001_0000 && version != u32::from_be_bytes(*b"true") {
            return Err(FontError::NotTrueType);
        }
        let tables = table_directory(data).ok_or(FontError::Truncated)?;
        let find = |tag: &'static str| {
            tables
                .iter()
                .find(|(t, _)| t == tag.as_bytes())
                .map(|&(_, table)| table)
                .filter(|t| t.offset + t.len <= data.len())
                .ok_or(FontError::MissingTable(tag))
        };
        let head = find("head")?;
        let maxp = find("maxp")?;
        let hhea = find("hhea")?;
        let at = |pos: usize| Reader::at(data, pos);

        let units_per_em = at(head.offset + 18).u16().ok_or(FontError::Truncated)?;
        let num_glyphs = at(maxp.offset + 4).u16().ok_or(FontError::Truncated)?;
        let mut r = at(hhea.offset + 4);
        let ascender = r.i16().ok_or(FontError::Truncated)?;
        let descender = r.i16().ok_or(FontError::Truncated)?;

        Ok(Font {
            data,
            units_per_em,
            num_glyphs,
            ascender,
            descender,
        })
    }
}
```

:::why Miért ellenőrizzük, hogy a tábla belefér-e a fájlba?
Mert a fájl **hazudhat**. A betűtípusokat a böngésző idegen weboldalakról tölti le, és egy rosszindulatú font azt állíthatja, hogy a `glyf` tábla a 4 milliárdodik bájtnál kezdődik. Ha ezt ellenőrzés nélkül elhisszük, a program a memóriában össze-vissza olvas. C-ben ez biztonsági rés, Rustban „csak” egy pánik (a szelet indexelése ellenőrzött), de a felhasználó szempontjából mindkettő rossz.

A fontkezelő kód történelmileg a böngészők egyik leggyakoribb támadási felülete volt. Ezért futtatja a Chrome és a Firefox minden letöltött fontot egy **OTS** (OpenType Sanitizer) nevű ellenőrzőn, mielőtt a FreeType egyáltalán látná.

```rust
fn find_table(tables: &[([u8; 4], usize, usize)], tag: &[u8; 4], file_len: usize) -> Option<(usize, usize)> {
```
```rust
    let i = tables.binary_search_by(|(t, _, _)| t.cmp(tag)).ok()?;
```
