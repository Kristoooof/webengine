## Kölcsönzés: & (olvasásra)

Az előző leckében a függvény elvitte a `String`-et. A megoldás a **referencia**: odaadod a függvénynek, hogy *nézze meg*, de a tulajdon nálad marad.

```rust
fn tag_len(name: &String) -> usize {
    name.len()
}

fn main() {
    let tag = String::from("section");
    let n = tag_len(&tag);      // kölcsönadjuk
    println!("{tag}: {n}");     // ✅ a tag még a miénk
}
```

A `&tag` egy **referencia** a `tag`-ra. A függvény olvashatja, de nem lesz a tulajdonosa, ezért a függvény végén **nem** szabadítja fel.

## Kölcsönzés: &mut (írásra)

Ha a függvénynek módosítania kell, **módosítható referenciát** adsz át:

```rust
fn push_end_tag(out: &mut String, name: &str) {
    out.push_str("</");
    out.push_str(name);
    out.push('>');
}

fn main() {
    let mut html = String::from("<p>Szia");
    push_end_tag(&mut html, "p");
    println!("{html}");     // <p>Szia</p>
}
```

Ehhez kell a `let mut` **és** a `&mut` is. A Rust a hívás helyén is látni akarja, hogy ez a függvény módosítani fogja a változódat.

## A kölcsönzés két szabálya

1. Egy adott pillanatban **vagy** akárhány `&` (olvasó) referencia lehet, **vagy pontosan egy** `&mut` (író). A kettő egyszerre nem.
2. A referencia nem élheti túl azt, amire mutat.

```rust
let mut s = String::from("div");
let r1 = &s;
let r2 = &s;          // ✅ több olvasó rendben van
let w = &mut s;       // ❌ amíg r1, r2 használatban van, nem lehet író
println!("{r1} {r2}");
```

```text
error[E0502]: cannot borrow `s` as mutable because it is also borrowed as immutable
```

:::note Miért kell ez egy böngészőben?
Képzeld el: a layout épp végigmegy a DOM-fán (olvas), miközben a JavaScript kitöröl belőle egy elemet (ír). C++-ban ez egy klasszikus összeomlás vagy biztonsági rés („use after free”). A Rust fordítási időben **nem engedi**, hogy egyszerre legyen olvasó és író. Ez az a szabály, amiért a Mozilla megalkotta a Rustot.
:::

:::compare
@@ C++
```cpp
void tag_len(const std::string& name);   // ≈ &String
void push_end(std::string& out);          // ≈ &mut String
```
A C++-os referencia hasonló, de a fordító nem ellenőrzi, hogy az objektum még él-e, és hogy más épp nem módosítja-e.
@@ C#
```csharp
void PushEnd(ref string out) { ... }    // ≈ &mut
void TagLen(in string name) { ... }     // ≈ & (C# 7.2+)
```
C#-ban a `ref` / `in` ritka, mert a referencia-típusok (osztályok) amúgy is referenciaként adódnak át. Rustban viszont ez a fő eszköz.
:::

## &str: a szöveg-szelet

Most végre megértheted a `&str`-t. A **string slice** (`&str`) egy referencia egy szöveg **egy darabjára**: egy mutató és egy hossz. Nem másolja le a szöveget.

```rust
let html = String::from("<div>Szia</div>");
let inner: &str = &html[5..9];    // bájtindexek: 5-től 9-ig (a 9 már nem)
println!("{inner}");              // Szia
```

A szöveg-literál (`"div"`) is `&str`: a program futtatható fájljába beégetett szövegre mutat.

| | `String` | `&str` |
|---|---|---|
| Tulajdon | Saját, a heapen | Kölcsönzött |
| Nőhet? | Igen (`push`, `push_str`) | Nem |
| Mikor használd | Ha tárolni vagy építeni kell | Függvényparaméternek, és ha csak olvasol |

:::tip Arany szabály: paraméternek `&str`
Ha egy függvény csak olvas egy szöveget, a paramétere legyen `&str`, ne `&String`. Így `String`-et (`&s`) és literált (`"div"`) is kaphat, mert a Rust a `&String`-et automatikusan `&str`-ré alakítja (*deref coercion*).
:::

:::warn Bájtindex, nem karakterindex!
A `&s[a..b]` **bájt**indexeket vár. Ha egy több bájtos karakter (pl. „ő”) **közepén** vágsz, a program pánikol:

```text
let s = "ő";
let x = &s[0..1];   // 💥 panic: byte index 1 is not a char boundary
```

Ezért ha karakterenként haladsz, és tudni akarod az indexet is, használd a **`char_indices()`**-t. Ez `(bájtindex, karakter)` párokat ad, és az indexek mindig érvényes vágási pontok.
:::

```rust
for (i, c) in "<ő>".char_indices() {
    println!("{i}: {c}");
}
// 0: <
// 1: ő
// 3: >     ← az ő 2 bájtos, ezért ugrik 1-ről 3-ra
```

## Te jössz: tag_name

:::task
Írd meg: `fn tag_name(tag: &str) -> &str`. A bemenet egy teljes tag, pl. `<div class="x">`, `</p>` vagy `<br/>`. A kimenet a tag neve (`div`, `p`, `br`), **szeletként** az eredeti szövegből, tehát másolás nélkül.

A név a `<` (vagy a `</`) után kezdődik, és az első olyan karakternél ér véget, ami nem betű vagy szám (`c.is_ascii_alphanumeric()`).

A második feladat: írd meg a fenti `push_end_tag` függvényt is (gépeld be, ne másold), és tesztelj vele.
:::

```rust test
    #[test]
    fn names() {
        assert_eq!(tag_name("<div class=\"x\">"), "div");
        assert_eq!(tag_name("</p>"), "p");
        assert_eq!(tag_name("<br/>"), "br");
        assert_eq!(tag_name("<h1>"), "h1");
        assert_eq!(tag_name("<img src=\"a.png\">"), "img");
    }

    #[test]
    fn end_tags() {
        let mut s = String::from("<p>Szia");
        push_end_tag(&mut s, "p");
        assert_eq!(s, "<p>Szia</p>");
    }
```

:::hint
Két lépésben gondolkodj. **1)** Hol kezdődik a név? Ha a tag `"</"`-rel kezdődik (`tag.starts_with("</")`), akkor a 2. bájtnál, különben az 1.-nél. **2)** Hol ér véget? Vágd le az elejét (`let rest = &tag[start..];`), és keresd meg a `rest`-ben az első nem alfanumerikus karaktert.
---
A végpont kereséséhez:
```rust
let mut end = rest.len();
for (i, c) in rest.char_indices() {
    if !c.is_ascii_alphanumeric() {
        end = i;
        break;
    }
}
```
Utána már csak a `&rest[..end]` kell. (A `..end` azt jelenti, hogy „az elejétől end-ig”.)
---
Az `if`-ből kifejezés lehet: `let start = if tag.starts_with("</") { 2 } else { 1 };`
:::

:::solution
```rust
fn tag_name(tag: &str) -> &str {
    let start = if tag.starts_with("</") { 2 } else { 1 };
    let rest = &tag[start..];
    let mut end = rest.len();
    for (i, c) in rest.char_indices() {
        if !c.is_ascii_alphanumeric() {
            end = i;
            break;
        }
    }
    &rest[..end]
}

fn push_end_tag(out: &mut String, name: &str) {
    out.push_str("</");
    out.push_str(name);
    out.push('>');
}
```
:::

:::why Honnan tudja a fordító, hogy a visszaadott &str meddig érvényes?
A `fn tag_name(tag: &str) -> &str` visszatérési értéke egy **szelet a bemenetből**. A fordító ebből kikövetkezteti, hogy a kimenet addig érvényes, ameddig a bemenet. Ezt hívják **lifetime**-nak (élettartamnak). Teljes alakban így nézne ki: `fn tag_name<'a>(tag: &'a str) -> &'a str`. Egyszerű esetekben ki sem kell írni (*lifetime elision*). Ha egyszer mégis kell, a fordító szólni fog, és akkor részletesen megnézzük.
:::
