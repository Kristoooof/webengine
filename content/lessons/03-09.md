:::goal
Megírod a fa-építőt (tree builder). A tokenekből a **nyitott elemek vermének** segítségével DOM-fa lesz, a hiányzó `<html>`, `<head>` és `<body>` pedig automatikusan létrejön. A lecke végére egy teljes HTML-dokumentum fává alakul.
:::

## A nyitott elemek verme

A fa-építés kulcsa egy **verem** (stack), a szabvány nevén *stack of open elements*. Benne vannak azok az elemek, amelyek **nyitva vannak**: már láttuk a kezdőtagjukat, de a zárótagjukat még nem.

```text Ábra
token          művelet                           verem
<html>         új elem, a gyökér alá, push       [html]
<body>         új elem, a html alá, push         [html, body]
<p>            új elem, a body alá, push         [html, body, p]
"Szia "        szöveg a verem tetejére (p)       [html, body, p]
<b>            új elem, a p alá, push            [html, body, p, b]
"Rozsda"       szöveg a b-be                     [html, body, p, b]
</b>           pop a b-ig                        [html, body, p]
</p>           pop a p-ig                        [html, body]
```

Két egyszerű szabály:

1. **Kezdőtag:** az új elem a verem **tetején** lévő elem gyereke lesz, és (ha nem void elem) felkerül a verem tetejére.
2. **Zárótag:** a veremből addig veszünk le elemeket (pop), amíg le nem vesszük a vele egyező nevűt.

A szöveg és a komment mindig a verem tetején lévő elembe kerül. Ha a verem üres, a dokumentum gyökerébe.

:::compare Ezt már láttad
@@ Érettségi
Zárójelek párosítása veremmel: `(` → push, `)` → pop. Pontosan ez! A HTML-tagek „zárójelek” nevekkel, és a fa-építő egy kicsit okosabb zárójel-párosító.
@@ C#
```csharp
var stack = new Stack<Node>();
stack.Push(node);
var top = stack.Peek();
stack.Pop();
```
Rustban a `Vec` a verem: `push`, `last()` (ez a peek) és `pop()`.
:::

## Az automatikus html, head, body

Ez a dokumentum is érvényes HTML, mégsincs benne se `<html>`, se `<head>`, se `<body>`:

```html
<title>Szia</title>
<p>Hello
```

A böngésző a hiányzó elemeket **magától** létrehozza. A szabályok egyszerűsítve (a szabvány „insertion mode”-jai alapján):

- Bármilyen tartalom előtt létre kell jönnie a `<html>`-nek (`ensure_html`).
- A **head-elemek** (`title`, `style`, `script`, `meta`, `link`, `base`, `noscript`) a `<head>`-be kerülnek, **ha a body még nem kezdődött el** (`ensure_head`).
- Minden más elem vagy nem-szóköz szöveg előtt létre kell jönnie a `<body>`-nak (`ensure_body`). Közben a head lezárul.
- A body kezdete előtti puszta szóközök (sortörések a tagek között) elvesznek.
- A `</body>` és a `</html>` zárótagot figyelmen kívül hagyjuk. Ami utánuk jön, az is a body-ba kerül (a böngészők is így csinálják).

## A fa-építő váza


A `html`, `head`, `body` mezők megjegyzik, hogy a három különleges elem létrejött-e már, és ha igen, melyik csomópont az.

:::hint
Az `insert_element` egy apró borrow-csapdát rejt. Ez **nem** fordul le:
```text Nem fordul le
self.doc.append(self.current(), id);
```
A `self.doc.append` már `&mut`-ként kölcsönzi a `self.doc`-ot, miközben a `self.current()` még olvasná a `self`-et. A megoldás: előbb egy változóba, aztán a hívás.
```rust
let parent = self.current();
self.doc.append(parent, id);
```
Ezt a mintát a fa-építőben többször is használni fogod.
---
Az `ensure_body`:
```rust
fn ensure_body(&mut self) {
    if self.body.is_some() {
        return;
    }
    self.ensure_head();
    // A head lezárása: minden, ami a head-ben (vagy alatta) nyitva maradt.
    if let Some(head) = self.head
        && let Some(i) = self.stack.iter().position(|&n| n == head)
    {
        self.stack.truncate(i);
    }
    let id = self.insert_element("body", vec![]);
    self.stack.push(id);
    self.body = Some(id);
}
```
A `truncate(i)` levágja a verem végét az `i`. elemtől kezdve. Így a head is kikerül, és minden, ami benne nyitva maradt.
---
A `text`: ha a body még nincs meg, két eset van. **1)** A verem tetején egy head-elem van (pl. `title` vagy `style`): akkor a szöveg oda megy. **2)** Különben vágd le a szöveg elejéről a szóközöket (`trim_start_matches(|c: char| c.is_ascii_whitespace())`). Ha semmi nem maradt, kész. Ha maradt, `ensure_body()`, és a maradék a current-be megy. Ha a body már megvan, a szöveg egyszerűen a current-be kerül, az `append_text`-tel.
:::

:::solution
```rust
//! Fa-építés a tokenekből (a WHATWG 13.2.6 fejezetének egyszerűsített változata).

use crate::lexer::{Token, tokenize};
use rozsda_core::dom::{Document, NodeData, NodeId};

const VOID: [&str; 13] = [
    "area", "base", "br", "col", "embed", "hr", "img", "input", "link", "meta", "source", "track", "wbr",
];

const HEAD_ELEMENTS: [&str; 7] = ["title", "style", "script", "meta", "link", "base", "noscript"];

pub struct TreeBuilder {
    doc: Document,
    stack: Vec<NodeId>,
    html: Option<NodeId>,
    head: Option<NodeId>,
    body: Option<NodeId>,
}

pub fn parse_document(html: &str) -> Document {
    let mut tb = TreeBuilder::new();
    for token in tokenize(html) {
        tb.process(token);
    }
    tb.finish()
}

impl Default for TreeBuilder {
    fn default() -> Self {
        Self::new()
    }
}

impl TreeBuilder {
    pub fn new() -> TreeBuilder {
        TreeBuilder { doc: Document::new(), stack: Vec::new(), html: None, head: None, body: None }
    }

    pub fn finish(self) -> Document {
        self.doc
    }

    fn current(&self) -> NodeId {
        self.stack.last().copied().unwrap_or(self.doc.root())
    }

    fn current_name(&self) -> Option<&str> {
        self.stack.last().and_then(|&n| self.doc.tag_name(n))
    }

    fn insert_element(&mut self, name: &str, attrs: Vec<(String, String)>) -> NodeId {
        let id = self.doc.create_element(name, attrs);
        let parent = self.current();
        self.doc.append(parent, id);
        id
    }

    fn ensure_html(&mut self) {
        if self.html.is_none() {
            let id = self.insert_element("html", vec![]);
            self.stack.push(id);
            self.html = Some(id);
        }
    }

    fn ensure_head(&mut self) {
        self.ensure_html();
        if self.head.is_none() {
            let id = self.insert_element("head", vec![]);
            self.stack.push(id);
            self.head = Some(id);
        }
    }

    fn ensure_body(&mut self) {
        if self.body.is_some() {
            return;
        }
        self.ensure_head();
        // A head lezárása: minden, ami a head-ben (vagy alatta) nyitva maradt.
        if let Some(head) = self.head
            && let Some(i) = self.stack.iter().position(|&n| n == head)
        {
            self.stack.truncate(i);
        }
        let id = self.insert_element("body", vec![]);
        self.stack.push(id);
        self.body = Some(id);
    }

    fn pop_until(&mut self, name: &str) {
        while let Some(n) = self.stack.pop() {
            if self.doc.tag_name(n) == Some(name) {
                break;
            }
        }
    }

    pub fn process(&mut self, token: Token) {
        match token {
            Token::Doctype { name } => {
                if self.html.is_none() {
                    let id = self.doc.create(NodeData::Doctype(name));
                    let root = self.doc.root();
                    self.doc.append(root, id);
                }
            }
            Token::Comment(c) => {
                let id = self.doc.create(NodeData::Comment(c));
                let parent = self.current();
                self.doc.append(parent, id);
            }
            Token::Text(t) => self.text(&t),
            Token::StartTag { name, attrs, .. } => {
                let attrs = attrs.into_iter().map(|a| (a.name, a.value)).collect();
                self.start_tag(&name, attrs);
            }
            Token::EndTag { name } => self.end_tag(&name),
            Token::Eof => {}
        }
    }

    fn text(&mut self, t: &str) {
        if self.body.is_none() {
            if matches!(self.current_name(), Some(n) if HEAD_ELEMENTS.contains(&n)) {
                let cur = self.current();
                self.doc.append_text(cur, t);
                return;
            }
            let rest = t.trim_start_matches(|c: char| c.is_ascii_whitespace());
            if rest.is_empty() {
                return;
            }
            self.ensure_body();
            let cur = self.current();
            self.doc.append_text(cur, rest);
            return;
        }
        let cur = self.current();
        self.doc.append_text(cur, t);
    }

    fn start_tag(&mut self, name: &str, attrs: Vec<(String, String)>) {
        match name {
            "html" => self.ensure_html(),
            "head" => {
                if self.body.is_none() {
                    self.ensure_head();
                }
            }
            "body" => self.ensure_body(),
            _ if self.body.is_none() && HEAD_ELEMENTS.contains(&name) => {
                self.ensure_head();
                let id = self.insert_element(name, attrs);
                if !VOID.contains(&name) {
                    self.stack.push(id);
                }
            }
            _ => {
                self.ensure_body();
                let id = self.insert_element(name, attrs);
                if !VOID.contains(&name) {
                    self.stack.push(id);
                }
            }
        }
    }

    fn end_tag(&mut self, name: &str) {
        if matches!(name, "body" | "html") {
            return;
        }
        if self.stack.iter().any(|&n| self.doc.tag_name(n) == Some(name)) {
            self.pop_until(name);
        }
    }
}
```

:::why Az „insertion mode”-ok
A szabvány fa-építője 23 **insertion mode**-ot ismer (initial, before html, before head, in head, after head, in body, in table, in select…). Mindegyik másképp kezeli ugyanazt a tokent. A mi `html`, `head` és `body` mezőnk ennek egy erősen egyszerűsített változata: a „before html”, „in head” és „in body” módokat utánozza. A legbonyolultabb részek a táblázatok („in table”, „in row”, „in cell”), mert egy `<table>`-ben rossz helyen álló tartalmat a böngésző **a táblázat elé** teszi (*foster parenting*). Ezt mi nem csináljuk meg. A 16. modulban a html5ever mind a 23 módot tudja.
