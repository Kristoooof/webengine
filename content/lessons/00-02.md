:::goal
A lecke végére a gépeden fut a `rustc --version` és a `cargo --version` parancs. Ezzel minden megvan, ami a Rust-fordításhoz kell.
:::

Ma nem programozunk, csak felállítjuk a műhelyt. A lecke nagy része várakozás, amíg a telepítők dolgoznak. Tökéletes alkalom egy teára.

## Mi az a három dolog, amit telepítünk?

A Rust-eszközkészlet három szereplőből áll. Érdemes tudni, melyik mire való, mert a hibaüzenetekben is így fogsz velük találkozni.

| Eszköz | Mire való | Ismerős megfelelője |
|---|---|---|
| **rustup** | A Rust-verziók kezelője. Ezzel telepítesz, frissítesz, váltasz verziót. | Python: `pyenv`, Node: `nvm` |
| **rustc** | Maga a fordító. Rust-kódból `.exe`-t csinál. | `g++`, `csc` |
| **cargo** | Build-rendszer és csomagkezelő egyben: projektet hoz létre, fordít, tesztel, letölti a függőségeket. | `pip` + `make`, vagy a C#-os `dotnet` CLI |

A gyakorlatban szinte mindig csak a `cargo` parancsot fogod használni, és az hívja meg helyetted a `rustc`-t.

:::note Miért kell hozzá Visual Studio?
Windowson a Rust a Microsoft **linkerét** (`link.exe`) használja. Ez rakja össze a lefordított darabokat egy futtatható `.exe`-vé, és a Windows SDK-val együtt érkezik. Ezért kell a „C++ build tools”, még akkor is, ha C++-ban egy sort sem írsz. A jó hír: a rustup telepítője ezt **fel is ajánlja automatikusan**.
:::

## Telepítés

:::steps
- Nyisd meg a [rustup.rs](https://rustup.rs) oldalt, és töltsd le a **rustup-init.exe**-t (64 bites). Ha szereted a parancssort, PowerShellben ez is működik: `winget install Rustlang.Rustup`.
- Futtasd a `rustup-init.exe`-t. Ha azt írja, hogy hiányzik a Visual Studio C++ build tools, válaszd az **1) Quick install via the Visual Studio Community installer** opciót. Ez letölti és beállítja a szükséges részeket (kb. 2–5 GB, ez a hosszú rész).
- Ha a Visual Studio Installer megnyílik, ellenőrizd, hogy a **„Desktop development with C++”** (Asztali fejlesztés C++ nyelven) munkaterhelés be van-e pipálva, aztán telepíts.
- Visszatérve a rustup ablakba, a kérdésnél nyomj **Entert** (1 = alapértelmezett telepítés). Megvárod, amíg végez.
- **Zárd be az összes terminált**, és nyiss egy újat (Windows Terminal / PowerShell). Erre azért van szükség, mert a `PATH` csak az új ablakokban frissül.
- Futtasd az ellenőrző parancsokat (lent), és nézd meg, hogy verziószámot írnak-e ki.
:::

```powershell
rustc --version
cargo --version
rustup --version
```

:::checkpoint
Valami ilyesmit kell látnod (a verziószám lehet nagyobb, az a jó):

```text
rustc 1.90.0 (1159e78c4 2025-09-14)
cargo 1.90.0 (840b83a10 2025-07-30)
rustup 1.28.2 (e4f3ad6f8 2025-04-28)
```
:::

## Ha valami nem stimmel

:::hint Gyakori hibák
**„A(z) rustc kifejezés nem ismerhető fel…”** (`rustc is not recognized`)

Nem nyitottál új terminált a telepítés után. Zárd be az összeset, és nyiss egy újat. Ha így sem megy, jelentkezz ki és be a Windowsba.
---
**„linker `link.exe` not found”**

Hiányzik a C++ build tools. Nyisd meg a *Visual Studio Installert* (Start menü), válaszd a **Módosítás** gombot, és pipáld be a **„Desktop development with C++”** munkaterhelést. Elég a Build Tools is, nem kell a teljes Visual Studio.
---
**Céges / iskolai gép, nincs admin jog**

A rustup alapból a saját felhasználói mappádba telepít (`%USERPROFILE%\.cargo`), ehhez nem kell admin. A Visual Studio Build Toolshoz viszont kell. Ilyenkor kérj segítséget a rendszergazdától, vagy dolgozz a saját gépeden.
:::

## Pár hasznos rustup-parancs

Ezeket nem kell most megtanulnod, csak tudd, hogy léteznek:

```powershell
rustup update          # frissítés a legújabb stabil verzióra (6 hetente jön új)
rustup doc --book      # a hivatalos Rust könyv, offline, a böngésződben
rustup component list  # telepíthető kiegészítők (pl. clippy, rustfmt)
```

:::tip A Rust könyv
A `rustup doc --book` megnyitja a **The Rust Programming Language** könyvet, a Rust hivatalos tankönyvét. Ez a kurzus végig a böngészőmotorhoz köti a tudnivalókat, de ha egy témában mélyebbre akarsz menni, a könyv a legjobb forrás. Ingyenes, és offline is működik.
:::

:::why Miért ilyen gyakran jön új Rust?
A Rust 6 hetente ad ki új stabil verziót („release train”). Ezek visszafelé kompatibilisek: a ma írt kódod évek múlva is le fog fordulni. Nagyobb nyelvi változások „editionökben” jönnek (2015, 2018, 2021, 2024). Az edition projektenként választható a `Cargo.toml`-ban, és a különböző editionű crate-ek gond nélkül használják egymást. Ez az egyik oka, hogy a Rust-ökoszisztéma nem szakadt ketté, mint annak idején a Python 2 és 3.
:::

:::quiz
Melyik eszköz fordítja le **ténylegesen** a Rust-kódot gépi kódra?
- [ ] cargo
- [x] rustc
- [ ] rustup
> A `rustc` a fordító. A `cargo` „karmesterként” hívja meg a megfelelő paraméterekkel, a `rustup` pedig a verziókat kezeli.
:::

:::card
K: Mi a különbség a rustup, a rustc és a cargo között?
V: **rustup**: verziókezelő (telepít, frissít). **rustc**: maga a fordító. **cargo**: build-rendszer és csomagkezelő, ezt használod a mindennapokban.
:::

:::card
K: Miért kell Windowson a Visual Studio C++ build tools a Rusthoz?
V: Mert a Rust a Microsoft linkerét (`link.exe`) és a Windows SDK-t használja a végső `.exe` összerakásához.
:::
