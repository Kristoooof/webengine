## Hogyan lesz a tokenekből Page?

A tokeneken egyszer végigmegyünk, és közben néhány dolgot számon tartunk:

| Állapot | Típus | Mire való |
|---|---|---|
| `page` | `Page` | Ide gyűlik az eredmény |
| `current` | `Block` | Az épp épülő blokk (szöveg és fajta) |
| `in_title` | `bool` | A `<title>`-ben vagyunk-e: akkor a szöveg a címbe megy |
| `skip_depth` | `i32` | Hány `<script>`/`<style>` tagon belül vagyunk. Ha > 0, a szöveget eldobjuk |

A szabályok tokenenként:

- **Kezdőtag**
  - `script`, `style` → `skip_depth += 1`
  - `title` → `in_title = true`
  - `br` → sortörés (`'\n'`) a `current.text`-be
  - **blokk-tag** (`h1`–`h6`, `p`, `div`, `li`, `ul`…) → az eddigi blokkot lezárjuk (`flush`), és az újnak beállítjuk a fajtáját
- **Zárótag**
  - `script`, `style` → `skip_depth -= 1`
  - `title` → `in_title = false`
  - blokk-tag → `flush`
- **Szöveg** → ha `skip_depth > 0`, eldobjuk. Különben dekódoljuk a hivatkozásokat, összevonjuk a szóközöket, és a címhez vagy a `current.text`-hez adjuk.
- **Komment** → semmi.

A `flush` lezárja az aktuális blokkot: soronként (a `<br>` miatti `'\n'` mentén) összevonja és levágja a szóközöket. Ha maradt szöveg, beteszi a blokkot a `page.blocks`-ba, aztán kiüríti a `current`-et.

## Karakterhivatkozások

A HTML-ben a `<` jelet nem lehet csak úgy leírni, mert tagnak hinné a böngésző. Ezért `&lt;`-t írunk. A leggyakoribbak:

| Hivatkozás | Karakter |
|---|---|
| `&lt;` | `<` |
| `&gt;` | `>` |
| `&amp;` | `&` |
| `&quot;` | `"` |
| `&#39;` | `'` |
| `&nbsp;` | nem törő szóköz (U+00A0) |

:::warn A sorrend számít!
A `&amp;lt;` szöveg jelentése: „a `&lt;` szöveg, ahogy le van írva”. Ha **előbb** cseréled az `&amp;`-ot `&`-re, `&lt;` lesz belőle, és a következő csere `<`-t csinál belőle. Ez hiba! Az `&amp;` cseréje mindig az **utolsó** legyen.

(A szabvány több mint 2000 nevesített hivatkozást ismer, és számosakat is, mint az `&#337;` vagy az `&#x151;`. Ezeket a 3. modulban rendesen megoldjuk.)
:::

:::note A script-teszt csalafinta
Nézd meg: `<script>if (a < b) {}</script>`. A tokenizered a `< b) {}</script>`-et tagnak fogja hinni! A teszt mégis átmegy, mert minden, ami a `<script>` után jön, a `skip_depth` miatt kimarad, egészen a következő `</script>` zárótagig. A valódi böngésző a `<script>` belsejét egy külön tokenizer-állapotban olvassa, ahol a `<` nem kezd tagot. Ezt a 3. modulban építjük meg.
:::

A `CursorTokenizer.tokenize(html)` működik, mert a `CursorTokenizer` egy unit struct, vagyis a neve egyben az egyetlen értéke is. Ne felejtsd el: `use tokenizer::{CursorTokenizer, Tokenizer};`, mert a trait metódusa csak akkor hívható, ha a trait is látható.
---
A kezdőtagnál a név szerinti elágazáshoz `match name.as_str() { "script" | "style" => ..., "title" => ..., "br" => ..., _ => { if let Some(kind) = block_kind(&name) { flush(&mut page, &mut current); current.kind = kind; } } }`
---
A szövegnél a cím: `page.title.get_or_insert_with(String::new).push_str(&t);`. A `get_or_insert_with` egy `&mut String`-et ad: ha a cím még `None`, előbb létrehoz egy üreset. A cím szóközeit a parse végén vond össze és vágd le.
---
A `flush`:
```rust

        .text
        .split('\n')
        .map(|line| util::collapse_whitespace(line).trim().to_string())
        .filter(|line| !line.is_empty())
        .collect();
```

Fontos: a szövegtokenek szóközeit **már hozzáadás előtt** vond össze, különben a forrásban lévő sortörések is `'\n'`-ként maradnak, és a `<br>`-rel összekeverednek.

:::solution
```rust
pub mod cursor;
pub mod tag;
pub mod token;
pub mod tokenizer;
pub mod util;

use rozsda_core::{Block, BlockKind, HtmlParser, Page};
use token::Token;
use tokenizer::{CursorTokenizer, Tokenizer};

pub struct OwnHtmlParser;

impl HtmlParser for OwnHtmlParser {
    fn name(&self) -> &'static str {
        "Rozsda (saját)"
    }

    fn parse(&self, html: &str) -> Page {
        let mut page = Page::default();
        let mut current = Block { kind: BlockKind::Paragraph, text: String::new() };
        let mut in_title = false;
        let mut skip_depth = 0;

        for token in CursorTokenizer.tokenize(html) {
            match token {
                Token::StartTag { name, .. } => match name.as_str() {
                    "script" | "style" => skip_depth += 1,
                    "title" => in_title = true,
                    "br" => current.text.push('\n'),
                    _ => {
                        if let Some(kind) = block_kind(&name) {
                            flush(&mut page, &mut current);
                            current.kind = kind;
                        }
                    }
                },
                Token::EndTag { name } => match name.as_str() {
                    "script" | "style" => skip_depth = (skip_depth - 1).max(0),
                    "title" => in_title = false,
                    _ => {
                        if block_kind(&name).is_some() {
                            flush(&mut page, &mut current);
                        }
                    }
                },
                Token::Text(t) => {
                    if skip_depth > 0 {
                        continue;
                    }
                    let t = util::collapse_whitespace(&decode_entities(&t));
                    if in_title {
                        page.title.get_or_insert_with(String::new).push_str(&t);
                    } else {
                        current.text.push_str(&t);
                    }
                }
                Token::Comment(_) => {}
            }
        }
        flush(&mut page, &mut current);
        if let Some(t) = &mut page.title {
            *t = util::collapse_whitespace(t).trim().to_string();
        }
        page
    }
}

fn block_kind(name: &str) -> Option<BlockKind> {
    match name {
        "h1" => Some(BlockKind::Heading(1)),
        "h2" => Some(BlockKind::Heading(2)),
        "h3" | "h4" | "h5" | "h6" => Some(BlockKind::Heading(3)),
        "li" => Some(BlockKind::ListItem),
        "p" | "div" | "section" | "article" | "header" | "footer" | "main" | "blockquote" | "pre"
        | "ul" | "ol" | "table" | "tr" | "body" => Some(BlockKind::Paragraph),
        _ => None,
    }
}

fn flush(page: &mut Page, current: &mut Block) {
    let lines: Vec<String> = current
        .text
        .split('\n')
        .map(|line| util::collapse_whitespace(line).trim().to_string())
        .filter(|line| !line.is_empty())
        .collect();
    if !lines.is_empty() {
        page.blocks.push(Block { kind: current.kind, text: lines.join("\n") });
    }
    current.text.clear();
    current.kind = BlockKind::Paragraph;
}

pub fn decode_entities(s: &str) -> String {
    s.replace("&lt;", "<")
        .replace("&gt;", ">")
        .replace("&quot;", "\"")
        .replace("&#39;", "'")
        .replace("&nbsp;", "\u{00A0}")
        .replace("&amp;", "&")
}
```
