:::goal
Elkészül a CSS-parser: egy teljes stíluslapból szabályok listája lesz, mindegyikben a szelektorokkal és a deklarációkkal. Megtanulod, hogyan **tűri a hibákat** a CSS: egy elgépelt deklaráció, egy ismeretlen at-szabály vagy egy hiányzó `}` sem rontja el a többi szabályt.
:::

## A célszerkezet

```rust
#[derive(Debug, Clone, PartialEq)]
pub struct Declaration {
    pub name: String,
    pub value: Vec<Token>,
    pub important: bool,
}

#[derive(Debug, Clone, PartialEq)]
pub struct Rule {
    pub selectors: Vec<Selector>,
    pub declarations: Vec<Declaration>,
}

#[derive(Debug, Clone, PartialEq, Default)]
pub struct Stylesheet {
    pub rules: Vec<Rule>,
}
```

Az érték egyelőre **nyers tokenek** listája (`Vec<Token>`). Hogy a `#c2410c` szín, a `2em` meg betűméret, azt a következő leckében döntjük el. A parser dolga csak a szerkezet: mi a név, mi az érték, és fontos-e.

## A hibatűrés szabályai

A CSS Syntax szabvány pontosan leírja, mi a teendő hibánál. Négy szabály kell nekünk:

| Hiba | Példa | Mit csinál a böngésző |
|---|---|---|
| Rossz deklaráció | `color red;` (nincs `:`) | Csak ezt az egy deklarációt hagyja ki, a következő `;`-ig. |
| Érvénytelen szelektor | `a:hover { … }` (nálunk) | Az egész szabályt kihagyja, a `{ … }` blokkal együtt. |
| Ismeretlen at-szabály | `@media print { … }`, `@import "x.css";` | Átugorja: vagy a következő `;`-ig, vagy a blokkja végéig. |
| A fájl vége | `p { color: red` | A fájl vége **mindent bezár**: a szabály érvényes. |

:::adhd Miért ilyen engedékeny?
Ugyanazért, amiért a HTML: a web a világ legnagyobb, legrégebbi és legkevésbé karbantartott kódbázisa. Egy 2004-es weboldal elgépelt pontosvesszője miatt ma sem szabad, hogy az egész oldal stílus nélkül jelenjen meg. Ha valami ismeretlen, kihagyjuk, és megyünk tovább.
:::

## A blokkok vége: mélységszámlálás

Egy `@media print { p { color: black } }` blokkban két `}` is van. A külső blokk végét a mélység számlálásával találjuk meg: a `{` növeli, a `}` csökkenti, és ahol újra 0 lesz, ott a vége. Ezt a segédet most megadom:

```rust
/// A `{` indexétől megkeresi a hozzá tartozó `}` indexét (a beágyazott blokkokat átugorva).
/// Ha nincs ilyen, a tokenek hosszát adja.
fn block_end(tokens: &[Token], open: usize) -> usize {
    let mut depth = 0;
    for (i, t) in tokens.iter().enumerate().skip(open) {
        match t {
            Token::LeftBrace => depth += 1,
            Token::RightBrace => {
                depth -= 1;
                if depth == 0 {
                    return i;
                }
            }
            _ => {}
        }
    }
    tokens.len()
}
```

A deklarációk között ugyanez a gond a zárójelekkel: a `background: url(a;b)` belsejében álló `;` nem választja el a deklarációkat. Ezért a `parse_declarations` is számolja a zárójel-mélységet. A `Function` token (pl. `url(`) is nyitó zárójelnek számít!

## `!important`

A deklaráció végén álló `!important` megjelöli a deklarációt fontosnak (a kaszkádnál látjuk, mit jelent). A `!` és az `important` között lehet szóköz, és a kis- és nagybetű nem számít. Ezt a segédet is megadom, mert sok benne az indexelés:

```rust
/// Ha az érték `! important`-ra végződik, levágja, és igazat ad.
fn strip_important(value: &mut Vec<Token>) -> bool {
    let Some(Token::Ident(last)) = value.last() else {
        return false;
    };
    if !last.eq_ignore_ascii_case("important") {
        return false;
    }
    let mut j = value.len() - 1;
    while j > 0 && value[j - 1] == Token::Whitespace {
        j -= 1;
    }
    if j == 0 || value[j - 1] != Token::Delim('!') {
        return false;
    }
    value.truncate(j - 1);
    while value.last() == Some(&Token::Whitespace) {
        value.pop();
    }
    true
}
```

Az első sor egy **let-else**: „ha a minta illik, kösd meg a változót, különben fuss le az `else` ág, aminek ki kell lépnie” (`return`, `break`, `continue`). A korai kilépés (*early return*) így nem tolja jobbra az egész függvényt egymásba ágyazott `if let`-ekkel.

:::hint
A `parse_declaration` két szelet-mintával elkészül:
```rust
let (name, rest) = match trim_ws(tokens) {
    [Token::Ident(name), rest @ ..] => (name, rest),
    _ => return None,
};
let rest = match trim_ws(rest) {
    [Token::Colon, rest @ ..] => rest,
    _ => return None,
};
```
Utána: `let mut value = trim_ws(rest).to_vec();`, majd `strip_important(&mut value)`.
---
A `parse_declarations` egy `for (i, t) in tokens.iter().enumerate()` ciklus, egy `depth` és egy `start` változóval. A `;`-nél (ha `depth == 0`) a `&tokens[start..i]` egy darab, és `start = i + 1`. A ciklus után az utolsó darabot (`&tokens[start..]`) se felejtsd el! Az eredményt kényelmes `out.extend(parse_declaration(…))`-szel hozzáadni: az `extend` egy `Option`-t is elfogad, és a `None`-t egyszerűen kihagyja.
---
A `parse_stylesheet` szabály-ágában:
```rust
let start = i;
while i < tokens.len() && tokens[i] != Token::LeftBrace {
    i += 1;
}
if i == tokens.len() {
    break; // blokk nélküli szemét a végén
}

let body = &tokens[i + 1..end];
// ha a parse_selector_list(&tokens[start..i]) Some, jöhet a Rule
i = end + 1;
```
Ha a blokk nincs lezárva, a `block_end` a tokenek hosszát adja, így a `body` a fájl végéig tart (a fájl vége mindent bezár).

:::solution
```rust
//! A CSS-parser: tokenekből szabályok és deklarációk.

use crate::selector::{Selector, parse_selector_list};
use crate::tokenizer::{Token, tokenize, trim_ws};

/// Egy at-szabály (pl. `@media … { … }` vagy `@import …;`) átugrása. A következő index.
fn skip_at_rule(tokens: &[Token], start: usize) -> usize {
    let mut i = start;
    while i < tokens.len() {
        match tokens[i] {
            Token::Semicolon => return i + 1,
            Token::LeftBrace => return block_end(tokens, i) + 1,
            _ => i += 1,
        }
    }
    i
}

pub fn parse_declaration(tokens: &[Token]) -> Option<Declaration> {
    let (name, rest) = match trim_ws(tokens) {
        [Token::Ident(name), rest @ ..] => (name, rest),
        _ => return None,
    };
    let rest = match trim_ws(rest) {
        [Token::Colon, rest @ ..] => rest,
        _ => return None,
    };
    let mut value = trim_ws(rest).to_vec();
    let important = strip_important(&mut value);
    if value.is_empty() {
        return None;
    }
    Some(Declaration {
        name: name.to_ascii_lowercase(),
        value,
        important,
    })
}

/// Pontosvesszővel elválasztott deklarációk. A zárójelen belüli `;` nem választ el.
pub fn parse_declarations(tokens: &[Token]) -> Vec<Declaration> {
    let mut out = Vec::new();
    let mut depth = 0;
    let mut start = 0;
    for (i, t) in tokens.iter().enumerate() {
        match t {
            Token::Function(_) | Token::LeftParen => depth += 1,
            Token::RightParen if depth > 0 => depth -= 1,
            Token::Semicolon if depth == 0 => {
                out.extend(parse_declaration(&tokens[start..i]));
                start = i + 1;
            }
            _ => {}
        }
    }
    out.extend(parse_declaration(&tokens[start..]));
    out
}

pub fn parse_stylesheet(css: &str) -> Stylesheet {
    let tokens = tokenize(css);
    let mut rules = Vec::new();
    let mut i = 0;
    while i < tokens.len() {
        match tokens[i] {
            Token::Whitespace => i += 1,
            Token::AtKeyword(_) => i = skip_at_rule(&tokens, i),
            _ => {
                let start = i;
                while i < tokens.len() && tokens[i] != Token::LeftBrace {
                    i += 1;
                }
                if i == tokens.len() {
                    break; // blokk nélküli szemét a végén
                }
                let end = block_end(&tokens, i);
                let body = &tokens[i + 1..end];
                if let Some(selectors) = parse_selector_list(&tokens[start..i]) {
                    rules.push(Rule {
                        selectors,
                        declarations: parse_declarations(body),
                    });
                }
                i = end + 1;
            }
        }
    }
    Stylesheet { rules }
}
```
(A structok, a `block_end` és a `strip_important` a lecke korábbi részében van.)

A 14. modulban (Modern CSS) visszatérünk rá. Addig ugyanaz a helyzet, mint egy régi böngészőben, ami még nem ismerte a media query-ket.

fn split_declarations(s: &str) -> Vec<(String, String, bool)> {
    let mut out = Vec::new();
    let parts: Vec<String> = s.split(';').map(|p| p.to_string()).collect();
    for part in parts {
        let chars: Vec<char> = part.chars().collect();
        let Some(colon) = chars.iter().position(|&c| c == ':') else {
            continue;
        };
        let name: String = chars[..colon].iter().collect::<String>().trim().to_string();
        if name.is_empty() || !name.chars().all(|c| c.is_ascii_alphanumeric() || c == '-') {
            continue;
        }
        let mut value: String = chars[colon + 1..].iter().collect::<String>().trim().to_string();
        let mut important = false;
        let lower = value.to_lowercase();
        if let Some(bang) = lower.rfind('!')
            && lower[bang + 1..].trim() == "important"
        {
            important = true;
            value = value[..bang].trim_end().to_string();
        }
        if value.is_empty() {
            continue;
        }
        out.push((name.to_lowercase(), value.clone(), important));
    }
