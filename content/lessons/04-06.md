## Az értékek fajtái

| Érték | Példák | Mit jelent |
|---|---|---|
| Kulcsszó (*keyword*) | `block`, `bold`, `none`, `inherit` | egy előre definiált szó |
| Hossz (*length*) | `12px`, `1.5em`, `2rem` | szám és mértékegység |
| Százalék (*percentage*) | `150%` | valaminek a százaléka (hogy minek, az a tulajdonságtól függ) |
| Szám (*number*) | `700`, `1.5` | mértékegység nélküli szám |
| Szín (*color*) | `#c2410c`, `#fff`, `navy`, `rgb(28, 25, 23)` | |

A mértékegységek közül hármat ismerünk:

- **`px`**: CSS-pixel. Egy abszolút méret (a képernyőn közel egy fizikai pixel, nagy felbontású kijelzőn több).
- **`em`**: az elem **betűméretének** többszöröse. A `font-size: 2em` a **szülő** betűméretének kétszerese.
- **`rem`**: a **gyökérelem** (`<html>`) betűméretének többszöröse. Ez nem halmozódik úgy, mint az `em`.

Az `em` és a `rem` értékét most még nem számoljuk ki, csak megjegyezzük. A 04-10-ben lesz belőle pixel, amikor már tudjuk, mekkora a szülő betűmérete.

## Színek

Egy szín négy bájt: piros, zöld, kék és **alfa** (átlátszóság: 0 = teljesen átlátszó, 255 = fedő). A `Color` a `rozsda-core`-ba kerül, mert a rajzoló (és később a profi stílusmotor) is használja:

```rust
//! A stílusok közös típusai: ezeket adja a saját és a profi stílusmotor is.

/// Egy szín, átlátszósággal (alfa: 0 = teljesen átlátszó, 255 = fedő).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Color {
    pub r: u8,
    pub g: u8,
    pub b: u8,
    pub a: u8,
}
```

A CSS háromféle színírást ismer (a teljes lista ennél hosszabb):

| Írásmód | Példa | Jelentés |
|---|---|---|
| `#rrggbb` | `#c2410c` | hexadecimális: `c2` = 194 piros, `41` = 65 zöld, `0c` = 12 kék |
| `#rgb` | `#fa0` | rövid forma: minden jegy megduplázva, `#ffaa00` |
| név | `navy` | a CSS 148 színnevének egyike |
| `rgb()` | `rgb(28, 25, 23)` | tízes számrendszerben, 0–255, a túl nagy érték levágódik |
| `rgba()` | `rgba(0, 0, 0, 0.5)` | negyedik érték: alfa 0 és 1 között |

A rövid formánál egy jegy duplázása szorzás 17-tel: `0xA` = 10, és `0xAA` = 10·16 + 10 = 10·17 = 170.

@@ Érettségi

@@ C#
`Convert.ToByte("c2", 16)` vagy `byte.Parse("c2", NumberStyles.HexNumber)`.
@@ Python
`int("c2", 16)`. A `0xc2` literál is ugyanaz, mint Rustban.
@@ C++

```rust test
        g: 0,
```

```rust
//! CSS-értékek: kulcsszavak, hosszok, százalékok, számok és színek.

use crate::tokenizer::{Token, trim_ws};
use rozsda_core::style::Color;

fn parse_unit(unit: &str) -> Option<Unit> {
    match unit.to_ascii_lowercase().as_str() {
        "px" => Some(Unit::Px),
        "em" => Some(Unit::Em),
        "rem" => Some(Unit::Rem),
        _ => None,
    }
}

/// `#rgb` vagy `#rrggbb` (a `#` nélkül).
pub fn hex_color(hex: &str) -> Option<Color> {
    let digits: Vec<u8> = hex
        .chars()
        .map(|c| c.to_digit(16).map(|d| d as u8))
        .collect::<Option<_>>()?;
    match digits.as_slice() {
        [r, g, b] => Some(Color::rgb(r * 17, g * 17, b * 17)),
        [r1, r2, g1, g2, b1, b2] => Some(Color::rgb(r1 * 16 + r2, g1 * 16 + g2, b1 * 16 + b2)),
        _ => None,
    }
}

/// A CSS 148 színnevéből a leggyakoribbak.
pub fn named_color(name: &str) -> Option<Color> {
    let (r, g, b) = match name {
        "black" => (0, 0, 0),
        "white" => (255, 255, 255),
        "red" => (255, 0, 0),
        "green" => (0, 128, 0),
        "blue" => (0, 0, 255),
        "yellow" => (255, 255, 0),
        "orange" => (255, 165, 0),
        "purple" => (128, 0, 128),
        "gray" | "grey" => (128, 128, 128),
        "silver" => (192, 192, 192),
        "maroon" => (128, 0, 0),
        "navy" => (0, 0, 128),
        "teal" => (0, 128, 128),
        "olive" => (128, 128, 0),
        "lime" => (0, 255, 0),
        "aqua" | "cyan" => (0, 255, 255),
        "fuchsia" | "magenta" => (255, 0, 255),
        "pink" => (255, 192, 203),
        "brown" => (165, 42, 42),
        "transparent" => return Some(Color::TRANSPARENT),
        _ => return None,
    };
    Some(Color::rgb(r, g, b))
}

/// `rgb(r, g, b)` vagy `rgba(r, g, b, a)` argumentumai (a záró zárójel nélkül).
fn rgb_function(args: &[Token]) -> Option<Color> {
    let numbers: Vec<f32> = args
        .split(|t| *t == Token::Comma)
        .map(|part| match trim_ws(part) {
            [Token::Number(n)] => Some(*n),
            _ => None,
        })
        .collect::<Option<_>>()?;
    let channel = |v: f32| v.round().clamp(0.0, 255.0) as u8;
    match numbers.as_slice() {
        [r, g, b] => Some(Color::rgb(channel(*r), channel(*g), channel(*b))),
        [r, g, b, a] => Some(Color {
            r: channel(*r),
            g: channel(*g),
            b: channel(*b),
            a: (a.clamp(0.0, 1.0) * 255.0).round() as u8,
        }),
        _ => None,
    }
}

/// Egyetlen érték egy deklarációból. A több részből álló értékeket (pl. `0 auto`) még nem ismerjük.
pub fn parse_value(tokens: &[Token]) -> Option<Value> {
    match trim_ws(tokens) {
        [Token::Ident(word)] => {
            let word = word.to_ascii_lowercase();
            Some(match named_color(&word) {
                Some(c) => Value::Color(c),
                None => Value::Keyword(word),
            })
        }
        [Token::Hash(hex)] => hex_color(hex).map(Value::Color),
        [Token::Number(n)] => Some(Value::Number(*n)),
        [Token::Percentage(p)] => Some(Value::Percentage(*p)),
        [Token::Dimension(n, unit)] => parse_unit(unit).map(|u| Value::Length(*n, u)),
        [Token::Function(name), args @ .., Token::RightParen]
            if name.eq_ignore_ascii_case("rgb") || name.eq_ignore_ascii_case("rgba") =>
        {
            rgb_function(args).map(Value::Color)
        }
        _ => None,
    }
}
```

:::why Miért `const fn` az `rgb`?
A `const fn` olyan függvény, amit a fordító **fordítási időben** is ki tud értékelni. Ezért írhatod: `pub const BLACK: Color = Color::rgb(0, 0, 0);`. A konstans értéke már a lefordított programban benne van, futásidőben semmibe nem kerül. Egy sima `fn`-nel ez nem fordulna le: a konstansok értékét a fordítónak kell kiszámolnia. A C++ `constexpr`-je ugyanez.

```rust
fn parse_color(s: &str) -> Option<(u8, u8, u8)> {
    let s: String = s.trim().to_string();
    if s.starts_with('#') {
        let hex: Vec<String> = s.chars().skip(1).map(|c| c.to_string()).collect();
        let full: Vec<String> = match hex.len() {
            3 => hex.iter().map(|c| format!("{c}{c}")).collect(),
            6 => hex.chunks(2).map(|p| p.concat()).collect(),
            _ => return None,
        };
        let mut out = Vec::new();
        for part in &full {
            out.push(u8::from_str_radix(part, 16).ok()?);
        }
        return Some((out[0], out[1], out[2]));
    }
    if !s.starts_with("rgb(") || !s.ends_with(')') {
        return None;
    }
    let inner: String = s.chars().skip(4).take(s.chars().count() - 5).collect();
    let parts: Vec<String> = inner.split(',').map(|p| p.trim().to_string()).collect();
    if parts.len() != 3 {
        return None;
    }
    let mut out = Vec::new();
    for p in parts {
        let v: f32 = p.parse().ok()?;
        out.push(v.round().clamp(0.0, 255.0) as u8);
    }
    Some((out[0], out[1], out[2]))
}
```
