## A `data:` cím: a tartalom maga a cím

Egy kis ikonért vagy egy pár soros oldalért kár egy külön kérést küldeni. A `data:` címben (RFC 2397) benne van az egész tartalom:

```text Ábra
data:text/html;charset=utf-8,<h1>Szia</h1>
     └──────── típus ───────┘ └── tartalom ──┘

data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA…
     └─ típus ─┘└jelző┘└──── base64 ────────────┘
```

- A `,` előtt a **MIME-típus** (media type). Ha üres, a szabvány szerint `text/plain;charset=US-ASCII`.
- A típus végén a `;base64` jelzi, hogy a tartalom **base64**-kódolt. Enélkül a tartalom szöveg, százalékkódolással (`%20` a szóköz, 08-01).

A CSS-ben gyakran látsz ilyet: `background: url(data:image/png;base64,…)`. A böngésző címsorába beírva is működik: próbáld ki a saját böngésződben a `data:text/html,<h1>Szia</h1>` címet!

A 08-02-ben láttad: a `data:` cím **átlátszatlan** (opaque), az egész a `path`-ba kerül. A `?` utáni részt viszont a parser lekérdezésnek veszi, ezért azt vissza kell ragasztani. A `#` utáni részlet nem tartozik a tartalomhoz.

### Base64: bájtok betűkkel

A base64 bármilyen bájtsorozatot 64 „biztonságos” karakterrel ír le: `A–Z`, `a–z`, `0–9`, `+`, `/`. Minden karakter 6 bitet hordoz, így **négy karakter három bájt** (4 × 6 = 3 × 8 = 24 bit):

```text Ábra
 S        z        i                    (bájtok)
 01010011 01111010 01101001             (24 bit)
 010100 110111 101001 101001            (4 × 6 bit)
 U      3      p      p                 (base64: 20, 55, 41, 41)
```

Ha a bájtok száma nem osztható hárommal, a végén `=` jelek töltik ki a négyest: a `Szia` (4 bájt) base64-ben `U3ppYQ==`. A böngészők „megbocsátók”: a szóközöket kihagyják, és a záró `=` el is maradhat. Egyetlen maradék karakter (6 bit) viszont nem ad ki egy bájtot: az hiba.

A dekódolás egy **bitpufferrel** megy: minden karakter 6 bitet tol be jobbról, és amint legalább 8 bit összegyűlt, kivesszük a felső 8-at.

## A `file:` cím: a saját géped

A `file:` cím egy helyi fájlra mutat. A gépnév üres (vagyis a saját géped), ezért van benne **három** perjel:

```text Ábra
file:///C:/Users/Rozsda/oldalak/pelda%20oldal.html     (Windows)
file:///home/rozsda/oldalak/pelda.html                 (Linux, macOS)
     └┘ üres gépnév
```

Windowson az útvonal `/C:/…` alakú. Fájlútvonal előtt a perjelet le kell venni, és a `%20`-at vissza kell alakítani szóközzé. A másik irányban egy relatív útvonalból (`oldalak/pelda.html`) előbb abszolút útvonal lesz (`std::path::absolute`), aztán a `\` jelekből `/`, és elé a `file://`.

A böngésző eddig is tudott fájlt megnyitni (a parancssorban egy útvonalat kapott), de most a fájl is egy **cím** lesz. Így a fájlban lévő relatív linkek (`masodik.html`) ugyanúgy oldódnak fel, mint a weben.

## Egy közös nyelv: `Resource`

A böngészőnek mindegy, honnan jön egy oldal: a hálózatról, a lemezről vagy a címből. Neki egy cím kell (ehhez képest relatívak a linkek), egy típus és a bájtok. Ez lesz a `Resource`. A `rozsda-core`-ba kerül, mert a 08-14-ben a profi hálózati crate is ezt fogja adni: a böngésző csak a core típusait ismeri.

```rust
//! Hálózat nélküli címek: a `data:` URL tartalma magában a címben van, a `file:` a saját gépre mutat.

use crate::percent::percent_decode;
use crate::url::{Url, UrlError};
use std::path::{Path, PathBuf};

/// Base64 (RFC 4648) a WHATWG „megbocsátó” szabályaival: a szóközök nem számítanak, a záró
/// `=` jelek elhagyhatók. Négy betű (4 × 6 bit) három bájt.
pub fn base64_decode(input: &str) -> Option<Vec<u8>> {
    let mut data: Vec<u8> = input.bytes().filter(|b| !b.is_ascii_whitespace()).collect();
    if data.len().is_multiple_of(4) {
        if data.ends_with(b"==") {
            data.truncate(data.len() - 2);
        } else if data.ends_with(b"=") {
            data.truncate(data.len() - 1);
        }
    }
    if data.len() % 4 == 1 {
        return None;
    }
    let mut out = Vec::with_capacity(data.len() * 3 / 4);
    let (mut buffer, mut bits) = (0u32, 0);
    for b in data {
        let value = match b {
            b'A'..=b'Z' => b - b'A',
            b'a'..=b'z' => b - b'a' + 26,
            b'0'..=b'9' => b - b'0' + 52,
            b'+' => 62,
            b'/' => 63,
            _ => return None,
        };
        buffer = (buffer << 6) | u32::from(value);
        bits += 6;
        if bits >= 8 {
            bits -= 8;
            out.push((buffer >> bits) as u8);
        }
    }
    Some(out)
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct DataUrl {
    pub mime: String,
    pub body: Vec<u8>,
}

/// `data:[típus][;base64],tartalom`. Ha nincs típus, a szabvány szerint `text/plain;charset=US-ASCII`.
pub fn parse_data_url(url: &Url) -> Option<DataUrl> {
    let rest = match &url.query {
        Some(query) => format!("{}?{query}", url.path),
        None => url.path.clone(),
    };
    let (mime, body) = rest.split_once(',')?;
    let mime = mime.trim();
    let base64 = mime.to_ascii_lowercase().ends_with(";base64");
    let mime = if base64 {
        mime[..mime.len() - ";base64".len()].trim()
    } else {
        mime
    };
    let body = percent_decode(body);
    let body = if base64 {
        base64_decode(&String::from_utf8_lossy(&body))?
    } else {
        body
    };
    let mime = if mime.is_empty() {
        "text/plain;charset=US-ASCII"
    } else {
        mime
    };
    Some(DataUrl {
        mime: mime.to_string(),
        body,
    })
}

/// Egy `file:` URL helyi útvonala. Windowson a `/C:/…` elejéről lekerül a perjel.
pub fn file_url_to_path(url: &Url) -> PathBuf {
    let decoded = String::from_utf8_lossy(&percent_decode(&url.path)).into_owned();
    let b = decoded.as_bytes();
    let drive = b.len() >= 3 && b[0] == b'/' && b[1].is_ascii_alphabetic() && b[2] == b':';
    PathBuf::from(if drive { &decoded[1..] } else { &decoded })
}

/// Egy helyi fájl `file:` URL-je: abszolút útvonal, `/` elválasztókkal.
pub fn path_to_file_url(path: &Path) -> Result<Url, UrlError> {
    let absolute =
        std::path::absolute(path).map_err(|_| UrlError::BadHost(path.display().to_string()))?;
    let mut text = absolute.to_string_lossy().replace('\\', "/");
    if !text.starts_with('/') {
        text.insert(0, '/'); // C:/… → /C:/…
    }
    Url::parse(&format!("file://{text}"))
}
```

```rust
    pub fn open(&mut self, url: &Url) -> Result<Resource, NetError> {
        match url.scheme.as_str() {
            "file" => Ok(Resource {
                url: url.to_string(),
                content_type: None,
                body: std::fs::read(file_url_to_path(url))?,
            }),
            "data" => {
                let data = parse_data_url(url).ok_or(NetError::BadDataUrl)?;
                Ok(Resource {
                    url: url.to_string(),
                    content_type: Some(data.mime),
                    body: data.body,
                })
            }
            _ => {
                let Fetched { url, response } = self.fetch(url)?;
                Ok(Resource {
                    url: url.to_string(),
                    content_type: response.header("Content-Type").map(String::from),
                    body: response.body,
                })
            }
        }
    }
```

```rust
fn base64_encode(data: &[u8]) -> String {
    let abc: Vec<char> = ('A'..='Z').chain('a'..='z').chain('0'..='9').chain(['+', '/']).collect();
    let mut bits = String::new();
    for byte in data {
        bits.push_str(&format!("{byte:08b}"));
    }
    let mut out = String::new();
    for group in bits.as_bytes().chunks(6) {
        let mut text = String::from_utf8(group.to_vec()).unwrap();
        while text.len() < 6 {
            text.push('0');
        }
        out.push(abc[usize::from_str_radix(&text, 2).unwrap()]);
    }
    while out.len() % 4 != 0 {
        out.push('=');
    }
    out
```

:::card
K: Mi van egy `data:` címben?
V: A tartalom maga: `data:típus[;base64],tartalom`. A típus nélküli a `text/plain;charset=US-ASCII`, a `;base64` jelzi a base64-kódolást, különben százalékkódolt szöveg.
:::

:::card
K: Hogyan lesz 3 bájtból 4 base64-karakter?
V: A 3 × 8 = 24 bitet 4 × 6 bites darabra vágjuk, és mindegyik egy karakter a 64 elemű ábécéből (`A–Z a–z 0–9 + /`). A csonka végét `=` jelek töltik ki.
:::
