## A `<!` utáni világ

A `TagOpen` állapotban a `!` a **MarkupDeclarationOpen** állapotba visz. Ez az állapot nem egy karaktert néz, hanem **előre** az egész folytatást:

| Ha ez következik | Akkor |
|---|---|
| `--` | komment kezdődik → **Comment** |
| `DOCTYPE` (kis- és nagybetű mindegy) | → **Doctype** |
| bármi más | parse error, hamis komment → **BogusComment** |

Az előrenézéshez két segédfüggvény kell. Iterátorokkal tömör és szép:

```rust
fn starts_with(&self, s: &str) -> bool {
    s.chars().enumerate().all(|(k, c)| self.input.get(self.pos + k) == Some(&c))
}

fn starts_with_ignore_case(&self, s: &str) -> bool {
    s.chars()
        .enumerate()
        .all(|(k, c)| matches!(self.input.get(self.pos + k), Some(x) if x.eq_ignore_ascii_case(&c)))
}
```

Az `enumerate()` sorszámot ad minden karakterhez, az `all()` pedig akkor igaz, ha **minden** elemre igaz a feltétel (és az első hamisnál megáll). Ez az 1. modul `Cursor::starts_with`-je, ciklus helyett iterátorral.

:::note A MarkupDeclarationOpen nem fogyaszt
A szabvány szerint ez az állapot csak megnézi, mi jön, és nem olvas be karaktert. A mi ciklusunk viszont minden kör elején beolvas egyet. Ezért az állapot első lépése egy `reconsume()`, ami visszalép, és onnantól úgy működik, mintha nem olvasott volna.
:::

## Kommentek

A rendes eset egyszerű: `<!--` után minden karakter a komment része, amíg el nem érünk a `-->`-ig. A szabványban ez hat állapot (CommentStart, CommentStartDash, Comment, CommentEndDash, CommentEnd, CommentEndBang…). Mi egyetlen állapottal oldjuk meg, de a fontos határeseteket a szabvány szerint kezeljük:

| Bemenet | Eredmény | Miért |
|---|---|---|
| `<!-- szia -->` | `Comment(" szia ")` | a rendes eset |
| `<!---->` | `Comment("")` | üres komment |
| `<!-->` | `Comment("")` | *abrupt-closing-of-empty-comment*: parse error, de lezárja |
| `<!--->` | `Comment("")` | ugyanez, egy kötőjellel |
| `<!-- nincs vége` | `Comment(" nincs vége")` | EOF: ami eddig volt, az a komment |
| `<?xml?>` | `Comment("?xml?")` | a `<?` hamis komment (régi XML-deklarációk miatt) |

## DOCTYPE

```html
<!DOCTYPE html>
```

Ez nem tag, hanem egy **deklaráció**, és ma már csak egy dolgot jelent: *„kérlek, szabvány szerint jeleníts meg”*. Ha hiányzik, a böngésző **quirks mode**-ba kapcsol, és utánozza a 90-es évek böngészőinek hibáit (pl. másképp számolja a dobozok méretét).

A régi HTML 4-es DOCTYPE-ok hosszúak voltak:

```html
<!DOCTYPE html PUBLIC "-//W3C//DTD HTML 4.01//EN" "http://www.w3.org/TR/html4/strict.dtd">
```

A szabvány a `PUBLIC` és a `SYSTEM` azonosítókat is külön állapotokban dolgozza fel, mert a quirks mode eldöntéséhez kellenek. Mi egyszerűsítünk: a `>`-ig mindent beolvasunk, és csak az első szót (a nevet) tartjuk meg, kisbetűsítve.

:::why Mi az a quirks mode, és miért él még?
A 90-es évek végén a böngészők rengeteg CSS-t hibásan valósítottak meg, és a weboldalak ezekre a hibákra épültek. Amikor a böngészők kijavították a hibákat, a régi oldalak szétestek volna. A megoldás a *DOCTYPE-váltás* lett: ha az oldal modern DOCTYPE-pal kezdődik, szabványos mód. Ha nincs DOCTYPE (vagy egy régi), quirks mode. Ma is milliónyi régi oldal fut quirks módban, ezért minden böngésző tartalmaz egy „hibautánzó” réteget. A szabványban külön fejezet szól róla. A Rozsda egyelőre csak a szabványos módot ismeri, de a DOCTYPE nevét azért eltároljuk.
:::

6. **Doctype**: a név előtti szóközöket átugorja, `>`-nél (vagy EOF-nál) kibocsát egy `Token::Doctype`-ot. A név az összegyűjtött szöveg **első szava**: `name.split_whitespace().next().unwrap_or("")`. Minden karakter kisbetűsítve gyűlik.
:::

```rust test
    #[test]
    fn comments() {
        assert_eq!(tokenize("a<!-- b -->c"), vec![text("a"), Token::Comment(" b ".into()), text("c"), Token::Eof]);
        assert_eq!(tokenize("<!---->"), vec![Token::Comment("".into()), Token::Eof]);
        assert_eq!(tokenize("<!-->x"), vec![Token::Comment("".into()), text("x"), Token::Eof]);
        assert_eq!(tokenize("<!-- nincs vége"), vec![Token::Comment(" nincs vége".into()), Token::Eof]);
        assert_eq!(tokenize("<?xml?>"), vec![Token::Comment("?xml?".into()), Token::Eof]);
    }

    #[test]
    fn doctype() {
        assert_eq!(tokenize("<!DOCTYPE html>"), vec![Token::Doctype { name: "html".into() }, Token::Eof]);
        assert_eq!(tokenize("<!doctype HTML>x"), vec![Token::Doctype { name: "html".into() }, text("x"), Token::Eof]);
        assert_eq!(
            tokenize("<!DOCTYPE html PUBLIC \"-//W3C//DTD HTML 4.01//EN\">"),
            vec![Token::Doctype { name: "html".into() }, Token::Eof]
        );
    }
```

:::hint
A MarkupDeclarationOpen:
```rust
State::MarkupDeclarationOpen => {
    self.reconsume();
    self.comment.clear();
    if self.starts_with("--") {
        self.pos += 2;
        self.state = State::Comment;
    } else if self.starts_with_ignore_case("DOCTYPE") {
        // ...
    } else {
        self.state = State::BogusComment;
    }
}
```
Itt nincs `match c`, mert a `c` nem érdekel minket: a reconsume visszaadja a bemenetnek.
---
A Comment állapotban az őrfeltételek sorrendje számít. Az első ág legyen a rendes lezárás (`Some('-') if self.starts_with("->")`), utána a két „üres komment” eset, aztán minden más. A `<!---->` esetén az első `-` után a `->` következik, tehát rögtön lezárul, üresen. Pont jó.
---
A Doctype-ban az első ág: `Some(c) if is_whitespace(c) && self.doctype_name.is_empty() => {}`. Ez csak a név **előtti** szóközöket hagyja ki. A név utáni szóközök bekerülnek, és a `split_whitespace().next()` választja le őket a végén.
:::

:::solution
```rust
fn starts_with(&self, s: &str) -> bool {
    s.chars().enumerate().all(|(k, c)| self.input.get(self.pos + k) == Some(&c))
}

fn starts_with_ignore_case(&self, s: &str) -> bool {
    s.chars()
        .enumerate()
        .all(|(k, c)| matches!(self.input.get(self.pos + k), Some(x) if x.eq_ignore_ascii_case(&c)))
}

// ... a TagOpen új ágai:
Some('!') => self.state = State::MarkupDeclarationOpen,
Some('?') => {
    self.comment.clear();
    self.reconsume();
    self.state = State::BogusComment;
}

// ... az új állapotok:
State::MarkupDeclarationOpen => {
    self.reconsume();
    self.comment.clear();
    if self.starts_with("--") {
        self.pos += 2;
        self.state = State::Comment;
    } else if self.starts_with_ignore_case("DOCTYPE") {
        self.pos += 7;
        self.doctype_name.clear();
        self.state = State::Doctype;
    } else {
        self.state = State::BogusComment;
    }
}
State::Comment => match c {
    Some('-') if self.starts_with("->") => {
        self.pos += 2;
        self.emit_comment();
        self.state = State::Data;
    }
    Some('>') if self.comment.is_empty() => {
        self.emit_comment();
        self.state = State::Data;
    }
    Some('-') if self.comment.is_empty() && self.starts_with(">") => {
        self.pos += 1;
        self.emit_comment();
        self.state = State::Data;
    }
    Some(c) => self.comment.push(c),
    None => {
        self.emit_comment();
        break;
    }
},
State::Doctype => match c {
    Some(c) if is_whitespace(c) && self.doctype_name.is_empty() => {}
    Some('>') => {
        let name = std::mem::take(&mut self.doctype_name);
        self.emit(Token::Doctype { name: name.split_whitespace().next().unwrap_or("").to_string() });
        self.state = State::Data;
    }
    Some(c) => self.doctype_name.push(c.to_ascii_lowercase()),
    None => {
        let name = std::mem::take(&mut self.doctype_name);
        self.emit(Token::Doctype { name: name.split_whitespace().next().unwrap_or("").to_string() });
        break;
    }
},
```
