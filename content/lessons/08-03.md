## Hová visz egy link?

A 06-06-ban a `resolve_link` egyszerűen az aktuális fájl mappájához fűzte a linket. Ez helyi fájlokra jó volt, de a weben a címeknek hat különböző formájuk lehet. Nézzük meg őket ugyanahhoz az alaphoz képest:

```text Ábra
alap:  http://pelda.hu/cikkek/2024/rozsda.html?lap=2#eleje
```

| Link (`href`) | Fajtája | Eredmény |
|---|---|---|
| `https://masik.hu/` | abszolút | `https://masik.hu/` |
| `//cdn.pelda.hu/a.css` | séma-relatív | `http://cdn.pelda.hu/a.css` |
| `/rolunk` | gyökér-relatív | `http://pelda.hu/rolunk` |
| `kep.png` | útvonal-relatív | `http://pelda.hu/cikkek/2024/kep.png` |
| `../index.html` | útvonal-relatív, felfelé | `http://pelda.hu/cikkek/index.html` |
| `?lap=3` | csak lekérdezés | `http://pelda.hu/cikkek/2024/rozsda.html?lap=3` |
| `#vege` | csak részlet | `http://pelda.hu/cikkek/2024/rozsda.html?lap=2#vege` |
| (üres) | ugyanez az oldal | `http://pelda.hu/cikkek/2024/rozsda.html?lap=2` |

A szabály lépcsőzetes. Ahol a link „kezdődik”, onnantól az övé, előtte minden az alapé:

- Ha van **sémája**, abszolút: semmi sem kell az alapból.
- Ha `//`-rel kezdődik, csak a séma jön az alapból.
- Ha `/`-rel, a séma és a gép jön az alapból, az útvonal az övé.
- Ha `?`-lel, az útvonal is az alapé, a lekérdezés az övé.
- Ha `#`-tel, a lekérdezés is az alapé.
- Különben az alap útvonalának **„mappájához”** fűzzük (az utolsó `/`-ig), és utána jöhet a `.` és a `..` feloldása, amit a 08-02-ben már megírtál.

:::note A „mappa” csak hasonlat
A `http://pelda.hu/cikkek/2024/rozsda.html` útvonala nem feltétlenül egy fájl egy mappában: a szerver bármit tehet vele. A relatív feloldás csak **szövegesen** kezeli az útvonalat: az utolsó `/` utáni rész cserélődik. Ezért fontos, hogy a mappára mutató címek `/`-re végződjenek: a `http://pelda.hu/cikkek` alapján a `kep.png` a `http://pelda.hu/kep.png`, a `http://pelda.hu/cikkek/` alapján viszont a `http://pelda.hu/cikkek/kep.png`.
:::

### Egy régi furcsaság

A `http:masik.html` egy http-oldalon **relatív** cím: a séma ugyanaz, mint az alapé, és nincs utána perjel, ezért a böngésző úgy kezeli, mintha csak `masik.html` lenne. Egy https-oldalon ugyanez a link viszont abszolút, és egy hibás cím lenne belőle. A szabvány a régi weboldalak miatt tartja meg ezt a viselkedést.

### Átlátszatlan alapok

Egy `data:` vagy `mailto:` címhez képest nincs értelme a `kep.png`-nek: nincs mappa, nincs gép. Ilyenkor hiba a vége. Egyetlen kivétel a `#részlet`, mert az bármilyen címhez hozzátehető.

```rust
    /// Relatív cím feloldása ehhez a címhez (az alaphoz) képest.
    fn resolve(&self, input: &str) -> Result<Url, UrlError> {
        if let Some(fragment) = input.strip_prefix('#') {
            return Ok(Url {
                fragment: Some(percent_encode(fragment, EncodeSet::Fragment)),
                ..self.clone()
            });
        }
        if self.cannot_be_a_base() {
            return Err(UrlError::CannotBeABase);
        }
        let special = self.is_special();
        let is_slash = |c: char| c == '/' || (special && c == '\\');
        let mut chars = input.chars();
        let (first, second) = (chars.next(), chars.next());
        if first.is_some_and(is_slash) && second.is_some_and(is_slash) {
            // `//masik.hu/x`: csak a séma marad
            return Url::parse_authority(self.scheme.clone(), &input[2..]);
        }
        let (host, port) = (self.host.clone(), self.port);
        let scheme = self.scheme.clone();
        match first {
            // `/x`: a gép marad, az útvonal új
            Some(c) if is_slash(c) => Url::with_path(scheme, host, port, input),
            // üres: ugyanaz az oldal, részlet nélkül
            None => Ok(Url {
                fragment: None,
                ..self.clone()
            }),
            // `?q`: ugyanaz az útvonal, új lekérdezés
            Some('?') => Url::with_path(scheme, host, port, &format!("{}{input}", self.path)),
            // `kep.png`, `../a`: az alap „mappájához” képest
            _ => {
                let dir = &self.path[..self.path.rfind('/').map_or(0, |i| i + 1)];
                Url::with_path(scheme, host, port, &format!("{dir}{input}"))
            }
        }
    }
```
:::

A `Url { fragment: …, ..self.clone() }` a **struct update** szintaxis: egy új érték, aminek a megadott mezői az újak, a többi a `self` másolatából jön.

:::why Mélyvíz: a `<base>` elem
Egy HTML-oldal a `<head>`-ben át is állíthatja az alapcímet: `<base href="https://cdn.pelda.hu/">`. Ilyenkor az oldal összes relatív linkje ehhez képest értendő, nem az oldal saját címéhez. A Rozsda ezt még nem tudja. Ha egyszer beépíted, a `Page`-nek kell majd egy „alapcím” a végső cím mellett.

A `javascript:` linkek (`<a href="javascript:…">`) is abszolút címek, a sémájuk `javascript`. A böngésző nem tölti be őket, hanem lefuttatja a kódot. A 13. modulban, amikor lesz JS-motorunk, ez is szóba kerül.

fn relative_path(from: &str, to: &str) -> String {
    let from_dirs: Vec<&str> = from[..from.rfind('/').unwrap_or(0)]
        .split('/')
        .filter(|s| !s.is_empty())
        .collect();
    let to_segments: Vec<&str> = to.trim_start_matches('/').split('/').collect();
    let to_dirs = &to_segments[..to_segments.len() - 1];
    let common = from_dirs
