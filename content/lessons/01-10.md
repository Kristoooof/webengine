## Closure: névtelen függvény

```rust
let is_tag_char = |c: char| c.is_ascii_alphanumeric() || c == '-';
println!("{}", is_tag_char('h'));   // true
```

A `|paraméterek| törzs` egy **closure**: kis, névtelen függvény, amit változóba tehetsz vagy paraméterként átadhatsz. A típusokat általában ki sem kell írni.

A closure „befogja” (capture) a környezetében lévő változókat. A sima függvény ezt nem tudja:

```rust
let quote = '"';
let not_quote = |c: char| c != quote;   // a quote-ot a környezetből veszi
```

:::compare
@@ C#
```csharp
Func<char, bool> notQuote = c => c != quote;
```
@@ C++
```cpp
auto not_quote = [quote](char c) { return c != quote; };
```
@@ Python
```python
not_quote = lambda c: c != quote
```
@@ Rust
```rust
let not_quote = |c: char| c != quote;
```
:::

### A kurzor fejlesztése

Az előző leckében a `consume_while` egy `fn(char) -> bool` paramétert kapott. Ez **nem** fogad el olyan closure-t, ami befog valamit, például a fenti `not_quote`-ot. Írd át így:

```rust
fn consume_while(&mut self, pred: impl Fn(char) -> bool) -> String {
    // a törzs ugyanaz marad
}
```

Az `impl Fn(char) -> bool` jelentése: *„bármi, amit `char`-ral meg lehet hívni, és `bool`-t ad”*. Ez a sima függvényeket és a befogó closure-öket is elfogadja. (A háttérben ez generikus kód, erről a traiteknél lesz szó.)

## Iterátorok

Az iterátor bármi, ami egymás után ad elemeket. Ilyen a `.chars()` és a `.char_indices()` is. Az igazi ereje a **láncolás**:

```rust
let tags = vec!["div", "p", "span", "p"];

let long: Vec<&str> = tags
    .iter()                        // végigmegy rajta (referenciákat ad: &&str)
    .filter(|t| t.len() > 1)       // csak ami 1-nél hosszabb
    .copied()                      // &&str → &str
    .collect();                    // összegyűjti egy Vec-be
// ["div", "span"]

let upper: Vec<String> = tags.iter().map(|t| t.to_uppercase()).collect();
// ["DIV", "P", "SPAN", "P"]

let count_p = tags.iter().filter(|t| **t == "p").count();   // 2
let any_span = tags.iter().any(|t| *t == "span");           // true
let first_long = tags.iter().find(|t| t.len() > 3);         // Some(&"span")
```

| Metódus | Mit csinál |
|---|---|
| `map(f)` | Minden elemet átalakít |
| `filter(f)` | Csak azokat tartja meg, amikre `f` igaz |
| `filter_map(f)` | Átalakít **és** szűr: `f` `Option`-t ad, és csak a `Some`-ok maradnak |
| `enumerate()` | `(index, elem)` párokat ad |
| `count()`, `sum()` | Megszámol / összead |
| `any(f)`, `all(f)` | Van-e olyan / mind olyan-e |
| `find(f)`, `position(f)` | Az első olyan elem / annak indexe (`Option`) |
| `collect()` | Gyűjteménybe gyűjt (`Vec`, `String`, `HashMap`…) |

:::note Az iterátorok lusták
A `map` és a `filter` önmagában **semmit nem csinál**, csak „felírja”, mit kell majd tenni. A munka akkor történik meg, amikor egy „fogyasztó” (`collect`, `count`, `for` ciklus…) elkéri az elemeket. Ezért az iterátor-láncok gyakran pont olyan gyorsak, mint egy kézzel írt ciklus. A Rust fordító egyetlen ciklussá optimalizálja őket.
:::

:::compare
@@ C# (LINQ)
```csharp
var upper = tags.Select(t => t.ToUpper()).ToList();
var countP = tags.Count(t => t == "p");
```
A Rust iterátorai nagyon hasonlítanak a LINQ-ra: `Select` = `map`, `Where` = `filter`, `ToList` = `collect`.
@@ Python
```python
upper = [t.upper() for t in tags]
count_p = sum(1 for t in tags if t == "p")
```
@@ Rust
```rust
let upper: Vec<String> = tags.iter().map(|t| t.to_uppercase()).collect();
let count_p = tags.iter().filter(|t| **t == "p").count();
```
:::

:::tip Mi az a **t?
A `tags.iter()` referenciákat ad az elemekre, a `filter` pedig még egy referenciát tesz eléjük, így a closure `&&&str`-t kap. A `**t` kétszer „lép át” a referencián. Ne ijedj meg tőle: ha rossz számú `*`-ot írsz, a fordító megmondja, hány kell. Idővel ránézésre fogod tudni.
:::

## HashMap: kulcs–érték tár

```rust
use std::collections::HashMap;

let mut counts: HashMap<String, usize> = HashMap::new();
counts.insert(String::from("p"), 1);
println!("{:?}", counts.get("p"));     // Some(1)

// A legszebb számlálás: az entry API
*counts.entry(String::from("div")).or_insert(0) += 1;
```

Az `entry(kulcs).or_insert(0)` jelentése: *„add ide a kulcshoz tartozó értéket, és ha még nincs, tedd be 0-val”*. Egy `&mut usize`-t ad vissza, a `*` pedig magát az értéket éri el, amit így megnövelhetsz.

## Te jössz: tokenlista-elemzés

:::task
Írd át a `consume_while`-t `impl Fn(char) -> bool`-ra, és írd meg ezt a három függvényt:

1. `fn text_content(tokens: &[Token]) -> String`: az összes szövegtoken összefűzve (a böngészőben ez a `element.textContent`).
2. `fn tag_counts(tokens: &[Token]) -> HashMap<String, usize>`: melyik kezdőtag hányszor fordul elő.
3. `fn element_names(tokens: &[Token]) -> Vec<&str>`: a kezdőtagok nevei, sorrendben.

Ne felejtsd el a fájl tetejére: `use std::collections::HashMap;`
:::

```rust test
    fn sample() -> Vec<Token> {
        vec![
            Token::StartTag { name: "p".into(), self_closing: false },
            Token::Text("Szia, ".into()),
            Token::StartTag { name: "b".into(), self_closing: false },
            Token::Text("Rozsda".into()),
            Token::EndTag { name: "b".into() },
            Token::EndTag { name: "p".into() },
            Token::StartTag { name: "p".into(), self_closing: false },
            Token::Comment("x".into()),
            Token::Text("!".into()),
            Token::EndTag { name: "p".into() },
        ]
    }

    #[test]
    fn analysis_text() {
        assert_eq!(text_content(&sample()), "Szia, Rozsda!");
        assert_eq!(text_content(&[]), "");
    }

    #[test]
    fn analysis_counts() {
        let c = tag_counts(&sample());
        assert_eq!(c.get("p"), Some(&2));
        assert_eq!(c.get("b"), Some(&1));
        assert_eq!(c.get("div"), None);
    }

    #[test]
    fn analysis_names() {
        assert_eq!(element_names(&sample()), vec!["p", "b", "p"]);
    }
```

:::hint
A `text_content`-hez a `filter_map` a legszebb. Minden tokenre egy `match`, ami szövegnél `Some(s.as_str())`-t, minden másnál `None`-t ad. A `collect()` pedig `&str`-ekből közvetlenül `String`-et tud gyűjteni (összefűzi őket)!
---
A `tag_counts`-nál egy sima `for t in tokens` ciklus és egy `if let Token::StartTag { name, .. } = t` a legolvashatóbb. Benne: `*counts.entry(name.clone()).or_insert(0) += 1;`. A `clone` azért kell, mert a HashMap saját `String` kulcsot akar, a token pedig csak kölcsönben van nálunk.
---
Az `element_names` ugyanaz a minta, mint a `text_content`, csak a `StartTag` nevét adod vissza (`Some(name.as_str())`), és `Vec`-be gyűjtesz. Észrevetted? A visszaadott `&str`-ek a bemeneti tokenekből kölcsönzött szeletek, másolás nélkül.
:::

:::solution
```rust
use std::collections::HashMap;

fn text_content(tokens: &[Token]) -> String {
    tokens
        .iter()
        .filter_map(|t| match t {
            Token::Text(s) => Some(s.as_str()),
            _ => None,
        })
        .collect()
}

fn tag_counts(tokens: &[Token]) -> HashMap<String, usize> {
    let mut counts = HashMap::new();
    for t in tokens {
        if let Token::StartTag { name, .. } = t {
            *counts.entry(name.clone()).or_insert(0) += 1;
        }
    }
    counts
}

fn element_names(tokens: &[Token]) -> Vec<&str> {
    tokens
        .iter()
        .filter_map(|t| match t {
            Token::StartTag { name, .. } => Some(name.as_str()),
            _ => None,
        })
        .collect()
}
```
:::

:::why Fn, FnMut, FnOnce
A closure-öknek három „fajtája” van, attól függően, mit csinálnak a befogott változókkal: az **`Fn`** csak olvassa őket, az **`FnMut`** módosítja is őket, az **`FnOnce`** elfogyasztja (move-olja) őket, ezért csak egyszer hívható. Ez ugyanaz a `&` / `&mut` / move hármas, amit az ownershipnél tanultál, csak closure-ökre. A fordító automatikusan kitalálja, melyik fajta a closure-öd. Neked csak a paraméter típusánál kell választanod, és a legtöbbször az `Fn` a jó.

:::card
K: Mi a különbség egy closure és egy sima függvény között?
V: A closure névtelen, és **befoghatja** a környezete változóit (`|c| c != quote`). A sima `fn` nem lát kívülre.
:::

:::card
K: Mit csinál a `filter_map`?
V: Egyszerre alakít át és szűr: a closure `Option`-t ad vissza, és csak a `Some` értékek kerülnek tovább (kicsomagolva).
:::

:::card
K: Hogyan számolsz előfordulásokat HashMap-pel?
V: `*map.entry(kulcs).or_insert(0) += 1;`. Ha a kulcs nincs benne, 0-val beteszi, aztán megnöveli.
