## Benne van-e a pont?

A téglalapot eddig egyszerű volt kitölteni: két ciklus a sarkai között. Egy lekerekített téglalapnál viszont minden pixelre meg kell kérdezni: **benne van-e az alakzatban?** Ehhez kell egy függvény, ami egy pontról eldönti ezt.

Egy ügyes trükk: képzelj el egy kisebb, „belső” téglalapot, aminek a sarkai éppen a négy negyedkör **középpontjai**:

```text Ábra
┌────────────────────────┐
│  ·──────────────────·  │   · = a sarkok köreinek középpontjai
│  │   belső téglalap  │  │       (r-rel beljebb minden oldalon)
│  ·──────────────────·  │
└────────────────────────┘
```

Keresd meg a pont **legközelebbi** helyét a belső téglalapban: `clamp`-pel mindkét koordinátát beszorítod a belső téglalap határai közé. Ha a pont a sarkokon kívül van, a legközelebbi hely saját maga, a távolság 0. Ha egy sarokban van, a legközelebbi hely a sarok körének középpontja. A pont akkor van bent, ha ez a távolság legfeljebb `r`.

```text Ábra
távolság² = (x − cx)² + (y − cy)²  ≤  r²      (gyökvonás nélkül!)
```

:::compare Pont az alakzatban
@@ C#
A `System.Drawing.Drawing2D.GraphicsPath.IsVisible(x, y)` ugyanezt csinálja tetszőleges alakzatra. A WPF-ben `Geometry.FillContains`.
@@ Python
A `matplotlib.path.Path.contains_point` a sokszögekre. A kör esete a Pitagorasz-tétel: `(x - cx)**2 + (y - cy)**2 <= r**2`.
@@ Érettségi
A „pont a körben” feladat: a távolság négyzetét hasonlítjuk a sugár négyzetéhez, így nem kell gyököt vonni. A `clamp(x, min, max)` = `max(min, min(x, max))`.
:::

## Élsimítás: amikor egy pixel félig bent van

Ha minden pixelnek csak a **közepét** vizsgáljuk, minden pixel vagy teljesen bent, vagy teljesen kint lesz. A görbe széle így lépcsős, csipkés lesz (aliasing). A javítás: nézzünk **több pontot** egy pixelen belül, egy 4×4-es rácsban, és számoljuk meg, hány van bent. Ha 16-ból 6, a pixel 6/16 arányban kap festéket. Ezt a 06-02-es keverés már meg is tudja csinálni: csak az alfát kell lecsökkenteni.

![Balra élsimítás nélkül (csak a pixel közepét vizsgáljuk), jobbra 4×4-es mintavétellel: a görbe szélén átmeneti színek simítják a lépcsőket](./img/elsimitas.png)

Ez a **szupermintavételezés** (supersampling). Egyszerű, és jól néz ki, de pixelenként 16 vizsgálat kell. A kártyánk kb. 100 000 pixeles, ez 1,6 millió vizsgálat, ami egy gyors gépen néhány milliszekundum.

```rust
/// Benne van-e az `(x, y)` pont a lekerekített sarkú téglalapban?
fn inside_rounded(x: f32, y: f32, r: Rect, radius: f32) -> bool {
    if x < r.x || x > r.right() || y < r.y || y > r.bottom() {
        return false;
    }
    let radius = radius.min(r.width / 2.0).min(r.height / 2.0);
    // A legközelebbi pont a „belső” téglalapban, ahol a sarkok köreinek középpontjai vannak.
    // A sarkokon kívül ez maga a pont, a sarkokban a kör középpontja.
    let cx = x.clamp(r.x + radius, r.right() - radius);
    let cy = y.clamp(r.y + radius, r.bottom() - radius);
    let (dx, dy) = (x - cx, y - cy);
    dx * dx + dy * dy <= radius * radius
}

/// Hány minta esik az alakzatba a pixel 4×4-es rácsából? (0–16)
fn coverage(px: i32, py: i32, inside: &impl Fn(f32, f32) -> bool) -> u32 {
    let mut hits = 0;
    for sy in 0..4 {
        for sx in 0..4 {
            let x = px as f32 + (sx as f32 + 0.5) / 4.0;
            let y = py as f32 + (sy as f32 + 0.5) / 4.0;
            if inside(x, y) {
                hits += 1;
            }
        }
    }
    hits
}

/// Egy alakzat kitöltése élsimítással (anti-aliasing): a szélén a pixel olyan
/// arányban kap festéket, amilyen arányban az alakzat lefedi.
fn fill_shape(
    canvas: &mut Canvas,
    bounds: Rect,
    scroll: i32,
    color: Color,
    inside: impl Fn(f32, f32) -> bool,
) {
    let x0 = (bounds.x.floor() as i32).max(0);
    let x1 = (bounds.right().ceil() as i32).min(canvas.width as i32);
    let y0 = (bounds.y.floor() as i32).max(scroll);
    let y1 = (bounds.bottom().ceil() as i32).min(scroll + canvas.height as i32);
    for py in y0..y1 {
        for px in x0..x1 {
            let hits = coverage(px, py, &inside);
            if hits > 0 {
                let a = (color.a as u32 * hits / 16) as u8;
                canvas.fill_rect(px, py - scroll, 1, 1, Color { a, ..color });
            }
        }
    }
}

/// A lekerekített keret: a külső alakzatból kivágjuk a belsőt.
fn rounded_border(
    canvas: &mut Canvas,
    r: Rect,
    w: Sides<f32>,
    radius: f32,
    scroll: i32,
    color: Color,
) {
    let inner = Rect {
        x: r.x + w.left,
        y: r.y + w.top,
        width: r.width - w.left - w.right,
        height: r.height - w.top - w.bottom,
    };
    let inner_radius = (radius - w.top.max(w.left)).max(0.0);
    fill_shape(canvas, r, scroll, color, |x, y| {
        inside_rounded(x, y, r, radius) && !inside_rounded(x, y, inner, inner_radius)
    });
}
```

```rust
fn inside_rounded(x: f32, y: f32, w: f32, h: f32, r: f32) -> bool {
    if x < 0.0 || x > w || y < 0.0 || y > h {
        return false;
    }
    let r = r.min(w / 2.0).min(h / 2.0);
    let in_cross = (x >= r && x <= w - r) || (y >= r && y <= h - r);
    let centers = vec![(r, r), (w - r, r), (r, h - r), (w - r, h - r)];
    let mut distances: Vec<f32> = centers
        .iter()
        .map(|&(cx, cy)| ((x - cx).powi(2) + (y - cy).powi(2)).sqrt())
        .collect();
    distances.sort_by(|a, b| a.partial_cmp(b).unwrap());
    in_cross || distances[0] <= r
}
```
