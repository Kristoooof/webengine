:::goal
Megírod a Rozsda URL-parserét a WHATWG URL-szabvány szerint. Egy címből séma, gépnév, port, útvonal, lekérdezés és részlet lesz, **kanonikus** alakban: a `HTTP://Pelda.HU:80/a/./b` és a `http://pelda.hu/a/b` ugyanaz a cím, és a parser ezt felismeri.
:::

## Egy URL részei

```text Ábra
  https://www.pelda.hu:8443/cikkek/rozsda.html?lap=2#vege
  └─┬─┘   └────┬─────┘└─┬─┘└────────┬────────┘└─┬─┘└─┬┘
  séma      gépnév     port      útvonal      lekérdezés részlet
 (scheme)   (host)    (port)     (path)        (query) (fragment)
            └──────┬───────┘
              authority
```

- A **séma** mondja meg, hogyan kell betölteni: `http`, `https`, `file`, `data`, `mailto` …
- A **gépnév** (host) egy domain (`www.pelda.hu`), egy IPv4-cím (`127.0.0.1`) vagy egy IPv6-cím szögletes zárójelben (`[::1]`).
- A **port** el is maradhat: a `http`-nél 80, a `https`-nél 443 az alapértelmezés.
- Az **útvonal** (path) a szerveren belüli hely, a **lekérdezés** (query) a `?` utáni rész. Mindkettő elmegy a szervernek.
- A **részlet** (fragment) a `#` utáni rész. Ez **nem** megy el a szervernek: a böngésző az oldalon belül ugrik vele.

## Miért kell egy szabvány?

Elég egy `split("://")` és pár `find`? Majdnem. A gond az, hogy a böngészők nagyon **elnézőek**: az emberek és a weboldalak mindenféle furcsa címet írnak, és a böngészők régóta „kitalálják”, mire gondoltak.

| Amit leírtak | Amit a böngésző lát | Miért |
|---|---|---|
| `HTTP://Pelda.HU/` | `http://pelda.hu/` | a séma és a domain kisbetűs |
| `http://pelda.hu` | `http://pelda.hu/` | a http-címnek mindig van útvonala |
| `http://pelda.hu:80/` | `http://pelda.hu/` | az alapértelmezett port eltűnik |
| `http:\\pelda.hu\a\b` | `http://pelda.hu/a/b` | a `\` is elválasztó (a Windows miatt) |
| `http://pelda.hu/a/./b/../c` | `http://pelda.hu/a/c` | a `.` és a `..` feloldódik |
| `http://127.1/` | `http://127.0.0.1/` | régi IPv4-rövidítés |
| `  http://a.hu/b c  ` | `http://a.hu/b%20c` | szóközök levágva, belül kódolva |

Évtizedekig minden böngésző kicsit másképp csinálta ezt. Ez **biztonsági** gond is: ha a szerver és a böngésző (vagy két program) mást ért ugyanazon a címen, egy támadó becsaphatja az egyiket. A **WHATWG URL Standard** ezért pontosan leírja, mit kell csinálni, egy állapotgéppel (state machine). Mi ennek egy rövidített, de hűséges változatát írjuk meg.

:::compare URL-ek máshol
@@ C#
`new Uri("http://pelda.hu/a/../b")` → `http://pelda.hu/b`. A .NET `Uri` osztálya az RFC 3986-ot követi, ami néhány helyen eltér a böngészők szabványától.
@@ C++
A Chrome C++-ban írt URL-parsere a `url::GURL`. A Firefoxé ma már Rustban van, és pont azt a szabványt követi, amit mi.
@@ Python
`urllib.parse.urlsplit("http://pelda.hu:8080/a?b#c")` szétszedi a részeket, de nem normalizál: a `..` marad.
@@ Rust
A profi `url` crate (a Servo projektből) a teljes WHATWG-szabványt tudja: Punycode-ot, jelszavakat, minden különleges esetet. A 16. modulban ez kerül a kapcsoló mögé.
@@ Érettségi
Az URL felépítése érettségi téma: protokoll, domain, elérési út. Az állapotgép (véges automata) pedig az algoritmusok közül ismerős lehet.
:::

## Speciális és átlátszatlan címek

A szabvány a sémákat két csoportra osztja:

- **Speciális** sémák: `http`, `https`, `ws`, `wss`, `ftp`, `file`. Ezeknek mindig van gépnevük (a `file`-nál ez üres is lehet), és az útvonaluk `/`-rel kezdődő, `.`-ot és `..`-ot feloldó **hierarchia**.
- Minden más séma. Ha a `:` után `//` jön, azoknak is van gépnevük (`foo://gep/x`). Ha nem, a cím **átlátszatlan** (opaque): `data:text/html,<b>Szia</b>`, `mailto:info@pelda.hu`, `javascript:alert(1)`. Ezeknek az útvonala bármi lehet, és nem lehetnek relatív címek alapjai.

## A gépnév

A gépnév feldolgozása a parser legkényesebb része:

1. Ha `[`-rel kezdődik, IPv6-cím. Ezt a Rust beépített `Ipv6Addr` parsere olvassa (az IPv6 rövidítési szabályai egy külön leckét érnének).
2. Különben százalékosan visszafejtjük, és kisbetűsítjük.
3. A tiltott karakterek (szóköz, `#`, `/`, `:`, `<`, `>`, `?`, `@`, `[`, `\`, `]`, `^`, `|`) hibát jelentenek. A nem ASCII betűket is elutasítjuk: egy `árvíztűrő.hu` címhez **Punycode** kellene (`xn--rvztr-…`), ez a profi oldal dolga.
4. Ha az utolsó címke szám, akkor az egésznek IPv4-címnek kell lennie, a régi C-könyvtárak engedékeny szabályaival: egy rész lehet hexa (`0x7f`), oktális (`0177`) vagy decimális, és lehet 1–4 rész. A `127.1` a 127.0.0.1, mert az utolsó rész az összes hátralévő bájtot kitölti.

```text Ábra
127.1          → részek: [127, 1]       → 127·256³ + 1                 = 127.0.0.1
0x7f.0.0.1     → részek: [127, 0, 0, 1]                                 = 127.0.0.1
1.2.3.256      → az utolsó rész 4 résznél legfeljebb 255 lehet          → hiba
pelda.hu       → az utolsó címke („hu”) nem szám                        → domain
```

```rust
    pub fragment: Option<String>,
}

/// A speciális sémák alapértelmezett portja.
pub fn default_port(scheme: &str) -> Option<u16> {
    match scheme {
        "http" | "ws" => Some(80),
        "https" | "wss" => Some(443),
        "ftp" => Some(21),
        _ => None,
    }
}

/// A „speciális” sémák: ezeknek mindig van gépnevük, és az útvonaluk hierarchikus.

}
```

```rust
/// `"a?b"` → `("a", Some("b"))`
fn split_off(s: &str, separator: char) -> (&str, Option<&str>) {
    match s.split_once(separator) {
        Some((before, after)) => (before, Some(after)),
        None => (s, None),
    }
}

/// A gépnév után a port: `[::1]:8080` → `("[::1]", Some("8080"))`.
fn split_port(authority: &str) -> (&str, Option<&str>) {
    let search_from = if authority.starts_with('[') {
        authority.find(']').unwrap_or(0)
    } else {
        0
    };
    match authority[search_from..].find(':') {
        Some(i) => (
            &authority[..search_from + i],
            Some(&authority[search_from + i + 1..]),
        ),
        None => (authority, None),
    }
}

/// A séma a cím elején: betűvel kezdődik, betű, szám, `+`, `-` vagy `.` követi, és `:` zárja.
fn split_scheme(input: &str) -> Option<(&str, &str)> {
    let (scheme, rest) = input.split_once(':')?;
    let mut chars = scheme.chars();
    let first = chars.next()?;
    let valid = first.is_ascii_alphabetic()
        && chars.all(|c| c.is_ascii_alphanumeric() || matches!(c, '+' | '-' | '.'));
    valid.then_some((scheme, rest))
}

/// Egy IPv4-szám a szabvány szerint: `0x` előtaggal hexa, `0` előtaggal oktális, különben decimális.
fn ipv4_number(part: &str) -> Option<u32> {
    let (digits, radix) = if let Some(hex) = part.strip_prefix("0x").or(part.strip_prefix("0X")) {
        (hex, 16)
    } else if part.len() > 1 && part.starts_with('0') {
        (&part[1..], 8)
    } else {
        (part, 10)
    };
    if digits.is_empty() {
        return (radix != 10).then_some(0); // a „0x” önmagában 0
    }
    u32::from_str_radix(digits, radix).ok()
}

/// IPv4-cím 1–4 részből: a `127.1` is a 127.0.0.1, mert az utolsó rész kitölti a maradékot.
fn parse_ipv4(host: &str) -> Option<Ipv4Addr> {
    let mut parts: Vec<&str> = host.split('.').collect();
    if parts.len() > 1 && parts.last() == Some(&"") {
        parts.pop(); // a záró pont megengedett
    }
    if parts.len() > 4 {
        return None;
    }
    let numbers: Vec<u32> = parts
        .iter()
        .map(|p| ipv4_number(p))
        .collect::<Option<_>>()?;
    let (last, rest) = numbers.split_last()?;
    if rest.iter().any(|&n| n > 255) || u64::from(*last) >= 256u64.pow(5 - numbers.len() as u32) {
        return None;
    }
    let mut ip = u64::from(*last);
    for (i, &n) in rest.iter().enumerate() {
        ip += u64::from(n) << (8 * (3 - i));
    }
    Some(Ipv4Addr::from(ip as u32))
}

/// Ha a gépnév utolsó címkéje szám, akkor IPv4-címnek kell lennie (különben hibás).
fn ends_in_number(host: &str) -> bool {
    let last = host.trim_end_matches('.').rsplit('.').next().unwrap_or("");
    !last.is_empty() && (last.bytes().all(|b| b.is_ascii_digit()) || ipv4_number(last).is_some())
}

/// A gépnév: IPv6 szögletes zárójelben, IPv4, vagy kisbetűs domain a tiltott karakterek nélkül.
fn parse_host(input: &str, special: bool) -> Result<Option<Host>, UrlError> {
    let bad = || UrlError::BadHost(input.to_string());
    if let Some(inner) = input.strip_prefix('[') {
        let inner = inner.strip_suffix(']').ok_or_else(bad)?;
        return inner
            .parse()
            .map(|ip| Some(Host::Ipv6(ip)))
            .map_err(|_| bad());
    }
    if input.is_empty() {
        return Ok(None);
    }
    if !special {
        return Ok(Some(Host::Domain(percent_encode(
            input,
            EncodeSet::C0Control,
        ))));
    }
    let decoded = String::from_utf8(percent_decode(input)).map_err(|_| bad())?;
    let domain = decoded.to_ascii_lowercase();
    // A nem ASCII domainekhez (árvíztűrő.hu) Punycode kellene: ez a 16. modul profi oldalán van.
    let forbidden = |c: char| !c.is_ascii() || c <= ' ' || "#%/:<>?@[\\]^|\u{7F}".contains(c);
    if domain.chars().any(forbidden) {
        return Err(bad());
    }
    if ends_in_number(&domain) {
        return parse_ipv4(&domain)
            .map(|ip| Some(Host::Ipv4(ip)))
            .ok_or_else(bad);
    }
    Ok(Some(Host::Domain(domain)))
}

/// A port: üres (= alapértelmezett), vagy 0–65535. Az alapértelmezett portot nem tároljuk.
fn parse_port(input: Option<&str>, scheme: &str) -> Result<Option<u16>, UrlError> {
    let Some(digits) = input.filter(|d| !d.is_empty()) else {
        return Ok(None);
    };
    if !digits.bytes().all(|b| b.is_ascii_digit()) {
        return Err(UrlError::BadPort);
    }
    let port: u16 = digits.parse().map_err(|_| UrlError::BadPort)?;
    Ok((default_port(scheme) != Some(port)).then_some(port))
}

/// Az útvonal szegmensekre bontva, a `.` és a `..` feloldásával. Speciális sémáknál a `\` is elválasztó.
fn normalize_path(path: &str, special: bool) -> String {
    if !special && path.is_empty() {
        return String::new();
    }
    let path = if special {
        path.replace('\\', "/")
    } else {
        path.to_string()
    };
    let segments: Vec<&str> = path.strip_prefix('/').unwrap_or(&path).split('/').collect();
    let last = segments.len() - 1;
    let mut out: Vec<String> = Vec::new();
    for (i, segment) in segments.iter().enumerate() {
        match segment.to_ascii_lowercase().as_str() {
            ".." | ".%2e" | "%2e." | "%2e%2e" => {
                out.pop();
                if i == last {
                    out.push(String::new()); // `/a/b/..` → `/a/`
                }
            }
            "." | "%2e" => {
                if i == last {
                    out.push(String::new());
                }
            }
            _ => out.push(percent_encode(segment, EncodeSet::Path)),
        }
    }
    format!("/{}", out.join("/"))
}
```

```rust
impl Url {
    /// Egy abszolút cím feldolgozása.
    pub fn parse(input: &str) -> Result<Url, UrlError> {
        // Az elejéről és a végéről a szóközök, közben a tabulátorok és a sortörések elhagyandók.
        let cleaned: String = input
            .trim_matches(|c: char| c <= ' ')
            .chars()
            .filter(|c| !matches!(c, '\t' | '\n' | '\r'))
            .collect();
        let Some((scheme, rest)) = split_scheme(&cleaned) else {
            return Err(UrlError::NoScheme);
        };
        let scheme = scheme.to_ascii_lowercase();
        if scheme == "file" {
            return match rest.strip_prefix("//").or(rest.strip_prefix("\\\\")) {
                Some(rest) => Url::parse_authority(scheme, rest),
                None => Url::with_path(scheme, None, None, rest),
            };
        }
        if is_special(&scheme) {
            // a speciális sémák a perjelek számát nem veszik szigorúan: `http:/a.hu` = `http://a.hu`
            return Url::parse_authority(scheme, rest.trim_start_matches(['/', '\\']));
        }
        match rest.strip_prefix("//") {
            Some(rest) => Url::parse_authority(scheme, rest),
            None => Ok(Url::opaque(scheme, rest)),
        }
    }

    /// `gépnév:port` és utána az útvonal, a lekérdezés és a részlet.
    fn parse_authority(scheme: String, rest: &str) -> Result<Url, UrlError> {
        let special = is_special(&scheme);
        let end = rest
            .find(|c| matches!(c, '/' | '?' | '#') || (special && c == '\\'))
            .unwrap_or(rest.len());
        let (authority, tail) = rest.split_at(end);
        if authority.contains('@') {
            return Err(UrlError::Credentials);
        }
        let (host, port) = split_port(authority);
        let mut host = parse_host(host, special)?;
        let port = parse_port(port, &scheme)?;
        if scheme == "file" {
            // a `file://localhost/…` ugyanaz, mint a `file:///…`
            if host == Some(Host::Domain("localhost".into())) {
                host = None;
            }
        } else if special && host.is_none() {
            return Err(UrlError::BadHost(String::new()));
        }
        Url::with_path(scheme, host, port, tail)
    }

    /// Az útvonal, a lekérdezés és a részlet beolvasása és kódolása.
    fn with_path(
        scheme: String,
        host: Option<Host>,
        port: Option<u16>,
        tail: &str,
    ) -> Result<Url, UrlError> {
        let special = is_special(&scheme);
        let (rest, fragment) = split_off(tail, '#');
        let (path, query) = split_off(rest, '?');
        let query_set = if special {
            EncodeSet::SpecialQuery
        } else {
            EncodeSet::Query
        };
        Ok(Url {
            path: normalize_path(path, special),
            query: query.map(|q| percent_encode(q, query_set)),
            fragment: fragment.map(|f| percent_encode(f, EncodeSet::Fragment)),
            scheme,
            host,
            port,
        })
    }

    /// Átlátszatlan (opaque) cím: `data:`, `mailto:`, `javascript:`. Az útvonal bármi lehet.
    fn opaque(scheme: String, rest: &str) -> Url {
        let (rest, fragment) = split_off(rest, '#');
        let (path, query) = split_off(rest, '?');
        Url {
            scheme,
            host: None,
            port: None,
            path: percent_encode(path, EncodeSet::C0Control),
            query: query.map(|q| percent_encode(q, EncodeSet::Query)),
            fragment: fragment.map(|f| percent_encode(f, EncodeSet::Fragment)),
        }
    }

    pub fn is_special(&self) -> bool {
        is_special(&self.scheme)
    }

    /// Az átlátszatlan címek nem lehetnek alapjai relatív címeknek.
    pub fn cannot_be_a_base(&self) -> bool {
        !self.is_special() && self.host.is_none() && !self.path.starts_with('/')
    }

    /// A port, vagy ha nincs megadva, a séma alapértelmezett portja.
    pub fn port_or_default(&self) -> Option<u16> {
        self.port.or(default_port(&self.scheme))
    }

    /// `gépnév[:port]`: ez megy a HTTP `Host` fejlécébe.
    pub fn authority(&self) -> String {
        let host = self
            .host
            .as_ref()
            .map(|h| h.to_string())
            .unwrap_or_default();
        match self.port {
            Some(port) => format!("{host}:{port}"),
            None => host,
        }
    }

    /// Az útvonal és a lekérdezés: ezt kérjük a szervertől (`GET /a/b?c HTTP/1.1`).
    pub fn request_target(&self) -> String {
        match &self.query {
            Some(q) => format!("{}?{q}", self.path),
            None => self.path.clone(),
        }
    }
}
```

```rust
impl fmt::Display for Url {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "{}:", self.scheme)?;
        if let Some(host) = &self.host {
            write!(f, "//{host}")?;
            if let Some(port) = self.port {
                write!(f, ":{port}")?;
            }
        } else if self.scheme == "file" {
            write!(f, "//")?;
        }
        write!(f, "{}", self.path)?;
        if let Some(query) = &self.query {
            write!(f, "?{query}")?;
        }
        if let Some(fragment) = &self.fragment {
            write!(f, "#{fragment}")?;
        }
        Ok(())
    }
}
```

```rust
fn parse_ipv4_strict(s: &str) -> Option<[u8; 4]> {
    let mut out = [0u8; 4];
    let mut parts = s.split('.');
    for slot in &mut out {
        let part = parts.next()?;
        let valid = !part.is_empty()
            && part.len() <= 3
            && part.bytes().all(|b| b.is_ascii_digit())
            && !(part.len() > 1 && part.starts_with('0'));
        if !valid {
            return None;
        }
        *slot = part.parse().ok()?;
    }
    if parts.next().is_some() {
        return None;
    }
    Some(out)
}
```
