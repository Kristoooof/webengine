## if: elágazás, ami értéket ad

```rust
let c = '<';
if c == '<' {
    println!("tag kezdődik");
} else if c == '&' {
    println!("karakterhivatkozás kezdődik");
} else {
    println!("sima szöveg");
}
```

Két különbség a C#-hoz és a C++-hoz képest: a feltétel körül **nincs zárójel**, a kapcsos zárójel viszont **kötelező**. Mivel az `if` is kifejezés, értéke is lehet:

```rust
let kind = if c == '<' { "tag" } else { "szöveg" };
```

Ez kiváltja a C#-os/C++-os ternáris operátort (`c == '<' ? "tag" : "szöveg"`), mert Rustban ilyen nincs.

## Ciklusok

```rust
// for: végigmegy egy tartományon vagy gyűjteményen
for i in 0..3 {           // 0, 1, 2 (a 3 már nem)
    println!("{i}");
}
for i in 1..=3 {          // 1, 2, 3 (a = miatt a 3 is)
    println!("{i}");
}

// for egy szöveg karakterein: ezt fogjuk a legtöbbet használni!
for c in "<p>".chars() {
    println!("{c}");
}

// while: amíg a feltétel igaz
let mut n = 3;
while n > 0 {
    n -= 1;
}

// loop: végtelen ciklus, amiből break-kel lépsz ki (akár értékkel!)
let mut tries = 0;
let result = loop {
    tries += 1;
    if tries == 5 {
        break tries * 10;   // a loop értéke 50 lesz
    }
};
```

A `continue` itt is a következő körre ugrik, ahogy megszoktad.

:::compare
@@ C#
```csharp
foreach (char c in "<p>") { ... }
for (int i = 0; i < 3; i++) { ... }
```
@@ C++
```cpp
for (char c : std::string("<p>")) { ... }
for (int i = 0; i < 3; i++) { ... }
```
@@ Python
```python
for c in "<p>": ...
for i in range(3): ...
```
@@ Rust
```rust
for c in "<p>".chars() { ... }
for i in 0..3 { ... }
```
Rustban nincs C-stílusú `for (i = 0; i < n; i++)`. Helyette tartomány van (`0..n`), ami olvashatóbb, és nem lehet vele „eggyel elcsúszni”.
:::

:::note Miért `.chars()`?
Az előző leckében láttad, hogy egy szöveg UTF-8 **bájtokból** áll. A `.chars()` ezeket helyesen **karakterekre** bontja, így az „ő” egyetlen `char` lesz, nem két érthetetlen bájt. Ha a bájtokra van szükséged, arra a `.bytes()` való.
:::

## Te jössz, 2. rész: a tagek eltávolítása

Most jön az izgalmas rész. A Rozsda 0.1 (2. modul) első változata nem fog „igazán” HTML-t parse-olni. Egyszerűen eltávolítja a tageket, és kiírja, ami marad. Ennek a magját írod meg most.

Az ötlet egy **állapotgép**, a legegyszerűbb fajtából, két állapottal: *tagon belül* vagy *tagon kívül* vagy.

<div class="pipeline">
  <div class="pl-step"><b>A</b><strong>Szövegben</strong><small>A karaktert hozzáadjuk a kimenethez. Ha <code>&lt;</code> jön → B</small></div>
  <div class="pl-step"><b>B</b><strong>Tagban</strong><small>Eldobjuk a karaktert. Ha <code>&gt;</code> jön → A</small></div>
</div>

Egy növelhető szöveget így hozol létre, és így bővítesz:

```rust
let mut out = String::new();
out.push('S');        // egy karakter hozzáadása
out.push_str("zia");  // egy szöveg hozzáadása
// out most: "Szia"
```

:::task
Írd meg: `fn strip_tags(html: &str) -> String`. Egy `bool` változó (`inside_tag`) jegyezze meg, hogy épp tagon belül vagy-e. Másold be a teszteket, és dolgozz, amíg zöld nem lesz.
:::

```rust test
    #[test]
    fn stripping() {
        assert_eq!(strip_tags("<p>Szia</p>"), "Szia");
        assert_eq!(strip_tags("<b>Rozsda</b> motor"), "Rozsda motor");
        assert_eq!(strip_tags("nincs tag"), "nincs tag");
        assert_eq!(strip_tags("<a href=\"x\">link</a>!"), "link!");
        assert_eq!(strip_tags(""), "");
    }
```

:::hint
A váz:
```rust
fn strip_tags(html: &str) -> String {
    let mut out = String::new();
    let mut inside_tag = false;
    for c in html.chars() {
        // ide jön a döntés
    }
    out
}
```
---
Három eset van: ha `c == '<'`, akkor `inside_tag = true`. Ha `c == '>'`, akkor `inside_tag = false`. Minden más esetben, **ha nem vagy tagon belül**, `out.push(c)`.
---
Figyelj a sorrendre: a `<` és a `>` karaktert soha ne tedd bele a kimenetbe. Egy `if` / `else if` / `else if !inside_tag` lánc pont jó.
:::

:::solution
```rust
fn count_char(s: &str, target: char) -> usize {
    let mut count = 0;
    for c in s.chars() {
        if c == target {
            count += 1;
        }
    }
    count
}

fn strip_tags(html: &str) -> String {
    let mut out = String::new();
    let mut inside_tag = false;
    for c in html.chars() {
        if c == '<' {
            inside_tag = true;
        } else if c == '>' {
            inside_tag = false;
        } else if !inside_tag {
            out.push(c);
        }
    }
    out
}
```
:::

Írd meg a `strip_tags` függvényt: a `<` és `>` közötti részt (a jelekkel együtt) hagyja ki, minden mást tartson meg.
@@ kód
```rust
fn strip_tags(html: &str) -> String {

}
```
@@ megoldás
```rust
fn strip_tags(html: &str) -> String {
    let mut out = String::with_capacity(html.len());
    let mut inside_tag = false;
    for c in html.chars() {
        match c {
            '<' => inside_tag = true,
            '>' => inside_tag = false,
            _ if !inside_tag => out.push(c),
            _ => {}
        }
    }
    out

```
@@ magyarázat
A minta egyetlen menetben megy végig a szövegen, és a kimenetnek **előre lefoglal** elég helyet: `String::with_capacity(html.len())`. A kimenet sosem hosszabb a bemenetnél, így a `push`-nak soha nem kell nagyobb memóriát kérnie és átmásolnia a szöveget. Az is gyakori, hogy a `replace`-szel többször megy végig a kód az egész szövegen.
@@ esetek


## Bónusz: szóközök összevonása

A böngésző a HTML-ben egymás után álló szóközöket, tabokat és sortöréseket **egyetlen** szóközként jeleníti meg (hacsak a CSS mást nem mond). Ezért néz ki ugyanúgy a két HTML:

```html
<p>Szia,     világ!</p>
<p>Szia,
   világ!</p>
```

:::task Bónusz (ha van még kedved)
Írd meg: `fn collapse_whitespace(s: &str) -> String`. Minden egymás utáni szóköz-sorozatot cseréljen **egy** szóközre. Használd az előző leckében írt `is_html_whitespace` függvényt!

```rust test
    #[test]
    fn collapsing() {
        assert_eq!(collapse_whitespace("a   b"), "a b");
        assert_eq!(collapse_whitespace("a\n\t b"), "a b");
        assert_eq!(collapse_whitespace("  a  "), " a ");
    }
```
:::

:::hint
Kell egy `prev_space: bool`, ami azt jegyzi meg, hogy az előző karakter szóköz volt-e. Szóköznél csak akkor teszel `' '`-t a kimenetbe, ha az előző **nem** volt szóköz.
:::

:::solution Bónusz megoldás
```rust
fn collapse_whitespace(s: &str) -> String {
    let mut out = String::new();
    let mut prev_space = false;
    for c in s.chars() {
        if is_html_whitespace(c) {
            if !prev_space {
                out.push(' ');
            }
            prev_space = true;
        } else {
            out.push(c);
            prev_space = false;
        }
    }
    out
}
```
:::

:::warn Mire nem jó a strip_tags?
Ez a függvény szándékosan naiv. Elrontja például ezt: `<a title="1 > 0">`, mert az idézőjelen belüli `>`-t tag végének hiszi. A `<script>` és a `<style>` tartalmát is szövegként hagyja meg. A 01-13-as főnöki pályán és a 3. modulban rendesen megoldjuk. Most az a lényeg, hogy működjön, és értsd.
:::
