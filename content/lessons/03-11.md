:::goal
A böngésződ mostantól az új, szabványkövető parserrel dolgozik. A `HtmlParser` trait DOM-ot ad vissza, a régi tokenizer nyugdíjba megy, és egy `--dom` kapcsolóval kiírhatod bármelyik oldal fáját. A képernyőn ugyanaz látszik, mint eddig, de alatta már egy igazi DOM dolgozik.
:::

## 3. A lapító

:::task
Hozd létre a `crates/rozsda-browser/src/flatten.rs` modult (`mod flatten;` a `main.rs`-be), benne:

1. `fn block_kind(name: &str) -> Option<BlockKind>`: ugyanaz a táblázat, mint a 02-03-ban (pár új blokkelemmel: `nav`, `aside`, `form`, `figure`).
2. `pub fn collapse_whitespace(s: &str) -> String`: a régi util-ból költözik ide.
3. `pub fn page_from_document(doc: &Document) -> Page`: bejárja a DOM-ot a gyökértől. A szöveg a szóközök összevonása után az aktuális blokkhoz adódik. A `br` sortörést jelent. A `head`, `script`, `style` és `template` elemeket teljesen kihagyja. Blokkelembe belépéskor és kilépéskor lezárja az aktuális blokkot (*flush*). A cím a `doc.title()`.

A bejárás **rekurzív** a legolvashatóbb: egy `walk(id)` függvény, ami egy elemnél végighívja magát a gyerekeken.
:::

```rust test
#[cfg(test)]
mod tests {
    use super::*;
    use rozsda_html::tree_builder::parse_document;

    #[test]
    fn flattens_like_before() {
        let doc = parse_document(
            "<title>Cím</title><h1>Szia</h1><p>Egy <b>kettő</b><br>három</p><ul><li>a<li>b</ul><script>x</script>",
        );
        let page = page_from_document(&doc);
        assert_eq!(page.title.as_deref(), Some("Cím"));
        let kinds: Vec<BlockKind> = page.blocks.iter().map(|b| b.kind).collect();
        assert_eq!(
            kinds,
            vec![BlockKind::Heading(1), BlockKind::Paragraph, BlockKind::ListItem, BlockKind::ListItem]
        );
        assert_eq!(page.blocks[1].text, "Egy kettő\nhárom");
    }
}
```

:::hint
A rekurzióhoz kényelmes egy kis segéd-struct, ami a bejárás közben tartja az állapotot (a dokumentumot, az épülő oldalt és az aktuális blokkot):
```rust
struct Flattener<'a> {
    doc: &'a Document,
    page: Page,
    current: Block,
}
```
A `<'a>` egy **élettartam-paraméter**: azt mondja, hogy a struct egy `Document`-re mutató referenciát tárol, és nem élheti túl azt. Ez az első eset, hogy ki kell írnod egy élettartamot, mert egy struct tárol referenciát. Az `impl Flattener<'_>`-ben az `'_` azt jelenti: „bármilyen élettartam, nem kell nevet adnom neki”.
---
A `walk` váza egy `match` a csomópont adatán:
```rust
fn walk(&mut self, id: NodeId) {
    match &self.doc.node(id).data {
        NodeData::Text(t) => self.current.text.push_str(&collapse_whitespace(t)),
        NodeData::Element(e) => { /* kihagyás, br, blokk: flush + gyerekek + flush */ }
        NodeData::Document => { /* minden gyerekre walk */ }
        NodeData::Doctype(_) | NodeData::Comment(_) => {}
    }
}
```
---
A `flush` ugyanaz, mint a 02-03-ban: a `'\n'` mentén sorokra bont, mindegyiket összevonja és levágja, és ha maradt valami, `Block`-ot tesz a `page.blocks`-ba.
:::

:::solution
```rust
//! Átmeneti híd: a DOM-ból a 0.1-es `Page` blokklistája lesz, amíg az 5. modulban
//! el nem készül az igazi layout.

use rozsda_core::dom::{Document, NodeData, NodeId};
use rozsda_core::{Block, BlockKind, Page};

fn block_kind(name: &str) -> Option<BlockKind> {
    match name {
        "h1" => Some(BlockKind::Heading(1)),
        "h2" => Some(BlockKind::Heading(2)),
        "h3" | "h4" | "h5" | "h6" => Some(BlockKind::Heading(3)),
        "li" => Some(BlockKind::ListItem),
        "p" | "div" | "section" | "article" | "header" | "footer" | "main" | "nav" | "aside" | "blockquote"
        | "pre" | "ul" | "ol" | "table" | "tr" | "body" | "form" | "figure" => Some(BlockKind::Paragraph),
        _ => None,
    }
}

pub fn collapse_whitespace(s: &str) -> String {
    let mut out = String::new();
    let mut prev_space = false;
    for c in s.chars() {
        if matches!(c, ' ' | '\t' | '\n' | '\r' | '\u{000C}') {
            if !prev_space {
                out.push(' ');
            }
            prev_space = true;
        } else {
            out.push(c);
            prev_space = false;
        }
    }
    out
}

struct Flattener<'a> {
    doc: &'a Document,
    page: Page,
    current: Block,
}

impl Flattener<'_> {
    fn flush(&mut self) {
        let lines: Vec<String> = self
            .current
            .text
            .split('\n')
            .map(|l| collapse_whitespace(l).trim().to_string())
            .filter(|l| !l.is_empty())
            .collect();
        if !lines.is_empty() {
            self.page.blocks.push(Block { kind: self.current.kind, text: lines.join("\n") });
        }
        self.current.text.clear();
        self.current.kind = BlockKind::Paragraph;
    }

    fn walk(&mut self, id: NodeId) {
        match &self.doc.node(id).data {
            NodeData::Text(t) => self.current.text.push_str(&collapse_whitespace(t)),
            NodeData::Element(e) => {
                let name = e.name.as_str();
                if matches!(name, "head" | "script" | "style" | "template") {
                    return;
                }
                if name == "br" {
                    self.current.text.push('\n');
                    return;
                }
                let kind = block_kind(name);
                if let Some(k) = kind {
                    self.flush();
                    self.current.kind = k;
                }
                for &child in self.doc.children(id) {
                    self.walk(child);
                }
                if kind.is_some() {
                    self.flush();
                }
            }
            NodeData::Document => {
                for &child in self.doc.children(id) {
                    self.walk(child);
                }
            }
            NodeData::Doctype(_) | NodeData::Comment(_) => {}
        }
    }
}

pub fn page_from_document(doc: &Document) -> Page {
    let mut f = Flattener {
        doc,
        page: Page { title: doc.title(), blocks: Vec::new() },
        current: Block { kind: BlockKind::Paragraph, text: String::new() },
    };
    f.walk(doc.root());
    f.flush();
    f.page
}
```

## 4. A `--dom` kapcsoló

:::task
A browser `main.rs`-ében:

1. Az `Options` kapjon egy `dump_dom: bool` mezőt. A `--dom` argumentum kapcsolja be (frissítsd a használati üzenetet is).
2. A `run`-ban: `let doc = parser.parse(&source);`. Ha `opts.dump_dom`, írd ki a `doc.dump()`-ot (`print!`), és lépj ki (`return Ok(())`). Különben: `let page = flatten::page_from_document(&doc);`, és innentől minden a régi.
:::

:::solution A main.rs változásai
```rust
mod canvas;
mod flatten;
mod layout;
mod text;

// ...

struct Options {
    path: String,
    html: Implementation,
    dump_dom: bool,
}

fn parse_args() -> Result<Options, String> {
    let mut path = None;
    let mut html = Implementation::Own;
    let mut dump_dom = false;
    for arg in std::env::args().skip(1) {
        match arg.as_str() {
            "--html=sajat" => html = Implementation::Own,
            "--html=profi" => html = Implementation::Pro,
            "--dom" => dump_dom = true,
            a if a.starts_with("--") => return Err(format!("ismeretlen kapcsoló: {a}")),
            a => path = Some(a.to_string()),
        }
    }
    let path = path.ok_or("használat: rozsda-browser <fájl.html> [--html=sajat|profi] [--dom]")?;
    Ok(Options { path, html, dump_dom })
}

// ... a run()-ban, a parse után:
let doc = parser.parse(&source);
if opts.dump_dom {
    print!("{}", doc.dump());
    return Ok(());
}
let page = flatten::page_from_document(&doc);
```
