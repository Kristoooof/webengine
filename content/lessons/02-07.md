## Hibakezelés a main-ben

A Rust `main` függvénye is visszaadhat `Result`-ot, és akkor működik benne a `?`:

```rust
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let source = std::fs::read_to_string("nincs.html")?;
    Ok(())
}
```

A `Box<dyn Error>` jelentése: *„bármilyen hiba”*. Ez egy trait object, pont úgy, mint a `Box<dyn Tokenizer>`. A `?` automatikusan bármilyen hibát (`io::Error`, `String`…) be tud csomagolni egy ilyen dobozba.

Csakhogy így a hibaüzenet csúnya:

```text
Error: Os { code: 2, kind: NotFound, message: "A rendszer nem találja a megadott fájlt." }
```

Ez a `Debug` formátum. Szebb, ha a valódi munkát egy `run()` függvény végzi, a `main` pedig csak kiírja a hibát `Display` formátumban, és hibakóddal kilép:

```rust
fn run() -> Result<(), Box<dyn Error>> {
    // ... minden munka itt, ?-ekkel
    Ok(())
}

fn main() {
    if let Err(e) = run() {
        eprintln!("Hiba: {e}");
        std::process::exit(1);
    }
}
```

- Az `eprintln!` a **standard hibakimenetre** ír (stderr), nem a sima kimenetre. A hibák helye ott van.
- Az `exit(1)` jelzi az operációs rendszernek (és a szkripteknek), hogy a program hibával állt le. A `0` jelenti a sikert.

### Saját kontextus a hibához: map_err

Az `io::Error` önmagában nem mondja meg, **melyik** fájllal volt baj. A `map_err` átalakítja a hibát, mielőtt a `?` továbbadja:

```rust
let source = std::fs::read_to_string(&path)
    .map_err(|e| format!("nem sikerült megnyitni: {path} ({e})"))?;
```

```text
Hiba: nem sikerült megnyitni: oldalak/pela.html (A rendszer nem találja a megadott fájlt. (os error 2))
```

:::compare
@@ C#
```csharp
try {
    var source = File.ReadAllText(path);
} catch (IOException e) {
    Console.Error.WriteLine($"nem sikerült megnyitni: {path} ({e.Message})");
    Environment.Exit(1);
}
```
@@ Rust
```rust
let source = std::fs::read_to_string(&path)
    .map_err(|e| format!("nem sikerült megnyitni: {path} ({e})"))?;
```
A `?` és a `map_err` együtt kb. egy célzott `try/catch`, ami csak egy sort ölel körül, és a hibát kontextussal adja tovább.
:::

:::tip Az anyhow crate
Nagyobb alkalmazásokban szinte mindenki az [anyhow](https://docs.rs/anyhow) crate-et használja erre: `anyhow::Result`, `.context("nem sikerült megnyitni")`. Most a standard könyvtárral csináljuk, hogy lásd, mi van a motorháztető alatt. Később nyugodtan áttérhetsz rá.
:::

## Te jössz

:::task
Írd át a `rozsda-browser/src/main.rs`-t:

1. Egy `Options` struct: `path: String`, `html: Implementation`.
2. `fn parse_args() -> Result<Options, String>`:
   - a `--html=sajat` és a `--html=profi` beállítja a `html` mezőt;
   - bármilyen más `--`-sal kezdődő argumentum hiba: `"ismeretlen kapcsoló: …"`;
   - minden más a fájl útvonala;
   - ha nincs útvonal, a hiba: `"használat: rozsda-browser <fájl.html> [--html=sajat|profi]"`.
3. `fn pick_html(choice: Implementation) -> Box<dyn HtmlParser>`: az `Own` esetén `OwnHtmlParser`. A `Pro` esetén **egyelőre** írjon ki egy üzenetet (`eprintln!`), hogy a profi motor a 16. modulban érkezik, és adja vissza a sajátot.
4. `fn run() -> Result<(), Box<dyn Error>>` a teljes eddigi logikával, `expect` és `unwrap` nélkül, `?`-ekkel. A `Window::new` és az `update_with_buffer` is `Result`-ot ad, azokra is `?` kerüljön.
5. Az ablak címe legyen: `"<oldal címe> – Rozsda"`, vagy csak `"Rozsda"`, ha az oldalnak nincs címe.
6. A `main` a fenti mintát kövesse.
:::

:::hint
A `parse_args` ciklusa:
```rust
for arg in std::env::args().skip(1) {
    match arg.as_str() {
        "--html=sajat" => html = Implementation::Own,
        "--html=profi" => html = Implementation::Pro,
        a if a.starts_with("--") => return Err(format!("ismeretlen kapcsoló: {a}")),
        a => path = Some(a.to_string()),
    }
}
```
---
A „nincs útvonal” hibát egyetlen sorban megoldhatod: `let path = path.ok_or("használat: …")?;`. Az `ok_or` az `Option`-ból `Result`-ot csinál, a `?` pedig `Err` esetén visszatér vele.
---
A `run`-ban a `parse_args()?` működik, pedig a `parse_args` `Result<_, String>`-et ad, a `run` pedig `Result<_, Box<dyn Error>>`-t vár. A `?` a `From` trait segítségével automatikusan átalakítja a `String`-et `Box<dyn Error>`-rá. Ugyanaz a trait, ami a `.into()` mögött van!
---
Az ablak címe: `let title = match &page.title { Some(t) => format!("{t} – Rozsda"), None => String::from("Rozsda") };`
:::

:::solution
```rust
mod canvas;
mod layout;
mod text;

use canvas::{Canvas, rgb};
use minifb::{Key, KeyRepeat, Window, WindowOptions};
use rozsda_core::{HtmlParser, Implementation};
use rozsda_html::OwnHtmlParser;
use std::error::Error;

const WIDTH: usize = 960;
const HEIGHT: usize = 720;
const MARGIN: i32 = 40;
const BACKGROUND: u32 = rgb(0xFA, 0xFA, 0xF9);

struct Options {
    path: String,
    html: Implementation,
}

fn parse_args() -> Result<Options, String> {
    let mut path = None;
    let mut html = Implementation::Own;
    for arg in std::env::args().skip(1) {
        match arg.as_str() {
            "--html=sajat" => html = Implementation::Own,
            "--html=profi" => html = Implementation::Pro,
            a if a.starts_with("--") => return Err(format!("ismeretlen kapcsoló: {a}")),
            a => path = Some(a.to_string()),
        }
    }
    let path = path.ok_or("használat: rozsda-browser <fájl.html> [--html=sajat|profi]")?;
    Ok(Options { path, html })
}

fn pick_html(choice: Implementation) -> Box<dyn HtmlParser> {
    match choice {
        Implementation::Own => Box::new(OwnHtmlParser),
        Implementation::Pro => {
            eprintln!("A profi HTML-motor a 16. modulban érkezik, addig a saját fut.");
            Box::new(OwnHtmlParser)
        }
    }
}

fn run() -> Result<(), Box<dyn Error>> {
    let opts = parse_args()?;
    let source = std::fs::read_to_string(&opts.path)
        .map_err(|e| format!("nem sikerült megnyitni: {} ({e})", opts.path))?;
    let parser = pick_html(opts.html);
    let page = parser.parse(&source);

    let title = match &page.title {
        Some(t) => format!("{t} – Rozsda"),
        None => String::from("Rozsda"),
    };
    let (lines, content_height) = layout::layout(&page, WIDTH as i32, MARGIN);

    let mut window = Window::new(&title, WIDTH, HEIGHT, WindowOptions::default())?;
    window.set_target_fps(60);
    let mut canvas = Canvas::new(WIDTH, HEIGHT);
    let max_scroll = (content_height - HEIGHT as i32).max(0);
    let mut scroll: i32 = 0;

    while window.is_open() && !window.is_key_down(Key::Escape) {
        // ... a görgetés ugyanaz, mint az előző leckében ...
        scroll = scroll.clamp(0, max_scroll);

        canvas.clear(BACKGROUND);
        for line in &lines {
            let y = line.y - scroll;
            if y + 8 * line.scale < 0 || y > HEIGHT as i32 {
                continue;
            }
            text::draw_text(&mut canvas, line.x, y, &line.text, line.scale, line.color);
        }
        window.update_with_buffer(&canvas.pixels, WIDTH, HEIGHT)?;
    }
    Ok(())
}

fn main() {
    if let Err(e) = run() {
        eprintln!("Hiba: {e}");
        std::process::exit(1);
    }
}
```
