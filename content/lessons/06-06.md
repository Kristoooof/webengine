## Mi van az egér alatt?

A rajzolás iránya: elem → doboz → pixel. A találatvizsgálat ennek a **fordítottja**: pixel → doboz → elem. A layout-fában minden szövegdarabnak megvan a téglalapja és az eleme (`TextFragment { rect, text, node }`, 05-04), úgyhogy csak meg kell keresni azt a darabot, amelyiknek a téglalapjában az egér van.

Két részlet:

- **Ablak vagy lap?** Az egér az **ablak** koordinátáiban jön, a darabok a **lap** koordinátáiban vannak. A kettő között a görgetés a különbség: `lap_y = ablak_y + scroll.offset`.
- **Ki van felül?** Ha két darab fedi egymást (később, a pozicionálásnál ez gyakori lesz), az nyer, amelyik **később festődik**, mert az van felül. Ezért nem az első, hanem a festési sorrendben **utolsó** találat számít.

Ha megvan a darab eleme, a szülők láncán felfelé haladva megkeressük, van-e fölötte `<a href>`. Egy `<a href="x"><b>szia</b></a>` esetén a darab eleme a `<b>`, de a link az `<a>`-é.

```rust
//! Találatvizsgálat (hit testing): mi van az egér alatt?

use rozsda_core::dom::{Document, NodeId};
use rozsda_core::layout::{LayoutBox, Rect};

fn contains(r: &Rect, x: f32, y: f32) -> bool {
    x >= r.x && x < r.right() && y >= r.y && y < r.bottom()
}

/// A lap `(x, y)` pontján lévő szövegdarab eleme. Ami később festődik, az van felül,
/// ezért a festés sorrendjében az utolsó találat nyer.
pub fn hit_test(b: &LayoutBox, x: f32, y: f32) -> Option<NodeId> {
    let mut hit = None;
    for line in &b.lines {
        for f in &line.fragments {
            if contains(&f.rect, x, y) {
                hit = Some(f.node);
            }
        }
    }
    for child in &b.children {
        if let Some(node) = hit_test(child, x, y) {
            hit = Some(node);
        }
    }
    hit
}

/// A link célja, ha a csomópont egy `<a href>` elemben van (akár mélyen benne).
pub fn link_at(doc: &Document, node: NodeId) -> Option<&str> {
    let mut current = Some(node);
    while let Some(id) = current {
        if let Some(e) = doc.element(id)
            && e.name == "a"
            && let Some(href) = e.attr("href")
        {
            return Some(href);
        }
        current = doc.parent(id);
    }
    None
}
```

## Egy link célja

A `href="masodik.html"` egy **relatív** cím: az aktuális oldal mappájához képest kell érteni. Ha az `oldalak/pelda.html`-en vagyunk, a cél az `oldalak/masodik.html`. A `#` utáni rész (fragment) egy helyet jelöl az oldalon belül, ezt most levágjuk. A webcímeket (`https://…`) pedig a 8. modulig, amíg nincs hálózatunk, nem követjük.

A `page.rs`-be (az importokhoz: `use std::path::{Path, PathBuf};`):

```rust
/// Egy link célja helyi fájlként, az aktuális oldal mappájához képest.
/// A webcímeket (a 8. modulig) és az oldalon belüli ugrásokat (`#…`) még nem követjük.
pub fn resolve_link(current: &Path, href: &str) -> Option<PathBuf> {
    if href.contains("://") || href.starts_with('#') {
        return None;
    }
    let file = href.split('#').next()?;
    let dir = current.parent().unwrap_or(Path::new(""));
    Some(dir.join(file))
}
```

és egy kényelmi függvény a `Page`-be, ami fájlból tölt:

```rust
    /// Egy HTML-fájl betöltése.
    pub fn open(engines: &Engines, path: &Path, width: f32) -> Result<Page, String> {
        let source = std::fs::read_to_string(path)
            .map_err(|e| format!("nem sikerült megnyitni: {} ({e})", path.display()))?;
        Page::load(engines, &source, width)
    }
```

A `Path` a `&str` megfelelője fájlútvonalakra, a `PathBuf` pedig a `String`-é. Azért külön típus, mert a fájlnevek nem mindig érvényes UTF-8 szövegek (Windowson UTF-16, Linuxon tetszőleges bájtok), és a `join` a rendszer elválasztóját (`\` vagy `/`) használja.

```rust test
    #[test]
    fn links_are_relative_to_the_current_page() {
        let here = Path::new("oldalak/pelda.html");
        assert_eq!(
            resolve_link(here, "masodik.html"),
            Some(PathBuf::from("oldalak/masodik.html"))
        );
        assert_eq!(
            resolve_link(here, "../README.html#mit-tud"),
            Some(PathBuf::from("oldalak/../README.html"))
        );
        assert_eq!(resolve_link(here, "#teteje"), None);
        assert_eq!(resolve_link(here, "https://example.com/"), None);
    }
```

## Kattintás, kurzor, vissza

Az `App` három új mezőt kap: `path: PathBuf` (az aktuális oldal), `history: Vec<PathBuf>` (az előzők) és `cursor: PhysicalPosition<f64>` (az egér helye). A `run` a `path`-ot paraméterként kapja, a `history` üres, a `cursor` `(0, 0)`.

```rust
    /// A link az egér alatt, ha van. Az ablak-koordinátához hozzá kell adni a görgetést.
    fn link_under_cursor(&self) -> Option<String> {
        let x = self.cursor.x as f32;
        let y = self.cursor.y as f32 + self.scroll.offset;
        let node = hit_test(&self.page.root, x, y)?;
        link_at(&self.page.doc, node).map(String::from)
    }

    /// Egy másik oldal betöltése. A `back` jelzi, hogy a „Vissza” hozott ide.
    fn open(&mut self, path: PathBuf, back: bool) {
        match Page::open(&self.engines, &path, self.viewport.width as f32) {
            Ok(page) => {
                let old = std::mem::replace(&mut self.path, path);
                if !back {
                    self.history.push(old);
                }
                self.page = page;
                self.scroll = Scroll::default();
                self.scroll
                    .set_limits(self.page.content_height(), self.viewport.height as f32);
                if let Some(window) = &self.window {
                    window.set_title(&self.page.title());
                }
                self.request_redraw();
            }
            Err(e) => eprintln!("Hiba: {e}"),
        }
    }
```

A `link_under_cursor` `String`-et ad vissza, nem `&str`-t. A `&str` a `self.page.doc`-ból kölcsönözne, és amíg él, a `self`-et nem lehetne módosítani. Márpedig kattintáskor pont lecseréljük a `self.page`-et. A `String::from` lemásolja a címet, és a kölcsönzés véget ér. Ez tipikus Rust-döntés: egy kis másolás a kölcsönzési ütközés helyett.

A `std::mem::replace(&mut hely, új)` (04-12) beteszi az új útvonalat, és visszaadja a régit, amit a `history`-ba teszünk.

```rust
fn topmost(boxes: &[(f32, f32, f32, f32)], px: f32, py: f32) -> Option<usize> {
    let copy = boxes.to_vec();
    let hits: Vec<usize> = (0..copy.len())
        .filter(|&i| {
            let (x, y, w, h) = copy[i];
            px >= x && px < x + w && py >= y && py < y + h
        })
        .collect();
    hits.last().copied()
}
```
