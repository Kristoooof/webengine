## 1. rész: karakterhivatkozások

A 02-03-ban egy `replace`-lánccal oldottuk meg, de az a szövegtokenen utólag dolgozott, és csak hat hivatkozást ismert. A szabvány szerint a tokenizer **olvasás közben** dekódol, egy saját állapotban (*character reference state*). Háromféle hivatkozás van:

| Fajta | Példa | Eredmény |
|---|---|---|
| Nevesített | `&amp;` `&odblac;` | `&` `ő` |
| Decimális | `&#337;` | `ő` (U+0151 = 337) |
| Hexadecimális | `&#x171;` | `ű` (U+0171) |

A szabvány **2231** nevesített hivatkozást ismer (a teljes lista a [szabvány JSON-fájljában](https://html.spec.whatwg.org/entities.json) van). Mi egy 30 elemes táblázattal dolgozunk, benne a magyar ékezetekkel:

```rust
const NAMED_REFS: [(&str, &str); 30] = [
    ("amp", "&"), ("lt", "<"), ("gt", ">"), ("quot", "\""), ("apos", "'"),
    ("nbsp", "\u{00A0}"), ("copy", "©"), ("reg", "®"), ("hellip", "…"),
    ("mdash", "—"), ("ndash", "–"), ("laquo", "«"), ("raquo", "»"),
    ("bdquo", "„"), ("rdquo", "”"), ("euro", "€"), ("deg", "°"), ("times", "×"),
    ("aacute", "á"), ("eacute", "é"), ("iacute", "í"), ("oacute", "ó"),
    ("ouml", "ö"), ("odblac", "ő"), ("uacute", "ú"), ("uuml", "ü"),
    ("udblac", "ű"), ("Aacute", "Á"), ("Eacute", "É"), ("Odblac", "Ő"),
];
```

(Gépelés helyett ezt nyugodtan másold ki egy szövegszerkesztőből. Ez adat, nem logika. 🙂)

### A szabályok, egyszerűsítve

**Numerikus** (`&#` után):
- `x` vagy `X` után hexadecimális, különben decimális számjegyek.
- Ha nincs egyetlen számjegy sem (pl. `&#;`), nem hivatkozás: a `&` sima karakter marad.
- A záró `;` elhagyható (parse error, de működik).
- A 0, a túl nagy szám és a **surrogate** (U+D800–U+DFFF) helyett U+FFFD (�) lesz. A `char::from_u32` a surrogate-ekre és a túl nagy számokra `None`-t ad, így ez szinte magától működik.

**Nevesített**:
- A `&` utáni betű- és számjegysorozatban megkeressük a **leghosszabb** egyező nevet a táblázatból.
- Ha nincs egyező név, a `&` sima karakter.
- Ha van `;` a név után, azt is elfogyasztjuk.
- **Attribútumban** különleges szabály: ha nincs `;`, és a név után `=` vagy betű/szám jön, **nem** dekódolunk. Ez az URL-ek miatt van: a `<a href="?a=1&copy=2">` értéke maradjon `?a=1&copy=2`, ne legyen belőle `?a=1©=2`.

A függvény az `&` beolvasása után fut. Ha sikerül, a dekódolt szöveget adja vissza, és továbblépteti a pozíciót. Ha nem, `None`-t ad, és a pozíció változatlan marad:

```rust
fn char_ref(&mut self, in_attribute: bool) -> Option<String>
```

## 2. rész: nyers szöveg

Mit tokenizál a mostani kódod ebből?

```html
<script>if (a<b) x = '</p>';</script>
```

A `<b`-t tagnak hiszi, és a `</p>`-t is. Pedig ez JavaScript! A szabvány szerint bizonyos elemek tartalma **nyers szöveg**:

| Elemek | Állapot | Karakterhivatkozás? |
|---|---|---|
| `script`, `style`, `xmp`, `iframe`, `noembed`, `noframes` | **RAWTEXT** | nem |
| `title`, `textarea` | **RCDATA** | igen (`&amp;` működik) |

Ezekben az állapotokban minden szöveg, amíg nem jön egy **„megfelelő zárótag”**: `</` + a nyitótag neve (kis- és nagybetű mindegy) + szóköz, `/` vagy `>`. Tehát a `</scriptx>` nem zárja le a scriptet, a `</SCRIPT >` viszont igen.

:::note Ki kapcsolja át az állapotot?
A szabványban a **fa-építő** kapcsolja át a tokenizert RAWTEXT-re, amikor egy `<script>` kezdőtagot kap. Mi ezt egyszerűsítjük: maga a tokenizer vált, amikor kibocsát egy ilyen kezdőtagot. Egy SVG-n belüli `<style>` esetén ez eltér a szabványtól, de egyszerű HTML-nél ugyanazt adja.
:::

:::task
1. Két új állapot (`RawText`, `Rcdata`) és egy új mező: `last_start_tag: String`.
2. Az `emit_tag` kezdőtag-ágában: a név alapján válassz következő állapotot (`RawText`, `Rcdata` vagy `Data`), és jegyezd meg a nevet a `last_start_tag`-ben.
3. `fn is_appropriate_end_tag(&self) -> bool`: a `<` utáni pozíción `/` + `last_start_tag` (kis- és nagybetű mindegy) + szóköz, `/` vagy `>` áll-e.
4. A **RawText** és az **Rcdata** állapot: `<` és megfelelő zárótag esetén lépd át a `/` jelet és a nevet, kezdj egy záró taget a névvel, és válts **TagName**-re (az onnan már kezeli a szóközt, a `/`-t és a `>`-t). Rcdata-ban az `&` hivatkozás. Minden más karakter szöveg.
:::

```rust test
    #[test]
    fn raw_text_script_and_style() {
        assert_eq!(
            tokenize("<script>if (a<b) x = '</p>';</script>z"),
            vec![start("script"), text("if (a<b) x = '</p>';"), end("script"), text("z"), Token::Eof]

        assert_eq!(tokenize("<style>a > b {}</STYLE >"), vec![start("style"), text("a > b {}"), end("style"), Token::Eof]);
```

:::solution
```rust
/// Az `&` után hívjuk. Ha sikerült dekódolni, visszaadja a szöveget; ha nem, `None`,
/// és a pozíció nem változik (a hívó egy sima `&`-et ír ki).
fn char_ref(&mut self, in_attribute: bool) -> Option<String> {
    let start = self.pos;
    if self.starts_with("#") {
        self.pos += 1;
        let hex = self.starts_with("x") || self.starts_with("X");
        if hex {
            self.pos += 1;
        }
        let radix = if hex { 16 } else { 10 };
        let mut digits = String::new();
        while let Some(&c) = self.input.get(self.pos) {
            if !c.is_digit(radix) {
                break;
            }
            digits.push(c);
            self.pos += 1;
        }
        if digits.is_empty() {
            self.pos = start;
            return None;
        }
        if self.starts_with(";") {
            self.pos += 1;
        }
        let n = u32::from_str_radix(&digits, radix).unwrap_or(0xFFFD);
        let c = match n {
            0 => '\u{FFFD}',
            _ => char::from_u32(n).unwrap_or('\u{FFFD}'),
        };
        return Some(c.to_string());
    }

    let mut run = String::new();
    let mut i = self.pos;
    while let Some(&c) = self.input.get(i) {
        if !c.is_ascii_alphanumeric() || run.len() >= 32 {
            break;
        }
        run.push(c);
        i += 1;
    }
    let best = NAMED_REFS
        .iter()
        .filter(|(name, _)| run.starts_with(name))
        .max_by_key(|(name, _)| name.len())?;
    let after = self.input.get(self.pos + best.0.len()).copied();
    let has_semicolon = after == Some(';');
    if in_attribute && !has_semicolon && matches!(after, Some(c) if c == '=' || c.is_ascii_alphanumeric()) {
        return None;
    }
    self.pos += best.0.len();
    if has_semicolon {
        self.pos += 1;
    }
    Some(best.1.to_string())
}

fn emit_tag(&mut self) {
    self.finish_attr();
    let name = std::mem::take(&mut self.tag_name);
    if self.tag_is_end {
        self.emit(Token::EndTag { name });
        self.state = State::Data;
    } else {
        self.state = match name.as_str() {
            "script" | "style" | "xmp" | "iframe" | "noembed" | "noframes" => State::RawText,
            "title" | "textarea" => State::Rcdata,
            _ => State::Data,
        };
        self.last_start_tag = name.clone();
        let attrs = std::mem::take(&mut self.attrs);
        self.emit(Token::StartTag { name, attrs, self_closing: self.self_closing });
    }
}

/// `</név` következik-e (a nyers szöveget nyitó tag nevével), utána szóköz, `/` vagy `>`.
fn is_appropriate_end_tag(&self) -> bool {
    if !self.starts_with("/") {
        return false;
    }
    let name_start = self.pos + 1;
    let name: Vec<char> = self.last_start_tag.chars().collect();
    for (k, c) in name.iter().enumerate() {
        match self.input.get(name_start + k) {
            Some(x) if x.eq_ignore_ascii_case(c) => {}
            _ => return false,
        }
    }
    matches!(self.input.get(name_start + name.len()), Some(&c) if is_whitespace(c) || c == '/' || c == '>')
}

// ... a run() match-ében:
State::RawText | State::Rcdata => match c {
    Some('<') if self.is_appropriate_end_tag() => {
        self.pos += 1 + self.last_start_tag.chars().count();
        self.new_tag(true);
        self.tag_name = self.last_start_tag.clone();
        self.state = State::TagName;
    }
    Some('&') if self.state == State::Rcdata => {
        let s = self.char_ref(false).unwrap_or_else(|| "&".to_string());
        self.text.push_str(&s);
    }
    Some(c) => self.text.push(c),
    None => break,
},
```

:::why Ami még hiányzik a szabványból
A tokenizerünk most kb. 20 állapotot ismer, a szabvány 80-at. Kimaradt például: a `<script>` belsejében lévő `<!--` „escape” állapotai (régi trükk, hogy a JS-t nem ismerő böngészők ne írják ki a kódot), a `PLAINTEXT` állapot, a CDATA-szakaszok az SVG-ben, a NULL karakter (U+0000) kezelése, a C1 vezérlőkarakterek átkódolása a numerikus hivatkozásokban (`&#128;` → €, a régi Windows-1252 kódolás miatt), és a 2231 nevesített hivatkozás. A **html5lib-tests** projekt több ezer tesztet tartalmaz a tokenizerhez, JSON formátumban. Ha kedved van, írhatsz hozzájuk egy kis tesztfuttatót, és lemérheted, a tesztek hány százalékán megy át a tokenizered. A 16. modulban a html5ever mind a 80 állapotot tudja, és a kapcsolóval összehasonlíthatod a kettőt.

@@ megoldás
```rust
fn numeric_char_ref(s: &str) -> Option<char> {
    let rest = s.strip_prefix('#')?;
    let (digits, radix) = match rest.strip_prefix(['x', 'X']) {
        Some(hex) => (hex, 16),
        None => (rest, 10),
    };
    let end = digits.find(|c: char| !c.is_digit(radix)).unwrap_or(digits.len());
    if end == 0 {
        return None;
    }
    let n = u32::from_str_radix(&digits[..end], radix).unwrap_or(0);
    Some(match n {
        0 => '\u{FFFD}',
        _ => char::from_u32(n).unwrap_or('\u{FFFD}'),
    })
}
```
