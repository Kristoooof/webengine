:::goal
A CSS-motor megtanulja a **rövidítő tulajdonságokat** (shorthands): a `margin: 0 auto`, a `padding: 8px 16px` és a `border: 2px solid red` szétbomlik a hosszú nevű (longhand) tulajdonságokra. Utána a böngésző beépített stíluslapja is valódi margókat kap: a `body` 8 pixelt, a bekezdések és a címsorok pontosan annyit, mint a Chrome-ban.
:::

## A négy oldal szabálya

A `margin`, a `padding` és a `border-width` 1, 2, 3 vagy 4 értéket fogad el. Óramutató járása szerint, **felülről** indulva:

| Megadva | Fent | Jobbra | Lent | Balra |
|---|---|---|---|---|
| `margin: A` | A | A | A | A |
| `margin: A B` | A | B | A | B |
| `margin: A B C` | A | B | C | B |
| `margin: A B C D` | A | B | C | D |

Az ökölszabály: ami hiányzik, azt a **szemközti** oldalról vesszük. A bal oldal a jobbról, a lent a fentről. Így lesz a `margin: 0 auto`-ból „fent-lent 0, jobbra-balra `auto`”: ez a klasszikus középre igazítás (05-05).

## A `border` rövidítés

A `border: 2px solid navy` három dolgot állít: a négy oldal vastagságát, a stílust és a színt, **bármilyen sorrendben**. Hogy melyik rész melyik, azt az értéke dönti el:

- ha szín (`navy`, `#c2410c`, `rgb(…)`, `currentcolor`) → `border-color`
- ha keretstílus-kulcsszó (`solid`, `none`, `dashed`…) → `border-style`
- ha hossz, `0`, `thin`, `medium` vagy `thick` → a négy `border-*-width`
- bármi más, vagy ugyanaz kétszer → az egész deklaráció érvénytelen

:::warn A rövidítés mindent beállít
Egy rövidítés **minden** részét beállítja, akkor is, ha nem írtad ki: ami hiányzik, a kezdőértékét kapja. A `border: 2px red` tehát `border-style: none`-t is jelent, és így **nincs keret** (05-02). Ez a CSS egyik leggyakoribb meglepetése. Mi ezt úgy oldjuk meg, hogy a hiányzó részek helyére az `initial` kulcsszót tesszük, amit a `compute` már ismer (04-10).
:::

## Részekre bontás

Az érték tokenjeit szóközöknél kell darabolni, de figyelni kell a zárójelekre: a `1px solid rgb(28, 25, 23)` három rész, nem öt, mert a függvény belsejében álló szóközök nem választanak el. Ugyanaz a mélységszámlálás, mint a deklarációk `;`-jénél (04-05).

```rust
//! Rövidítő tulajdonságok (shorthands) szétbontása: `margin: 0 auto` → négy margó.

use crate::tokenizer::{Token, trim_ws};
use crate::value::{Value, parse_value};

const SIDES: [&str; 4] = ["top", "right", "bottom", "left"];

/// Egy érték szóközzel elválasztott részei. A zárójelen belüli szóköz nem választ el,
/// így az `rgb(1, 2, 3)` egyetlen rész marad.
pub fn components(tokens: &[Token]) -> Vec<&[Token]> {
    let tokens = trim_ws(tokens);
    let mut out = Vec::new();
    let mut depth = 0;
    let mut start = 0;
    for (i, t) in tokens.iter().enumerate() {
        match t {
            Token::Function(_) | Token::LeftParen => depth += 1,
            Token::RightParen if depth > 0 => depth -= 1,
            Token::Whitespace if depth == 0 => {
                if i > start {
                    out.push(&tokens[start..i]);
                }
                start = i + 1;
            }
            _ => {}
        }
    }
    if start < tokens.len() {
        out.push(&tokens[start..]);
    }
    out
}

/// A négy oldal (fent, jobbra, lent, balra) 1–4 megadott részből.
pub fn four_sides<T: Clone>(parts: &[T]) -> Option<[T; 4]> {
    match parts {
        [a] => Some([a.clone(), a.clone(), a.clone(), a.clone()]),
        [a, b] => Some([a.clone(), b.clone(), a.clone(), b.clone()]),
        [a, b, c] => Some([a.clone(), b.clone(), c.clone(), b.clone()]),
        [a, b, c, d] => Some([a.clone(), b.clone(), c.clone(), d.clone()]),
        _ => None,
    }
}

/// Egy deklarációból a hosszú nevű (longhand) deklarációk.
/// Ami nem rövidítés, az változatlanul jön vissza; a hibás rövidítésből üres lista lesz.
pub fn expand(name: &str, value: &[Token]) -> Vec<(String, Vec<Token>)> {
    match name {
        "margin" | "padding" => sides(name, "", value),
        "border-width" => sides("border", "-width", value),
        "border" => border(value),
        "background" => vec![("background-color".to_string(), value.to_vec())],
        _ => vec![(name.to_string(), value.to_vec())],
    }
}

fn sides(prefix: &str, suffix: &str, value: &[Token]) -> Vec<(String, Vec<Token>)> {
    let Some(parts) = four_sides(&components(value)) else {
        return Vec::new();
    };
    SIDES
        .iter()
        .zip(parts)
        .map(|(side, part)| (format!("{prefix}-{side}{suffix}"), part.to_vec()))
        .collect()
}

fn is_border_style(word: &str) -> bool {
    matches!(
        word,
        "none" | "hidden" | "solid" | "dashed" | "dotted" | "double"
    )
}

fn is_border_width(value: &Value) -> bool {
    match value {
        Value::Length(..) => true,
        Value::Number(n) => *n == 0.0,
        Value::Keyword(k) => matches!(k.as_str(), "thin" | "medium" | "thick"),
        _ => false,
    }
}

/// `border: 1px solid red`, bármilyen sorrendben. Ami kimarad, a kezdőértékét kapja.
fn border(value: &[Token]) -> Vec<(String, Vec<Token>)> {
    let mut width = None;
    let mut style = None;
    let mut color = None;
    for part in components(value) {
        match parse_value(part) {
            Some(Value::Color(_)) if color.is_none() => color = Some(part.to_vec()),
            Some(Value::Keyword(k)) if k == "currentcolor" && color.is_none() => {
                color = Some(part.to_vec())
            }
            Some(Value::Keyword(k)) if is_border_style(&k) && style.is_none() => {
                style = Some(part.to_vec())
            }
            Some(v) if is_border_width(&v) && width.is_none() => width = Some(part.to_vec()),
            _ => return Vec::new(),
        }
    }
    let initial = || vec![Token::Ident("initial".to_string())];
    let width = width.unwrap_or_else(initial);
    let mut out: Vec<(String, Vec<Token>)> = SIDES
        .iter()
        .map(|side| (format!("border-{side}-width"), width.clone()))
        .collect();
    out.push(("border-style".to_string(), style.unwrap_or_else(initial)));
    out.push(("border-color".to_string(), color.unwrap_or_else(initial)));
    out
}
```

```rust
fn expand_sides(value: &str) -> Option<[String; 4]> {
    let parts: Vec<String> = value
        .split(' ')
        .map(|p| p.trim().to_string())
        .filter(|p| !p.is_empty())
        .collect();
    let mut sides: Vec<String> = Vec::new();
    for i in 0..4 {
        let pick = match (parts.len(), i) {
            (1, _) => 0,
            (2, 0) | (2, 2) => 0,
            (2, _) => 1,
            (3, 3) => 1,
            (3, n) => n,
            (4, n) => n,
            _ => return None,
        };
        sides.push(format!("{}", parts[pick].clone()));
    }
    let arr: [String; 4] = sides.try_into().ok()?;
    Some(arr)
}
```
